## 📋 使用说明

### 如何分配资源

1. **评估愿景需求**
   - 需要哪些技能
   - 预计多少工时
   - 什么时间需要

2. **查看可用资源**
   - 检查资源池可用状态
   - 查看技能匹配度
   - 确认时间安排

3. **执行分配**
   - 更新上表的分配比例
   - 记录到变更日志
   - 通知相关方

4. **跟踪调整**
   - 每周审查实际使用情况
   - 根据需要动态调整
   - 记录偏差和原因

### 如何解决冲突

当多个愿景竞争同一资源时：

1. **优先级排序**: P0 > P1 > P2
2. **紧急程度**: 截止日期近的优先
3. **依赖关系**: 上游任务优先
4. **协商调整**: 必要时重新规划
