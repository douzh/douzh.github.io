# 中华人民共和国学科分类与代码

> **标准号**：GB/T 13745—2009  
> **发布日期**：2009-05-06  
> **实施日期**：2009-11-01  
> **发布机构**：中华人民共和国国家质量监督检验检疫总局 / 中国国家标准化管理委员会  
> **代替标准**：GB/T 13745—1992

---

## 总体说明

本标准共设 **62 个一级学科**（或学科群）、**738 个二级学科**、**2732 个三级学科**，分属以下五大门类：

| 门类代号 | 门类名称 | 一级学科代码范围 |
| A | 自然科学 | 110～199 |
| B | 农业科学 | 210～249 |
| C | 医药科学 | 310～369 |
| D | 工程与技术科学 | 410～639 |
| E | 人文与社会科学 | 710～919 |

---

## 编码方法

学科分类代码采用三级结构，共 7 位数字：

```
XXX  XX  XX
|    |   +-- 三级学科（2位）
|    +------ 二级学科（2位）
+----------- 一级学科（3位）
```

- 二、三级学科设“群体学科”，用 **99** 表示
- 交叉学科或多重归属学科，只在一处赋予代码，其他位置标注“见（代码）”
