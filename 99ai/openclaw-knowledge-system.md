# 创建类似 OpenClaw 智能助手所需知识体系

## 一、核心架构知识

### 1. **智能体架构设计**
- Agent Loop（感知→规划→行动→观察→反馈）
- 轮辐式架构设计（网关 + 智能体运行时）
- 微内核 vs 单体架构选择
- 插件化扩展机制

### 2. **四层架构能力**
- **渠道适配层**（前台）：多通讯平台接入
