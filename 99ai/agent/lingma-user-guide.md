## 一、认识 Lingma

### 1.1 什么是 Lingma

Lingma 是一个智能 AI 助手，可以：
- 💬 与您自然对话，理解您的需求
- 💻 编写和审查代码
- 📝 创建和修改文档
- 🔧 调用工具执行实际任务（通过 MCP）

### 1.2 Lingma 能帮您做什么

#### **层级 1：纯数字能力**（原生支持）
- ✅ 语言理解、代码生成、文档创作
- ✅ 知识问答、逻辑推理、数学计算
- ✅ 代码分析、Bug 检测、优化建议

#### **层级 2：操作系统能力**（IDE 支持）
- ✅ 文件操作、命令执行、进程管理
- ✅ 项目结构分析、代码导航
- ✅ 终端命令、脚本执行

#### **层级 3：物理世界能力**（通过 MCP）
- ✅ 硬件控制、IoT 设备、工业系统
- ✅ 打印机、传感器、音视频设备
- ✅ 智能家居、机器人、自动化系统

### 4.3 设置和使用规则

规则是你设定的**必须遵守的指令和行为准则**，Lingma 会严格按照规则执行。

#### **规则的类型**

**1. 永久规则（Always On）**

始终生效的规则，每次交互都遵守。

```
您：以后所有的代码注释都用英文写

Lingma: ✅ 已设置永久规则
        规则名称：code-comment-language
        规则内容：所有代码注释必须使用英文编写
        生效范围：所有代码生成场景
```

**示例代码（应用规则后）：**
```java
public class UserManager {
    // User's unique identifier
    private int userId;
    
    // User's display name
    private String userName;
}
```

**2. 临时规则（Session Rules）**

仅在当前会话中有效的规则。

```
您：今天生成的所有变量名都加上前缀 temp_

Lingma: ✅ 已设置临时规则（仅本次会话有效）
        规则：变量名添加 temp_ 前缀
        有效期：当前会话
```

**3. 条件规则（Conditional Rules）**

在特定条件下才应用的规则。

```
您：生成 Java 代码时必须写 Javadoc 注释

Lingma: ✅ 已设置条件规则
        触发条件：生成 Java 代码
        规则要求：必须包含 Javadoc 注释
```

#### **常用规则示例**

**编码规范类：**
```
✅ 所有函数必须有类型注解
✅ 使用 ES6+ 语法
✅ 禁止使用 var，使用 let/const
✅ 组件必须使用函数式写法
```

**工作流程类：**
```
✅ 提交前必须运行 lint 检查
✅ 新功能必须写单元测试
✅ 每天下班前提交代码
```

**文档规范类：**
```
✅ README 必须包含安装说明
✅ API 文档必须用 OpenAPI 格式
✅ 日期格式：yyyy-MM-dd HH:mm:ss
```

#### **规则的应用效果**

```
您：创建一个用户管理类

Lingma: [自动应用规则]
        ✓ 规则 1：代码注释用英文
        ✓ 规则 2：使用驼峰命名
        ✓ 规则 3：必须写 Javadoc
        
        /**
         * Manages user accounts and authentication
         */
        public class UserManager {
            
            /**
             * The unique identifier for the user
             */
            private int userId;
            
            /**
             * The user's display name
             */
            private String userName;
        }
```

#### **查看当前规则**

```
您：现在有什么规则在生效？

Lingma: 📋 当前的规则集：
        
        【永久规则】
        ✅ 使用中文回复
        ✅ 代码注释用英文
        ✅ Markdown 可直接修改
        
        【条件规则】
        ⚪ Java 代码 → Javadoc 注释
        ⚪ TypeScript 代码 → 类型注解
        
        【临时规则】
        （无）
```

## 六、常见问题

### Q1: 如何让 Lingma 调用工具？
**答：** 直接告诉 Lingma 您的需求，它会自动判断是否需要调用工具。

```
您：查询北京的天气
Lingma: [自动调用天气 API]
       北京今天晴转多云，气温 15-22°C...
```

### Q2: 工具调用失败怎么办？
**答：** Lingma 会提供详细的错误信息和建议。

```
Lingma: 抱歉，调用 GitHub API 失败。
       错误原因：网络连接超时
       
       建议操作：
       1. 检查网络连接
       2. 确认 GitHub 服务正常
       3. 重试操作
       
       需要我重新尝试吗？
```

### Q3: 可以控制哪些硬件设备？
**答：** 通过 MCP 可以控制：
- 智能家居设备（灯光、空调、门锁）
- 传感器（温度、湿度、压力）
- 工业设备（PLC、机械臂）
- 打印扫描设备
- 音视频设备

需要相应的 MCP 服务和硬件接口。
