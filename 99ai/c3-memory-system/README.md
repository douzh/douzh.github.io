## 记忆系统架构

```
┌─────────────────────────────────────┐
│         用户请求                     │
└──────────────┬──────────────────────┘
               ↓
    ┌──────────────────────┐
    │   短期记忆 (内存)     │ ← 最近 72 小时对话
    │  - LRU Cache          │
    │  - 会话上下文         │
    │  - 工作记忆           │
    └──────────┬───────────┘
               ↓
    ┌──────────────────────┐
    │   检索增强            │
    │  - 关键词检索 (BM25)  │
    │  - 向量语义检索       │
    │  - 混合检索策略       │
    └──────────┬───────────┘
               ↓
    ┌──────────────────────┐
    │   长期记忆 (持久化)   │ ← 永久存储
    │  - SQLite 数据库      │
    │  - Markdown 文件      │
    │  - 向量索引           │
    └──────────────────────┘
```
