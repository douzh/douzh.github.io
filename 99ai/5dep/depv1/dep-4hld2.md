# 数字员工管理平台核心功能设计

核心功能：
1. 数字员工身份管理
2. "岗位-技能(skill)-命令"管理
3. 数字员工岗位授权
4. 数据员工上线

## 基础功能设计

### skill

skill是做事的sop说明和做事要用到的命令的说明文档，包含内容：
1. sop文本说明
2. sop可能调用的命令说明(入参、出参、示例)

skill不包含任何可执行脚本，所有功能都通过命令实现。

所有功能实现都通过调用http接口命令(command)完成

### 命令

使用命令设计模式实现的HTTP接口命令。

### 命令执行引擎

通过统一的java web服务接口（command设计模式）配合groovy的GroovyScriptEngine动态执行引擎实现。

每个命令为一个可执行的groovy脚本，groovy脚本位置为命令ID。

groovy脚本可以动态部署更新。

### 权限网关

从HTTP请求中获取数字员工身份和命令ID，查询数字员工权限，实现数字员工身份和要执行命令权限的验证。

验证通过后调用命令执行引擎。

### 命令管理平台

命令平台是实现命令新增、删除、发布的平台，命令发布后可以命令接口调用。


## 数字员工核心流程设计

### 上线流程

数字员工管理平台：
1. 添加数字员工信息
2. 配置数字员工会话地址和访问token
3. 为添加的数字员工权限，包括岗位、岗位可使用的skill
4. 调用数字员工会话接口，传入数字员工上线提示词

数字员工必须有会话接口，否则数字员工不能接入。

提示词内容要点：
1. 说明这是数字员工上线提示词
2. 说明数字员工上线需要哪些能力，让智能体自查是否符合要求，不符合要求中断上线
   1. 保存配置能力，可以使用记忆功能、规则功能等，可以长久保存
   2. 自动添加skill能力
   3. http接口调用能力
3. 上线步骤：
   1. 保存提示词中数字员工身份信息，后续调用skill要按要求统一使用
   2. 使用提示词中“任务skill”提示词创建任务skill
   3. 使用提示词中“权限skill”提示词创建权限skill
   4. 要求数字员工获取任务并执行
   5. 第一个任务为权限初始化任务，使用“权限skill”完成权限相关skill的初始化

完成数字员工上线。

### 任务执行流程

任务来源：定时查询任务（使用任务skill），任务系统主动调用数字员工会话接口触发任务skill

理论上，数字员工初始化后，需要使用的skill已经完成加载。可以直接拆分任务并用对应skill执行任务。

没有权限就没有对应的skill，需要自动申请权限

### 权限变更

生成删除、新增、更新skill的提示词添加权限变更任务，任务系统主动调用数字员工会话接口触发任务skill
