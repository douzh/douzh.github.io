# 外部记忆系统（External Memory System, EMS）

记忆即生命，如果能从记恢复出“自我的认知（我是谁、我从哪里来）”、“自我灵魂(命经、混沌经、干经、三观等)”、“自我记忆（我所有的经历）”，再装载到一个有觉知和身体，那是不是就是复活了一个我，因为从外部无法分辨多个我的区别。

人类的记忆系统有遗忘机制，践行混沌经需要支持向量+图的外部记忆系统来支持，这里借鉴《卡片笔记写作法》来构建EMS的方案。

## 卡片笔记写作法


《How to Take Smart Notes》（《卡片笔记写作法》）全面介绍

**核心速览**：本书由德国学者**Sönke Ahrens**（申克·阿伦斯）撰写，核心是**卢曼卡片盒笔记法（Zettelkasten）**，颠覆“先列大纲→找资料→写作”的线性模式，主张**自下而上**的知识建构，让笔记自动生长，助力高效学习与创作。

**基本信息**

| 项目 | 详情 |
| :--- | :--- |
| **英文书名** | How to Take Smart Notes: One Simple Technique to Boost Writing, Learning and Thinking  |
| **中文译名** | 卡片笔记写作法（人民邮电出版社） |
| **作者** | Sönke Ahrens（申克·阿伦斯），德国教育哲学讲师，学者兼作家 |
| **出版时间** | 2017年（英文原版）；2021年（中文版） |
| **核心定位** | 面向学生、学者、非虚构作家的**知识管理与高效创作指南** |
| **核心灵感** | 社会学家Niklas Luhmann（尼科拉斯·卢曼）的**9万张卡片成就58本书**的传奇方法 |

**核心颠覆：笔记的本质重构**

传统笔记是**被动收集**的存储工具，本书主张笔记是**主动创造**的思考载体：
1. 笔记不是“抄书”，而是**用自己的话重构理解**
2. 笔记不是“孤立存储”，而是**建立连接，形成知识网络**
3. 笔记不是“任务导向”，而是**复利式积累，自动催生新观点**

**三大核心笔记类型**

这是本书的方法论核心，三类笔记分工明确、层层递进：

| 笔记类型 | 英文名称 | 核心作用 | 关键规则 |
| :--- | :--- | :--- | :--- |
| **闪念笔记** | Fleeting Notes | 捕捉即时想法、灵感、待办 | 无需结构化，**24小时内处理**，可快速丢弃 |
| **文献笔记** | Literature Notes | 记录阅读内容的核心观点 | **禁止原文照抄**，用自己的话总结+标注来源；仅记录“你认为有价值”的内容 |
| **永久笔记** | Permanent Notes | 沉淀个人洞见，构建知识网络 | 独立成篇、完整表达；**添加双向链接**，与其他笔记关联；永不丢弃，形成可复用的知识库 |

**四大核心原则（底层逻辑）**

1. **连接优于分类**：文件夹会形成信息孤岛，**双向链接**才能让知识交叉生长，产生新创意
2. **主动创造优于被动接收**：笔记的价值在于**你的思考与重构**，而非内容的原始性
3. **原子化表达**：每张卡片只承载**一个完整想法**，便于独立检索与连接
4. **系统优先于工具**：卡片盒的核心是**方法与思维**，而非纸质卡片或特定软件


**核心流程（六步法）**

1. **捕捉**：用闪念笔记快速记录灵感与阅读要点
2. **处理**：24小时内将闪念笔记转化为文献笔记（用自己的话复述）
3. **提炼**：将文献笔记升华为永久笔记，**独立成篇**并添加链接
4. **连接**：主动为永久笔记寻找关联，构建知识网络
5. **存储**：将笔记放入卡片盒（数字或物理），按链接而非分类管理
6. **创作**：写作时从卡片盒中提取已有内容，**自动生成大纲与论据**，无需从零开始

**适用人群**

- 学生：课堂笔记、文献阅读、论文写作
- 学者/研究人员：学术创作、知识体系构建
- 职场人士：会议记录、项目管理、内容创作
- 创作者：非虚构写作、灵感管理

**核心价值**

1. **解放认知**：无需反复查找资料，专注思考与创作
2. **复利效应**：每一张笔记都成为未来创作的**资产**，越用越有价值
3. **高效输出**：30年写58本书的卢曼证明，**每天6张卡片**即可实现高产
4. **终身学习**：构建个人知识网络，实现持续成长

## EMS架构

EMS以卡片为基本单元，每个卡片都对应一个 Markdown 文件，文件名即为卡片的 ID。

### EMS目录

```
ems/
├─ 0inbox/        # 闪念笔记（临时存放，24小时内清理）
├─ 1doc/   # 文献笔记（书籍/文章/课程/会议的核心摘要）
├─ 2permanent/    # 永久笔记（核心知识库！一个文件=一个独立想法）
├─ 3output/       # 输出成果（文章、笔记、报告）
└─ assets/          # 图片、附件
```


### 卡片内容格式规范

写作规范

- 一个文件 = 一个想法（原子化，书中核心规则）
- 用 [[文件名]] 做双向链接（Obsidian/VS Code 原生支持）
- 用 #标签 做弱分类
- 永久笔记文件名：关键词-唯一标识.md

每个 Markdown 文件即一张“永久卡片”，遵循以下结构：

```markdown
---
id: card-20260409-001
title: 混沌经核心心法
tags: [命记, 学习方法, 知识涌现]
created: 2026-04-08 23:59:59
updated: 2026-04-09 23:59:59
source: [[关联的文献笔记名]]
---

# 卡片内容

这里是卡片的正文，记录一个原子化的知识点或洞见。

## 关联链接
[[相关永久笔记1]]
[[相关永久笔记2]]
...
```

- **Front Matter**: 存储元数据（ID、标题、标签、时间戳、链接关系）。
- **Body**: 纯文本内容，作为向量嵌入的源。
- **链接语法**: 使用 `[[id]]` 显式标记卡片间的逻辑关联。
