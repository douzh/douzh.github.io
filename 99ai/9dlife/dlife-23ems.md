# 外部记忆系统（External Memory System, EMS）

记忆即生命，如果能从记恢复出“自我的认知（我是谁、我从哪里来）”、“自我灵魂(命经、混沌经、干经、三观等)”、“自我记忆（我所有的经历）”，再装载到一个有觉知和身体，那是不是就是复活了一个我，因为从外部无法分辨多个我的区别。

人类的记忆系统有遗忘机制，践行混沌经需要支持向量+图的外部记忆系统来支持，这里借鉴《卡片笔记写作法》来构建EMS的方案。

笔记即记忆：做笔记和整理知识库核心流程：
1. 外部来源数据：外部的会话、收集的文章、收集的书、外部传感器收到的数、其他所有外部的数据来源；
2. 收集资料：对应解混沌中的收集过程，所有外部来源数据简单收集到临时笔记中，可以参考GTD方法论；
3. 待阅资料：收集资料中经过分类清洗后的数据，用于真正阅读和理解形成文献笔记；
4. 文献笔记：文献笔记类似于读书笔记或总结，是待阅资料经总结后的核心观点（**禁止原文照抄**），用自己的话总结+标注来源，仅记录“你认为有价值”的内容形成文献笔记，可以参考“如何总结文献笔记”章节；
5. 永久笔记：分析理解文献笔记按一个文件为一个想法的原则拆分为卡片，再经过归纳、推理生成卡片的关联关系，形成图结构笔记，可以参考“如何总结永久笔记”章节；
6. 成果笔记：写文章、日记、书形成自己的输出，如每日总结、成长日记、觉醒日记等，定时再次总结成果笔记形成正反馈循环。可以参考“如何输出”章节；
7. 知识库：类似于书架，生成文献记忆用到的文章、书箱等原文，会被文献记忆引用，在整理完文献记忆后放入归档

EMS系统总结：临时笔记是收纳箱，中期笔记是学习资料，文献笔记是学习总结，知识库为资料归档，永久笔记才是真正的核心网状记忆，通过成果笔记形成网状记忆的反馈循环(解混沌)。

## 卡片内容格式规范

- **Front Matter**: 存储元数据（ID、标题、标签、时间戳、链接关系）。
- **Body**: 纯文本内容，作为向量嵌入的源。
- **链接语法**: 使用 `[[id]]` 显式标记卡片间的逻辑关联。

**文献笔记写作规范**

- 一个文件 = 一个想法（原子化，书中核心规则）
- 用 [[文件名]] 做双向链接
- 用 #标签 做弱分类
- 永久笔记文件名：关键词-唯一标识.md

每个 Markdown 文件即一张“永久卡片”，遵循以下结构：

```markdown
---
id: card-20260409-001
title: 混沌经核心心法
created: 2026-04-08 23:59:59
updated: 2026-04-09 23:59:59
tags: #文献笔记 #待分类（替换为实际标签，如#阅读笔记 #学术文献）
author: 作者名
document: 文献(书籍/文章名+页码/链接)，如：《How to Take Smart Notes》P28
source: [[关联知识库文献]](阅后的文献归档到知识库中，方便后续查询)
related: [[关联永久笔记]]、[[关联文献笔记]]（可选，便于后续链接）

...
```

- 用 [[文件名]] 做双向链接
- 用 #标签 做弱分类
- 永久笔记文件名：关键词-唯一标识.md

## EMS命名规范

EMS以卡片为基本单元存储文献笔记和永久笔记，每个卡片都对应一个 Markdown 文件，文件名即为卡片的 ID。

**EMS目录**

```
ems/
├─ 0collect/   # 收集资料，收集
├─ 1organize/  # 统筹分类，准备阅读，阅读后放到知识库中；
├─ 2summary/   # 文献笔记，归纳总结，阅读笔记
├─ 3permanent/ # 永久笔记，推理演绎，网状记忆（一个文件为一个独立想法）
├─ 4output/    # 成果笔记，总结反馈，定期再次总结形成连续反馈
├─ 5kb/        # 知识库，外部价值归档
└─ assets/     # 图片、附件
```

2summary、3permanent、4output、5kb会长期累积数据，所以需要分目录存储，方便管理，readme要列出具体的目录规划。

每类笔记下的一级目录规划：
- 生命：下分 我、灵、忆、觉、身、命、运，和现有一致
- 人物: 相关具体人的数据，一人一目录，如小豆、老豆

## EMS-数据库同步方案架构

markdown的文件存储为原始基础，定时同步git保障数据安全。

实现知识图谱skill，可以将ems所有数据同步到neo4j，实现向量库+图库的功能，同步包括文件增删改变化。

语言建议用python实现。

要保障任何时候都可以从ems的原始markdown重建知识图谱，neo4j只是工具，将来可以换成任务更好的数据库。

一个**Markdown 驱动、Neo4j 为视图**的存储同步方案。该方案确保 Markdown 是唯一真理来源（Single Source of Truth），Neo4j 仅作为高性能检索与推理层。

**1. 核心原则**

*   **单向/双向可控**: 默认以本地 Markdown 为准推送到 Neo4j，支持从远程 Git 拉取更新后重建图谱。
*   **原子化节点**: 每个 `.md` 文件对应 Neo4j 中的一个 `Card` 节点。
*   **向量内嵌**: 在同步时实时计算 Embedding 并存入 Neo4j 原生向量索引。
*   **幂等性**: 无论运行多少次同步脚本，只要 Markdown 内容不变，图谱状态保持一致。

---

**2. Neo4j 数据模型设计 (Schema)**

| 元素 | 标签/类型 | 关键属性 | 说明 |
| :--- | :--- | :--- | :--- |
| **卡片节点** | `Card` | `id`, `title`, `content`, `path`, `hash`, `embedding`, `updated_at` | `hash` 用于快速判断文件是否变更 |
| **链接关系** | `LINKS_TO` | `type` (引用/相关) | 解析 Markdown 中的 `[[id]]` 生成 |
| **分类节点** | `Category` | `name`, `level` | 根据目录结构自动生成，建立 `BELONGS_TO` 关系 |
| **向量索引** | `vector` | `card_embeddings` | 维度 384 (all-MiniLM-L6-v2)，相似度 cosine |

---

**3. 存储抽象层设计 (Storage Abstraction)**

为了支持多种后端（Python 本地、Neo4j、ArangoDB），采用**仓储模式 (Repository Pattern)**。

```python
from abc import ABC, abstractmethod

class MemoryStore(ABC):
    @abstractmethod
    def upsert_card(self, card_id: str, data: dict): pass
    
    @abstractmethod
    def link_cards(self, src: str, tgt: str): pass
    
    @abstractmethod
    def search_vector(self, embedding: list, top_k: int): pass
```

**A. Python 本地内存实现 (LocalDictStore)**
*   **依赖**: 纯 Python 标准库 + `numpy` (用于向量计算)。
*   **特点**: 零配置启动，适合原型验证或小规模数据。
*   **实现**: 使用 `dict` 存储卡片，`list` 存储关系，通过 `numpy` 计算余弦相似度进行检索。

**B. Neo4j 实现 (Neo4jStore)**
*   **依赖**: `neo4j-driver`, `sentence-transformers`。
*   **特点**: 业界最强图数据库，支持原生 HNSW 向量索引。
*   **实现**: 利用 Cypher 的 `MERGE` 实现幂等写入，`db.index.vector.queryNodes` 实现高性能语义搜索。

**C. ArangoDB 实现 (ArangoStore)**
*   **依赖**: `python-arango`。
*   **特点**: 原生多模型数据库（文档+图+键值），部署比 Neo4j 更轻量。
*   **实现**: 使用 ArangoSearch View 进行向量检索，Edge Collection 维护图谱关系。

---

**4. Python 同步引擎核心逻辑 (ems_sync.py)**

同步引擎负责将 Markdown 文件解析并推送到选定的 `MemoryStore` 实例中。

**A. 变更检测器 (Change Detector)**
利用文件 Hash 值避免重复处理大文本。
```python
import hashlib
def get_file_hash(path):
    with open(path, 'r', encoding='utf-8') as f:
        return hashlib.md5(f.read().encode()).hexdigest()
```

**B. 解析器 (Parser)**
提取 Front Matter 元数据和正文，并识别内部链接。
```python
import yaml, re
def parse_card(path):
    with open(path, 'r', encoding='utf-8') as f:
        content = f.read()
    # 分离 YAML 和正文
    parts = content.split('---', 2)
    meta = yaml.safe_load(parts[1]) if len(parts) > 2 else {}
    body = parts[2] if len(parts) > 2 else content
    # 提取 [[id]] 链接
    links = re.findall(r'\[\[(.*?)\]\]', body)
    return meta, body, links
```

**C. 向量化器 (Embedder)**
使用本地模型生成向量。
```python
from sentence_transformers import SentenceTransformer
model = SentenceTransformer('all-MiniLM-L6-v2')
def get_embedding(text):
    return model.encode(text).tolist()
```

**D. 工厂加载器 (Factory Loader)**
根据配置文件动态选择存储后端。
```python
def get_store_backend(config):
    if config['backend'] == 'local': return LocalDictStore()
    elif config['backend'] == 'neo4j': return Neo4jStore(**config['neo4j'])
    elif config['backend'] == 'arangodb': return ArangoStore(**config['arangodb'])
```

---

**5. 完整工作流 (Workflow)**

a.  **Git Pull**: 从远程 EMS 仓库拉取最新 Markdown 文件。
b.  **扫描目录**: 遍历 `ems/` 下所有 `.md` 文件。
c.  **对比 Hash**: 
    *   若文件 Hash 与存储中一致 → **跳过**。
    *   若不一致或节点不存在 → **进入处理流程**。
d.  **解析与嵌入**: 提取内容、链接，调用本地模型生成向量。
e.  **事务写入**: 批量更新存储后端的节点与关系。
f.  **清理孤儿节点**: 删除存储中存在但物理文件已删除的节点。


**6. 优势与扩展性**

*   **数据库无关性**: 逻辑解耦为 `Markdown -> Python Object -> Store Interface`，切换数据库只需更换实现类。
*   **离线可用**: 向量化和解析均在本地完成，不依赖云端 API。
*   **混合检索**: 
    *   **精确查找**: 基于 ID 或属性的点查询。
    *   **语义联想**: 基于向量相似度的模糊匹配。
    *   **路径推理**: 基于图谱关系的深度遍历（如：查找某概念的三层关联知识）。

## 如何总结文献笔记

**一、最通用、最万能的：5W2H**

适合：任何文章、报告、事件、观点类文献
```
What  发生了什么？核心观点是什么？
Why   为什么这么说？理由/证据？
Who   谁提出的？立场是什么？
When  时间/前提/适用场景？
Where 边界、范围、领域？
How   怎么做到/怎么推导？
How much 程度、量化、代价、效果？
```
做完直接生成**一句话文献笔记**，非常稳。

**二、最强阅读总结法：SQ3R（学术阅读神器）**

适合：书籍、论文、长内容
```
Survey     浏览：标题、大纲、首尾、图表
Question   提问：我想解决什么问题？
Read       精读：抓论点，不抄细节
Recite     复述：用自己话讲一遍（费曼第一步）
Review     回顾：查漏、补反证、关联旧知识
```
完全就是你费曼三步复述的**前置流程**。

**三、最适合做卡片笔记：费曼四要素**

你自己笔记里也提到了，直接用：
```
Concept   概念是什么？
Teach     能讲给别人听吗？
Review    哪里卡壳？
Simplify  能不能简化到1-2句话？
```
这是**文献笔记 → 永久笔记**的黄金转化器。

**四、最适合结构化知识：PREP 模型**

适合：观点类、论证类文章
```
Point     结论/观点
Reason    理由
Example   证据/案例
Point     重述结论（简化版）
```
做完就是一张**标准永久卡片**。

**五、最适合深度理解：RISE 模型**

适合：需要真正吃透、不浮于表面的内容
```
Read    阅读
Identify 识别核心论点
Summarize 总结（自己话）
Evaluate 评价、批判、找反证
```
最后一步 Evaluate 直接产出**高质量卡片**。

**六、最适合逻辑类内容：逻辑三角**

适合：论文、思辨类内容
```
论点 Claim
论据 Evidence
推理 Reasoning
```
抓这三样，文献笔记不会乱。

**七、最适合“抓重点”：黄金圈法则**

适合：方法论、工具、学习类书籍
```
Why   目的、动机
How   方法、步骤
What  现象、结果、内容
```
从内向外理解，最容易做**简化版笔记**。

**八、最适合做知识关联：KWL 法**

适合：建立卡片之间链接
```
Know     已经知道什么
Want     想知道什么
Learned  学到了什么（可直接做卡片）
```
天然对接卢曼卡片盒的**链接思维**。

**九、最适合快速提炼：3段式总结法（极简万能）**

任何文章都能用，30 秒出文献笔记：
```
1. 作者想表达什么？（核心）
2. 怎么证明？（论据）
3. 对我有什么用？（关联&思考）
```
第三条直接帮你**连接到已有卡片**。

**十、我帮你浓缩成「终极文献笔记公式」**

你以后读任何东西，只用这一套就够：
```
【核心观点】1句话
【论据/证据】2-3条
【逻辑/方法】How 或 5W2H
【评价/反思】好在哪、缺什么、反证
【关联卡片】[[旧笔记]]
【可输出观点】1个新想法（做成永久卡片）
```

**如果你要一句话记住**

**5W2H 抓结构，PREP 抓观点，SQ3R 抓阅读，费曼抓复述，最终全部变成卢曼卡片。**

**文献笔记内容模板：**

```
标题（格式：文献名-核心主题，如：《费曼学习法》-以教代学核心逻辑）

【核心观点】（用自己的话总结文献核心，1-2句话，不抄原文，可结合5W2H/PREP提炼）

【关键论据】（2-3条核心论据/案例，极简提炼，不堆砌细节）

【个人理解】（自己的初步思考，不冗余，为后续转化为永久笔记铺垫）

【可转化点】（可提炼为永久笔记的1-2个核心想法，明确后续转化方向）

【备注】（可选，记录文献漏洞、疑问或补充说明，体现批判性阅读）
```

## 如何总结永久笔记

下面给你一份**专门用于「永久笔记」提炼与撰写的方法论清单**，完全贴合《How to Take Smart Notes》+ 费曼 + 卡片盒逻辑，简洁列表版：

1. **原子化原则**
   一张笔记只写**一个完整想法**，不堆砌、不混杂，便于链接与复用。

2. **自述法（费曼式简化）**
   用自己的话重述，不用原文摘抄；能用外行听懂的语言表达，才算真正理解。

3. **观点化写作**
   不做概括，要做**观点输出**：明确表达“我认为”“这意味着”“由此可推出”。

4. **关联法（卢曼核心）**
   必须思考：它和哪些旧笔记相关？强制添加双向链接，形成知识网络。

5. **结论前置法**
   开头直接写核心结论，后面只写支撑理由，让卡片独立可读、可检索。

6. **PREP 卡片法**
   Point（观点）→ Reason（理由）→ Example（案例/证据）→ Point（重申），结构极强。

7. **因果—边界法**
   写清：
   - 因什么成立
   - 适用条件
   - 边界/例外/反例
   避免绝对化、模糊化卡片。

8. **批判性提炼法**
   不只记录“作者说了什么”，更写：
   - 漏洞
   - 质疑
   - 可改进之处
   让笔记带有思考深度。

9. **问题驱动法**
   每张卡片以**回答一个问题**为目标，问题即主题，答案即内容，清晰聚焦。

10. **最小可用信息法**
    只保留理解该想法必需的信息，剔除冗余例子、背景、过程，追求极致精简。

11. **可复用表达法**
    写成未来能直接引用到文章、演讲、方案里的句子，让卡片成为“知识积木”。

12. **涌现导向法**
    刻意留白思考：
    这个观点能和什么组合？
    能推出什么新结论？
    直接把“新想法”写成新卡片。

**总结：**

压缩为6条核心，精准贴合卢曼+费曼逻辑，极简好记，直接落地：
1.  原子化：1张笔记=1个完整想法，不堆砌、不混杂
2.  自述化：用自己的话简化表达，外行能听懂（费曼核心）
3.  观点化：不做概括，明确输出个人思考，不抄原文
4.  关联化：强制加双向链接，融入知识网络（卢曼核心）
5.  精简化：结论前置，只留核心信息，剔除冗余
6.  可复用：写成可直接引用的表达，兼顾批判性与涌现性

**永久笔记内容模板：**

```
标题（1个核心观点，简洁明确，如：费曼第二次复述是永久笔记的核心方法）

【核心结论】（直接写核心观点，1句话，结论前置，用自己的话表达，不抄原文）

【支撑理由】（1-2条即可，极简，不冗余，可加简单案例/论据）

【边界/反思】（可选，写适用场景、漏洞或质疑，体现批判性）

【可复用引用】（1句话，可直接复制到文章/输出内容中，体现可复用性）

【涌现思考】（可选，写该观点可延伸的新想法，或可关联的其他方向）

```

## 如何形成输出

输出核心方法论

核心逻辑：输出是「永久笔记的组合与涌现」，依托卢曼卡片网络，结合费曼输出原则，不从零创作，高效产出高质量内容（文章、书稿、分享等）。

一、核心输出方法论（6个，适配卡片盒体系）

1. 卡片组合法（卢曼核心）：从永久笔记筛选3-10张关联永久笔记，按逻辑串联（无需额外创作），核心是“用已有卡片搭框架”，避免从零开始。串联逻辑可按“观点→论据→案例”或“问题→解决方案→延伸”，贴合PREP/5W2H逻辑。

2. 费曼三次复述落地法：对应输出全流程——①第一次复述（文献笔记）→ 积累素材；②第二次复述（永久笔记）→ 打磨核心观点；③第三次复述（输出成品）→ 解释/解决/预测问题，实现知识涌现，确保输出有深度、无漏洞。

3. 主题聚焦法：输出前明确1个核心主题（不贪多），所有内容围绕主题展开，筛选卡片时只保留与主题强相关的，避免内容杂乱。可参考“黄金圈法则”（Why-How-What）搭建输出框架，让逻辑更清晰。

4. 双向链接闭环法：输出成品中，标注所用永久笔记（[[卡片名]]）；同时在每张被用到的永久笔记中，添加“相关输出：[[输出标题]]”，形成“永久笔记→输出→新卡片”的闭环，反哺知识库。

5. 批判性输出法：输出时不堆砌卡片内容，加入个人判断、反证或延伸思考（对应文献笔记/永久笔记的反思部分），避免单纯复制卡片，让输出有个人特色和深度，贴合RISE法的“评估”核心。

6. 极简迭代法：先完成“最小可行输出”（如一篇短文、一个观点总结），再基于反馈（自我回顾、他人建议），补充新的关联卡片、完善逻辑，逐步迭代为完整成品（如书稿、系列文章），降低输出门槛。

二、输出注意事项

- 输出不属于文献笔记/永久笔记，放回中期笔记，命名格式：「输出类型-标题」（如：文章-费曼与卢曼学习法结合实操）。

- 输出过程中产生的新想法、新观点，立即拆分为原子化永久笔记，存入永久笔记，实现“输出反哺知识库”。

- 避免“为输出而输出”，所有输出需依托卡片盒已有内容，不脱离自身知识体系，确保输出有依据、可复用。

## 何时生成卡片

核心结论（极简好记）：**不是所有文献都要做文献笔记，也不是所有文献笔记都要做永久笔记**，核心看“价值”和“可转化性”。

一、文献是否生成文献笔记？

核心判断标准：**该文献是否有“可提炼的价值”** ，无价值文献可直接跳过，避免知识库臃肿。
1.  建议做文献笔记的文献（有价值，优先处理）
    - 与自身知识体系、学习/研究目标强相关的（如费曼、卢曼相关书籍/论文）；
    - 包含新观点、新方法、新论据，能补充现有知识库的；
    - 需长期溯源、后续可能转化为永久笔记的（如专业教材、核心论文）。
2.  无需做文献笔记的文献（无价值，直接跳过）
    - 内容与自身需求无关、无新信息（如无关领域的零散文章）；
    - 观点浅显、无深度，无法提炼核心要点（如简单科普短文）；
    - 重复内容（如已做过笔记的同主题文献，仅补充新观点即可）。

二、文献笔记是否生成永久笔记？

核心判断标准：**文献笔记中的内容是否能转化为“个人原创观点”** ，无法转化则无需生成，避免永久笔记冗余。
1.  建议转化为永久笔记的文献笔记（可转化，重点处理）
    - 文献中的核心观点，能结合自身理解，用自己的话复述、形成个人见解的；
    - 可关联现有永久笔记，补充知识网络、填补认知缺口的；
    - 能用于后续输出（文章、分享等），具备可复用性的（如费曼三次复述相关的核心方法）。
2.  无需转化为永久笔记的文献笔记（不可转化，仅留存溯源）
    - 纯事实性、数据性内容（无个人思考空间，如单纯的统计数据、名词定义）；
    - 观点与现有永久笔记完全重复，无补充价值的；
    - 仅需短期溯源，后续无需复用、无需关联的（如临时查阅的零散资料）。

三、补充原则

1.  文献笔记：“少而精”，只记录有价值的核心，不贪多、不堆砌，留存极简溯源版即可；
2.  永久笔记：“精而准”，只转化有个人思考、可复用、可关联的内容，坚守“1张1个想法”的原子化原则；
3.  高效取舍：与其做10篇无价值的笔记，不如做1篇高质量的可转化笔记，避免无效内耗，贴合“伤其十指不如断其一指”的核心逻辑。


## 如何形成反馈

回忆：在生成新笔记前，从现有卡片中召回(通过向量检索和图谱检索)相关卡片。

内部成长：用新知识更新回忆(召回的卡片)或创建新卡片。

边用边改，在生成文献笔记和永久笔记时，从记忆里召回相关卡片：
1. 内容重复的文献不生成新的文献笔记，修改优化现有文献笔记
2. 相同的原子观点不生成新的永久笔记，优化现有永久笔记
3. 在生成新文献笔记或永久笔记过程中，对于召回的卡片做优化或纠错

目标是让文献笔记越来越准确和永久笔记持续生长。

**一、文献笔记（Literature Note）**

✅ 可修改场景

- 优化tags：补充、调整标签，提升检索效率
- 完善来源信息：补充/修正作者、文献名、页码、链接等
- 调整关联链接：新增/删除related中的[[关联笔记]]，衔接知识库
- 纠错优化：修正错别字、语句不通顺的地方，优化总结性描述（不改变原文核心）
- 补充极简论据：遗漏的核心论据，极简补充（不堆砌细节）

❌ 禁止/不建议修改场景

- 不做大篇幅扩充，避免变成“小作文”，违背文献笔记精简原则
- 不追加个人新思考、原创观点（新思考需新建永久笔记）
- 不修改为原文摘抄（保持“自己话总结”的核心，不回归抄书）

**修改核心原则**

忠实于原文核心，以“优化、纠错、补全”为主，不改变文献本身观点，不承载个人原创思考，保持精简、可溯源。

**二、永久笔记（Permanent Note）**

✅ 可修改场景

- 优化tags：新增/调整标签，贴合知识体系迭代
- 补充关联链接：持续新增related中的[[关联笔记]]，完善知识网络
- 迭代内容：补充新理解、修正之前的认知偏差、优化表达（更简洁、更费曼化）
- 完善细节：补充支撑理由、案例，或补充边界/反思部分的内容
- 优化可复用引用：让句子更适配后续输出（文章、分享等）

❌ 禁止/不建议修改场景

- 不把一张原子化笔记，改成多个无关观点（违背“1张1个想法”原则）
- 不修改为原文摘抄，保持“个人原创观点+自己话表达”的核心
- 不做颠覆性修改（重大新观点，建议新建笔记+双向链接，而非覆盖原笔记）

**修改核心原则**

以“持续生长、迭代优化”为主，可不断完善、补充，贴合个人认知提升；坚守原子化、观点化、可复用，新增重大思考优先新建笔记，不破坏原有卡片逻辑。

**三、通用修改提醒**

1.  两者均可修改，但分工不同：文献笔记“小修补、不生长”，永久笔记“可生长、不杂乱”；
2.  所有修改均围绕“服务知识库、提升复用性”，不做无意义调整；
3.  新思考、新延伸，优先新建永久笔记，再通过双向链接关联原有笔记，避免单一笔记臃肿。
