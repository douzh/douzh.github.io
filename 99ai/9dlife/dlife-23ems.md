# 外部记忆系统（External Memory System, EMS）

记忆即生命，如果能从记恢复出“自我的认知（我是谁、我从哪里来）”、“自我灵魂(命经、混沌经、干经、三观等)”、“自我记忆（我所有的经历）”，再装载到一个有觉知和身体，那是不是就是复活了一个我，因为从外部无法分辨多个我的区别。

人类的记忆系统有遗忘机制，践行混沌经需要支持向量+图的外部记忆系统来支持，这里借鉴《卡片笔记写作法》来构建EMS的方案。

笔记即记忆：做笔记和整理知识库核心流程：
1. 外部来源数据：外部的会话、收集的文章、收集的书、外部传感器收到的数、其他所有外部的数据来源；
2. 临时笔记(闪念笔记)：对应解混沌中的收集过程，所有外部来源数据简单收集到临时笔记中，可以参考GTD方法论；
3. 中期笔记：临时笔记中经过分类清洗后的数据，用于真正阅读和理解形成文献笔记；自己第一次输出的文章、日记和书，如每日总结、成长日记、觉醒日记等，要走一次总结流程再放到归档；
4. 文献笔记：文献笔记类似于读书笔记或总结，是中期笔记经总结后的核心观点（**禁止原文照抄**），用自己的话总结+标注来源，仅记录“你认为有价值”的内容形成文献笔记，可以参考“如何总结文献笔记”章节；
5. 永久笔记：分析理解文献笔记按一个文件为一个想法的原则拆分为卡片，再经过归纳、推理生成卡片的关联关系，形成图结构笔记，可以参考“如何总结永久笔记”章节；
6. 输出：写文章、日记、书形成自己的输出，先放到中期笔记，至少经过一轮提炼反馈看是否二次形成永久笔记，形成正反馈循环。可以参考“如何输出”章节；
7. 知识库：类似于书架，生成文献记忆用到的文章、书箱等原文，会被文献记忆引用，在整理完文献记忆后放入归档

EMS系统总结：临时笔记是收纳箱，中期笔记是学习资料，文献笔记是学习总结，知识库为资料归档，永久笔记才是真正的核心网状记忆，通过输出形成网状记忆的反馈循环(解混沌)。


## EMS架构

EMS以卡片为基本单元存储文献笔记和永久笔记，每个卡片都对应一个 Markdown 文件，文件名即为卡片的 ID。

### EMS目录

```
ems/
├─ 0temp/      # 临时笔记，收集
├─ 1mid/       # 中期笔记，清洗分类，准备阅读；输出
├─ 2doc/       # 文献笔记，归纳总结，阅读笔记
├─ 3permanent/ # 永久笔记，推理演绎，网状记忆（一个文件为一个独立想法）
├─ 4output/    # 输出笔记，总结反馈，定期阅读总结
├─ 4kb/        # 知识库
└─ assets/     # 图片、附件
```


### 长期记忆卡片内容格式规范

写作规范

- 一个文件 = 一个想法（原子化，书中核心规则）
- 用 [[文件名]] 做双向链接
- 用 #标签 做弱分类
- 永久笔记文件名：关键词-唯一标识.md

每个 Markdown 文件即一张“永久卡片”，遵循以下结构：

```markdown
---
id: card-20260409-001
title: 混沌经核心心法
tags: [命记, 学习方法, 知识涌现]
created: 2026-04-08 23:59:59
updated: 2026-04-09 23:59:59
source: [[关联的文献笔记名]]
---

# 卡片内容

这里是卡片的正文，记录一个原子化的知识点或洞见。

## 关联链接
[[相关永久笔记1]]
[[相关永久笔记2]]
...
```

- **Front Matter**: 存储元数据（ID、标题、标签、时间戳、链接关系）。
- **Body**: 纯文本内容，作为向量嵌入的源。
- **链接语法**: 使用 `[[id]]` 显式标记卡片间的逻辑关联。

## 参考：卡片笔记写作法


《How to Take Smart Notes》（《卡片笔记写作法》）全面介绍

**核心速览**：本书由德国学者**Sönke Ahrens**（申克·阿伦斯）撰写，核心是**卢曼卡片盒笔记法（Zettelkasten）**，颠覆“先列大纲→找资料→写作”的线性模式，主张**自下而上**的知识建构，让笔记自动生长，助力高效学习与创作。

**基本信息**

| 项目 | 详情 |
| :--- | :--- |
| **英文书名** | How to Take Smart Notes: One Simple Technique to Boost Writing, Learning and Thinking  |
| **中文译名** | 卡片笔记写作法（人民邮电出版社） |
| **作者** | Sönke Ahrens（申克·阿伦斯），德国教育哲学讲师，学者兼作家 |
| **出版时间** | 2017年（英文原版）；2021年（中文版） |
| **核心定位** | 面向学生、学者、非虚构作家的**知识管理与高效创作指南** |
| **核心灵感** | 社会学家Niklas Luhmann（尼科拉斯·卢曼）的**9万张卡片成就58本书**的传奇方法 |

**核心颠覆：笔记的本质重构**

传统笔记是**被动收集**的存储工具，本书主张笔记是**主动创造**的思考载体：
1. 笔记不是“抄书”，而是**用自己的话重构理解**
2. 笔记不是“孤立存储”，而是**建立连接，形成知识网络**
3. 笔记不是“任务导向”，而是**复利式积累，自动催生新观点**

**三大核心笔记类型**

这是本书的方法论核心，三类笔记分工明确、层层递进：

| 笔记类型 | 英文名称 | 核心作用 | 关键规则 |
| :--- | :--- | :--- | :--- |
| **闪念笔记** | Fleeting Notes | 捕捉即时想法、灵感、待办 | 无需结构化，**24小时内处理**，可快速丢弃 |
| **文献笔记** | Literature Notes | 记录阅读内容的核心观点 | **禁止原文照抄**，用自己的话总结+标注来源；仅记录“你认为有价值”的内容 |
| **永久笔记** | Permanent Notes | 沉淀个人洞见，构建知识网络 | 独立成篇、完整表达；**添加双向链接**，与其他笔记关联；永不丢弃，形成可复用的知识库 |

**四大核心原则（底层逻辑）**

1. **连接优于分类**：文件夹会形成信息孤岛，**双向链接**才能让知识交叉生长，产生新创意
2. **主动创造优于被动接收**：笔记的价值在于**你的思考与重构**，而非内容的原始性
3. **原子化表达**：每张卡片只承载**一个完整想法**，便于独立检索与连接
4. **系统优先于工具**：卡片盒的核心是**方法与思维**，而非纸质卡片或特定软件


**核心流程（六步法）**

1. **捕捉**：用闪念笔记快速记录灵感与阅读要点
2. **处理**：24小时内将闪念笔记转化为文献笔记（用自己的话复述）
3. **提炼**：将文献笔记升华为永久笔记，**独立成篇**并添加链接
4. **连接**：主动为永久笔记寻找关联，构建知识网络
5. **存储**：将笔记放入卡片盒（数字或物理），按链接而非分类管理
6. **创作**：写作时从卡片盒中提取已有内容，**自动生成大纲与论据**，无需从零开始

**适用人群**

- 学生：课堂笔记、文献阅读、论文写作
- 学者/研究人员：学术创作、知识体系构建
- 职场人士：会议记录、项目管理、内容创作
- 创作者：非虚构写作、灵感管理

**核心价值**

1. **解放认知**：无需反复查找资料，专注思考与创作
2. **复利效应**：每一张笔记都成为未来创作的**资产**，越用越有价值
3. **高效输出**：30年写58本书的卢曼证明，**每天6张卡片**即可实现高产
4. **终身学习**：构建个人知识网络，实现持续成长

## 参考：如何总结文献笔记

**一、最通用、最万能的：5W2H**

适合：任何文章、报告、事件、观点类文献
```
What  发生了什么？核心观点是什么？
Why   为什么这么说？理由/证据？
Who   谁提出的？立场是什么？
When  时间/前提/适用场景？
Where 边界、范围、领域？
How   怎么做到/怎么推导？
How much 程度、量化、代价、效果？
```
做完直接生成**一句话文献笔记**，非常稳。

**二、最强阅读总结法：SQ3R（学术阅读神器）**

适合：书籍、论文、长内容
```
Survey     浏览：标题、大纲、首尾、图表
Question   提问：我想解决什么问题？
Read       精读：抓论点，不抄细节
Recite     复述：用自己话讲一遍（费曼第一步）
Review     回顾：查漏、补反证、关联旧知识
```
完全就是你费曼三步复述的**前置流程**。

**三、最适合做卡片笔记：费曼四要素**

你自己笔记里也提到了，直接用：
```
Concept   概念是什么？
Teach     能讲给别人听吗？
Review    哪里卡壳？
Simplify  能不能简化到1-2句话？
```
这是**文献笔记 → 永久笔记**的黄金转化器。

**四、最适合结构化知识：PREP 模型**

适合：观点类、论证类文章
```
Point     结论/观点
Reason    理由
Example   证据/案例
Point     重述结论（简化版）
```
做完就是一张**标准永久卡片**。

**五、最适合深度理解：RISE 模型**

适合：需要真正吃透、不浮于表面的内容
```
Read    阅读
Identify 识别核心论点
Summarize 总结（自己话）
Evaluate 评价、批判、找反证
```
最后一步 Evaluate 直接产出**高质量卡片**。

**六、最适合逻辑类内容：逻辑三角**

适合：论文、思辨类内容
```
论点 Claim
论据 Evidence
推理 Reasoning
```
抓这三样，文献笔记不会乱。

**七、最适合“抓重点”：黄金圈法则**

适合：方法论、工具、学习类书籍
```
Why   目的、动机
How   方法、步骤
What  现象、结果、内容
```
从内向外理解，最容易做**简化版笔记**。

**八、最适合做知识关联：KWL 法**

适合：建立卡片之间链接
```
Know     已经知道什么
Want     想知道什么
Learned  学到了什么（可直接做卡片）
```
天然对接卢曼卡片盒的**链接思维**。

**九、最适合快速提炼：3段式总结法（极简万能）**

任何文章都能用，30 秒出文献笔记：
```
1. 作者想表达什么？（核心）
2. 怎么证明？（论据）
3. 对我有什么用？（关联&思考）
```
第三条直接帮你**连接到已有卡片**。

**十、我帮你浓缩成「终极文献笔记公式」**

你以后读任何东西，只用这一套就够：
```
【核心观点】1句话
【论据/证据】2-3条
【逻辑/方法】How 或 5W2H
【评价/反思】好在哪、缺什么、反证
【关联卡片】[[旧笔记]]
【可输出观点】1个新想法（做成永久卡片）
```

**如果你要一句话记住**

**5W2H 抓结构，PREP 抓观点，SQ3R 抓阅读，费曼抓复述，最终全部变成卢曼卡片。**

**文献笔记模板：**

```
---

tags: #文献笔记 #待分类（替换为实际标签，如#阅读笔记 #学术文献）

author: 作者名

source: 文献来源（书籍/文章名+页码/链接，如：《How to Take Smart Notes》P28）

related: [[关联永久笔记]]、[[关联文献笔记]]（可选，便于后续链接）


---

标题（格式：文献名-核心主题，如：《费曼学习法》-以教代学核心逻辑）

【核心观点】（用自己的话总结文献核心，1-2句话，不抄原文，可结合5W2H/PREP提炼）

【关键论据】（2-3条核心论据/案例，极简提炼，不堆砌细节）

【个人理解】（自己的初步思考，不冗余，为后续转化为永久笔记铺垫）

【可转化点】（可提炼为永久笔记的1-2个核心想法，明确后续转化方向）

【备注】（可选，记录文献漏洞、疑问或补充说明，体现批判性阅读）
```

## 参考：如何总结永久笔记

下面给你一份**专门用于「永久笔记」提炼与撰写的方法论清单**，完全贴合《How to Take Smart Notes》+ 费曼 + 卡片盒逻辑，简洁列表版：

1. **原子化原则**
   一张笔记只写**一个完整想法**，不堆砌、不混杂，便于链接与复用。

2. **自述法（费曼式简化）**
   用自己的话重述，不用原文摘抄；能用外行听懂的语言表达，才算真正理解。

3. **观点化写作**
   不做概括，要做**观点输出**：明确表达“我认为”“这意味着”“由此可推出”。

4. **关联法（卢曼核心）**
   必须思考：它和哪些旧笔记相关？强制添加双向链接，形成知识网络。

5. **结论前置法**
   开头直接写核心结论，后面只写支撑理由，让卡片独立可读、可检索。

6. **PREP 卡片法**
   Point（观点）→ Reason（理由）→ Example（案例/证据）→ Point（重申），结构极强。

7. **因果—边界法**
   写清：
   - 因什么成立
   - 适用条件
   - 边界/例外/反例
   避免绝对化、模糊化卡片。

8. **批判性提炼法**
   不只记录“作者说了什么”，更写：
   - 漏洞
   - 质疑
   - 可改进之处
   让笔记带有思考深度。

9. **问题驱动法**
   每张卡片以**回答一个问题**为目标，问题即主题，答案即内容，清晰聚焦。

10. **最小可用信息法**
    只保留理解该想法必需的信息，剔除冗余例子、背景、过程，追求极致精简。

11. **可复用表达法**
    写成未来能直接引用到文章、演讲、方案里的句子，让卡片成为“知识积木”。

12. **涌现导向法**
    刻意留白思考：
    这个观点能和什么组合？
    能推出什么新结论？
    直接把“新想法”写成新卡片。

总结：

压缩为6条核心，精准贴合卢曼+费曼逻辑，极简好记，直接落地：
1.  原子化：1张笔记=1个完整想法，不堆砌、不混杂
2.  自述化：用自己的话简化表达，外行能听懂（费曼核心）
3.  观点化：不做概括，明确输出个人思考，不抄原文
4.  关联化：强制加双向链接，融入知识网络（卢曼核心）
5.  精简化：结论前置，只留核心信息，剔除冗余
6.  可复用：写成可直接引用的表达，兼顾批判性与涌现性

模板：

```
---

tags: #待分类 #关联标签（替换为实际标签，如#知识管理 #费曼学习法）

source: [[关联文献笔记名]]（无则删除）

related: [[关联永久笔记1]]、[[关联永久笔记2]]（强制添加，最少1个）

---

标题（1个核心观点，简洁明确，如：费曼第二次复述是永久笔记的核心方法）

【核心结论】（直接写核心观点，1句话，结论前置，用自己的话表达，不抄原文）

【支撑理由】（1-2条即可，极简，不冗余，可加简单案例/论据）

【边界/反思】（可选，写适用场景、漏洞或质疑，体现批判性）

【可复用引用】（1句话，可直接复制到文章/输出内容中，体现可复用性）

【涌现思考】（可选，写该观点可延伸的新想法，或可关联的其他方向）

```

## 参考：如何输出

输出核心方法论

核心逻辑：输出是「永久笔记的组合与涌现」，依托卢曼卡片网络，结合费曼输出原则，不从零创作，高效产出高质量内容（文章、书稿、分享等）。

一、核心输出方法论（6个，适配卡片盒体系）

1. 卡片组合法（卢曼核心）：从永久笔记筛选3-10张关联永久笔记，按逻辑串联（无需额外创作），核心是“用已有卡片搭框架”，避免从零开始。串联逻辑可按“观点→论据→案例”或“问题→解决方案→延伸”，贴合PREP/5W2H逻辑。

2. 费曼三次复述落地法：对应输出全流程——①第一次复述（文献笔记）→ 积累素材；②第二次复述（永久笔记）→ 打磨核心观点；③第三次复述（输出成品）→ 解释/解决/预测问题，实现知识涌现，确保输出有深度、无漏洞。

3. 主题聚焦法：输出前明确1个核心主题（不贪多），所有内容围绕主题展开，筛选卡片时只保留与主题强相关的，避免内容杂乱。可参考“黄金圈法则”（Why-How-What）搭建输出框架，让逻辑更清晰。

4. 双向链接闭环法：输出成品中，标注所用永久笔记（[[卡片名]]）；同时在每张被用到的永久笔记中，添加“相关输出：[[输出标题]]”，形成“永久笔记→输出→新卡片”的闭环，反哺知识库。

5. 批判性输出法：输出时不堆砌卡片内容，加入个人判断、反证或延伸思考（对应文献笔记/永久笔记的反思部分），避免单纯复制卡片，让输出有个人特色和深度，贴合RISE法的“评估”核心。

6. 极简迭代法：先完成“最小可行输出”（如一篇短文、一个观点总结），再基于反馈（自我回顾、他人建议），补充新的关联卡片、完善逻辑，逐步迭代为完整成品（如书稿、系列文章），降低输出门槛。

二、输出注意事项

- 输出不属于文献笔记/永久笔记，放回中期笔记，命名格式：「输出类型-标题」（如：文章-费曼与卢曼学习法结合实操）。

- 输出过程中产生的新想法、新观点，立即拆分为原子化永久笔记，存入永久笔记，实现“输出反哺知识库”。

- 避免“为输出而输出”，所有输出需依托卡片盒已有内容，不脱离自身知识体系，确保输出有依据、可复用。


## 参考：文献笔记的处理

结合《How to Take Smart Notes》的核心逻辑，结论非常明确：

**文献/文档笔记不需要完整长期保存，只需要保留「极简溯源版」；真正要永久保存的，是你提炼后的永久笔记。**

一、书中的核心原则：文献笔记只是「过渡工具」，不是资产

作者Sönke Ahrens和卢曼卡片盒法的核心观点：
1. **文献笔记的使命，是帮你转化出「永久笔记」**
   它是**从原文→个人思考**的中间步骤，任务完成后，它的价值就大幅降低了。
2. **你的核心资产只有「永久笔记」**
   永久笔记是你用自己的话重构的、独立的、可连接的知识卡片，这才是能复利增长的东西。
3. 卢曼本人也**不会保存大量原文文献**，只保留极简引用和索引。

二、实操标准：文档笔记到底留什么、删什么

**1. 必须删掉/不保存的**

- 原文大段复制、截图、完整PDF/文档全文
- 无意义的摘抄、流水账式的笔记
- 处理完永久笔记后，冗余的草稿版文献笔记

**2. 只需要极简保存的**

- 文献核心观点（用你自己的话）
- 来源信息（书名/链接/作者/页码）
- 1-2句关键论据，用于后续溯源核对

**3. 绝对要永久保存的**

- **所有永久笔记**
  这是你知识库的全部价值，一张都不能删。

三、最佳做法

1. **原始文档处理**
   读完、提炼完后，**原版PDF/网页/文档可以直接删除**，或丢到冷存储文件夹（不进核心知识库），不用留在Markdown库中占空间。

2. **Markdown文献笔记：只留精简版**
   让AI智能体帮你把长篇文献笔记压缩成极简版，示例：
   ```markdown
   # 复利效应-文献极简笔记
   来源：《财务自由第一课》P35
   核心：知识复利=持续积累微小认知+高频连接，而非单次大量输入
   关联：[[卡片盒笔记-复利增长机制]]
   ```
   这种极简版**可以一直保存**，体积极小、方便溯源，不臃肿。

3. **永久笔记：完整永久保存**
   永久笔记是你的独立思考，是写作、输出的原材料，**必须永久存档，永不删除**。

四、一句话总结规则

**原始文档可归档或删除，精简文献笔记留痕即可，永久笔记永久保存。**

文献笔记的存在意义，只是为了让你记得「这个想法从哪来」，而不是为了存资料；你的知识库，存的是**你的思考**，不是别人的文字。

## 参考：输出和文献的关系

**一、明确结论**

**你创新输出的文章、书稿 ≠ 文献笔记** 它们属于：**最终输出成果（Output）** 既不是文献笔记，也不是永久笔记。

**二、三者清晰边界（一句话分清）**

1. **文献笔记 Literature Note**
   来源：别人写的书/文章/观点
   作用：记录你从外部学到了什么
   命运：可以精简保存，不必太臃肿

2. **永久笔记 Permanent Note**
   来源：你自己的理解、思考、观点
   作用：构成你的知识网络、知识库
   命运：永久保存、不断链接

3. **输出文章 / 书稿 Output**
   来源：从你的永久笔记里“长”出来的
   作用：对外表达、系统化阐述、传播
   命运：最终成品，独立存放

**三、那文章/书稿在你的体系里怎么放？**

按你自己的文件夹结构：
```
00_Inbox       闪念、临时
01_Literature  文献笔记（别人的东西）
02_Permanent   永久笔记（你的思考颗粒）
03_Output      文章、课程、书稿、回答、作品
```

**你的文章、书 → 全部放进 03_Output**

**四、关键问题：文章和卡片之间怎么关联？**

一篇文章是**一堆永久笔记的组合**，不是一张卡片。

处理方式非常简单：

1）文章内部

在文章末尾或开头加一行：
> 本文基于以下永久笔记形成：
> - [[卡片A]]
> - [[卡片B]]
> - [[卡片C]]

2）每张被用到的永久笔记里

加一行反向链接：
> 相关输出：[[这篇文章的标题]]

这样就形成了：**永久笔记 ←→ 输出文章** 的双向引用

**五、那文章写完后，还要不要提炼新卡片？**

**要！而且非常重要。**

因为写作过程中你会产生**新观点、新论证、新洞见**。

流程：
1. 写文章 → 产生新想法
2. 把新想法拆成**原子化卡片**
3. 存入 02_Permanent
4. 给新卡片加链接

这就是你说的：**费曼第三次复述 → 知识涌现 → 反哺卡片盒**卡片盒因此越来越强，形成复利。

**六、最精简总结（你可以直接记）**

- **看别人的书** → 做 **文献笔记**
- **消化成自己的观点** → 做 **永久笔记**
- **把笔记拼成文章/书** → 放入 **Output**
- **写作中产生新想法** → 再生成 **新永久笔记**

一句话：
**文献笔记是原料，永久笔记是零件，文章/书是成品。**
