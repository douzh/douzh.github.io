# 因果模型

## 一、模型定义与核心机制

### 1.1 核心定义

> **因果模型是用显式的因果结构(有向图 + 结构方程)表征世界"什么导致什么"的智慧模型。它超越相关性,支持干预推理(do-操作)、反事实推理("如果当时...会怎样"),是高级智慧的核心能力。**

### 1.2 核心机制

| 机制 | 说明 |
| --- | --- |
| 因果图 | 用有向无环图(DAG)表示因果关系 |
| 结构方程 | 用方程描述变量间的因果机制 |
| 干预推理 | do(X=x) 操作,预测干预后果 |
| 反事实推理 | 推理"如果当时做了不同选择会怎样" |
| 因果发现 | 从数据中学习因果结构 |

### 1.3 与其他模型的区别

| 维度 | 因果模型 | 概率模型 | 隐式模型 |
| --- | --- | --- | --- |
| 关系类型 | 因果(有向) | 相关(可能无向) | 相关(隐式) |
| 干预推理 | ✅ do-calculus | ❌ | ❌ |
| 反事实 | ✅ | ❌ | ❌ |
| 可解释性 | 强 | 中 | 弱 |
| 结构来源 | 人工 + 发现 | 人工设计 | 自动学习 |

**关键区别**:
- 相关性:$P(Y | X)$ —— 观察 X 时 Y 的概率
- 干预:$P(Y | do(X))$ —— 强制设 X 时 Y 的概率
- 反事实:$P(Y_{X=x} | X=x', Y=y')$ —— 若当时做了 x 而非 x',Y 会怎样

## 二、数学/结构形式

### 2.1 因果图(DAG)

```
    吸烟 ──► 肺癌
      │
      ▼
    黄牙
```

- **吸烟 → 肺癌**:因果
- **吸烟 → 黄牙**:因果
- **黄牙 ← 吸烟 → 肺癌**:黄牙与肺癌相关,但黄牙不导致肺癌

### 2.2 do-calculus(Pearl)

**观察**:
$$P(Y | X = x)$$

**干预**:
$$P(Y | do(X = x))$$

**后门调整**:
若 Z 是 X→Y 的后门路径,则:
$$P(Y | do(X = x)) = \sum_z P(Y | X = x, Z = z) P(Z = z)$$

**前门调整**:
若有中介变量 M:
$$P(Y | do(X = x)) = \sum_m P(M = m | X = x) \sum_{x'} P(Y | X = x', M = m) P(X = x')$$

### 2.3 结构因果模型(SCM)

**结构方程**:

$$X = f_X(U_X)$$
$$Y = f_Y(X, U_Y)$$
$$Z = f_Z(X, Y, U_Z)$$

其中 $U$ 是外生噪声。

**反事实**:
$$Y_{X=x}(u) = f_Y(x, U_Y(u))$$

含义:在现实 $u$ 中 X 取 $x'$,但"如果"X 取 $x$,Y 会是 $f_Y(x, U_Y(u))$。

### 2.4 潜在结果框架(Rubin)

**潜在结果**:$Y_i(1), Y_i(0)$ —— 个体 i 在接受/不接受处理的潜在结果。

**处理效应**:
- 个体:$Y_i(1) - Y_i(0)$
- 平均(ATE):$E[Y(1) - Y(0)]$
- 受处理者(ATT):$E[Y(1) - Y(0) | T = 1]$

## 四、优势与局限

### 4.1 优势

| 优势 | 说明 |
| --- | --- |
| 干预推理 | 预测"做 X 会怎样" |
| 反事实推理 | 评估"如果当时...会怎样" |
| 区分因果与相关 | 避免混淆与伪相关 |
| 可解释 | 因果图直观 |
| 支持决策 | 为行动提供依据 |
| 可迁移 | 因果机制跨环境稳定 |

### 4.2 局限

| 局限 | 说明 |
| --- | --- |
| 结构获取难 | 因果结构通常未知 |
| 未观测混淆 | 隐藏变量破坏因果推断 |
| 非线性困难 | 非线性因果建模复杂 |
| 时间动态 | 动态因果建模困难 |
| 反事实不可观测 | 无法直接验证反事实 |

## 五、在智慧等级中的定位

| 等级 | 因果模型的角色 |
| --- | --- |
| 6.0-6.1 | 无 |
| 6.2 本能模型 | 动物的简单因果(撞到会痛) |
| 6.3 中级模型 | 动物的工具因果(用工具达成目标) |
| 6.4 高级模型 | 人类的科学因果(实验、RCT) |
| 6.5 超越性模型 | 因果 AI、反事实推理系统 |

**关键洞察**:
- 因果理解是**人类智慧与动物智慧的分水岭**之一。
- 动物有简单因果(工具使用),但无系统化因果推理。
- 人类智慧 = 隐式神经模型 + 外部符号模型 + **因果模型**(科学方法的核心)。
- 因果 AI 是当前前沿方向,旨在让 AI 超越相关性,理解因果。

## 六、边界案例辨析

### 6.1 动物的工具使用算不算因果模型?

| 特征 | 是否具备 |
| --- | --- |
| 因果理解 | ✅ 简单的(用树枝够到食物) |
| 干预推理 | ⚠️ 隐式,非显式 |
| 反事实 | ❌ 无 |
| 可迁移 | ⚠️ 有限 |

**判定**:**隐式因果模型**。动物有简单因果理解,但非显式、系统化,属于因果模型的初级形式。

### 6.2 科学实验算不算因果模型?

| 特征 | 是否具备 |
| --- | --- |
| 因果结构 | ✅ 显式假设 |
| 干涉推理 | ✅ RCT、对照实验 |
| 反事实 | ✅ 思想实验 |
| 可迁移 | ✅ 物理定律普适 |

**判定**:**人类的高级因果模型**。科学方法是因果推理的系统化,是因果模型的最高实现。

### 6.3 大语言模型有因果理解吗?

| 特征 | 是否具备 |
| --- | --- |
| 相关性 | ✅ 强 |
| 因果结构 | ⚠️ 隐式,弱 |
| 干预推理 | ❌ 弱 |
| 反事实 | ⚠️ 文本层面,非真正理解 |

**判定**:**相关性强大,因果理解薄弱**。这是当前 LLM 的核心局限,也是因果 AI 的研究方向。

## 七、与其他模型的关系

### 7.1 可与哪些模型混合

| 混合对象 | 混合方式 | 示例 |
| --- | --- | --- |
| 隐式模型 | 神经因果发现、因果表示学习 | 从数据学因果结构 |
| 符号模型 | 因果逻辑编程 | 因果 + 逻辑推理 |
| 概率模型 | 因果贝叶斯网络 | do-calculus |
| 物理模型 | 物理机理因果 | 物理方程的因果解释 |

### 7.2 因果模型的独特地位

因果模型是**唯一支持干预与反事实推理**的模型形式,这使它成为:

- **科学方法的核心**:实验、假设检验
- **决策智能的基石**:为行动提供因果依据
- **AI 的下一前沿**:从相关 AI 到因果 AI
- **人类智慧的标志**:区分人类与动物智慧

## 八、演化逻辑

因果模型的出现与生命演化一致:

1. **本能因果**:动物的本能反应(前因果)
2. **工具因果**:动物使用工具(简单因果)
3. **直觉因果**:人类的直觉因果(前科学)
4. **亚里士多德因果**:初步系统化(目的论)
5. **伽利略-牛顿**:实验因果(现代科学)
6. **统计学因果**:相关 ≠ 因果的辨析
7. **Pearl 因果**:do-calculus、反事实
8. **因果 AI**:从数据中学习因果

每一层都让生命在**理解世界、干预世界**方面更有效,与 [生命定义](life.md) 和 [智慧定义](20wisdom.md) 一脉相承。

## 九、一句话总结

> **因果模型用显式因果结构(因果图 + 结构方程)表征"什么导致什么",支持干预推理(do-calculus)、反事实推理,是高级智慧的核心能力。它区分因果与相关,是科学方法的基础。Pearl 因果图、结构因果模型、潜在结果框架是其典型代表。动物有简单因果,人类有系统化因果,当前 AI 因果理解薄弱——因果 AI 是超越性智慧的关键方向。**
