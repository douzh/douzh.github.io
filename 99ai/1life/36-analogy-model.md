# 类比/原型模型

## 一、模型定义与核心机制

### 1.1 核心定义

> **类比/原型模型是通过将新情境与已知情境进行相似性映射来表征世界的智慧模型。它不依赖显式规则或方程,而是用典型样例(原型)和跨域映射(类比)来理解新事物、解决问题、进行创造性推理。**

### 1.2 核心机制

| 机制 | 说明 |
| --- | --- |
| 原型表征 | 用典型样例代表一类事物 |
| 相似性匹配 | 将新事物与已知原型比较 |
| 跨域映射 | 将一个域的结构映射到另一个域(类比) |
| 案例检索 | 从记忆中找相似案例 |
| 结构迁移 | 将案例的解决方案迁移到新问题 |

### 1.3 与其他模型的区别

| 维度 | 类比模型 | 隐式模型 | 符号模型 |
| --- | --- | --- | --- |
| 知识形式 | 具体样例 | 分布式权重 | 符号规则 |
| 推理方式 | 相似性映射 | 归纳 | 演绎 |
| 精确度 | 低,灵活 | 中 | 高 |
| 创造性 | ✅ 强 | ⚠️ 中 | ❌ 弱 |
| 可解释 | ⚠️ 中 | ❌ 弱 | ✅ 强 |

## 二、数学/结构形式

### 2.1 原型理论

**原型**:一类事物的"典型代表",用特征向量表示:

$$\vec{p}_c = \frac{1}{|C|} \sum_{x \in C} \vec{x}$$

**分类**:新样本 $\vec{x}$ 归入最近原型:

$$c^* = \arg\min_c d(\vec{x}, \vec{p}_c)$$

### 2.2 类比推理的结构映射理论(Gentner)

**源域** S → **目标域** T

```
源域:太阳系
├── 太阳 ────────► 原子核
├── 行星 ────────► 电子
├── 引力 ────────► 库仑力
└── 轨道运动 ────► 轨道运动

目标域:原子模型
```

**映射规则**:
- 属性映射:对象的属性对应
- 关系映射:对象间的关系对应
- 高阶关系:关系之间的关系对应

### 2.3 案例推理(CBR)

**CBR 循环**:

```
新问题 ──► 检索相似案例 ──► 复用解决方案 ──► 修正 ──► 保存新案例
```

**相似度**:

$$\text{sim}(x, y) = \sum_i w_i \cdot \text{sim}_i(x_i, y_i)$$

### 2.4 度量学习(神经网络类比)

学习一个距离函数:

$$d(x, y) = \|f(x) - f(y)\|$$

其中 $f$ 是神经网络,使相似样本距离小,不相似样本距离大。

## 三、典型实例详表

### 3.1 生物实例

| 实例 | 机制 | 应用 |
| --- | --- | --- |
| **人类类比推理** | 跨域结构映射 | 科学发现(原子-太阳系) |

| **案例记忆** | 情景记忆 | 经验复用 |
| **模式识别** | 视觉原型 | 脸孔识别 |
| **动物迁移学习** | 相似情境迁移 | 新环境适应 |

| 类比 | 源域 → 目标域 | 影响 |

| 图灵:机器 → 思维 | 计算 → 认知 | 认知科学 |

### 3.3 工程实例

| --- | --- | --- |
| **少样本学习** | 度量学习 | 图像分类 |

## 四、优势与局限

### 4.1 优势

| 优势 | 说明 |
| --- | --- |
| 创造性强 | 跨域映射产生新洞见 |
| 灵活 | 不需精确规则 |
| 小样本 | 单个案例即可推理 |
| 可解释 | 类比关系直观 |
| 人类友好 | 符合人类思维习惯 |
| 跨域迁移 | 突破领域边界 |

### 4.2 局限

| 局限 | 说明 |
| --- | --- |
| 不精确 | 类比可能误导(原子-太阳系的局限) |
| 主观性强 | 相似性判断因人而异 |
| 无因果 | 类比不保证因果正确 |
| 难形式化 | 难以用数学严格描述 |
| 依赖记忆 | 需丰富的案例库 |

## 五、在智慧等级中的定位

| 等级 | 类比模型的角色 |
| --- | --- |
| 6.0-6.1 | 无 |
| 6.2 本能模型 | 动物的简单模式匹配 |
| 6.3 中级模型 | 动物的迁移学习 |
| 6.4 高级模型 | 人类的类比推理、科学隐喻 |
| 6.5 超越性模型 | 少样本学习、迁移学习 |

**关键洞察**:
- 类比推理是**人类创造力的核心**。
- 动物有简单迁移学习,但无系统化类比。
- 人类智慧 = 隐式神经模型 + 外部符号模型 + 因果模型 + **类比模型**。
- 科学史上的重大突破常源于类比(太阳系-原子、人工选择-自然选择)。

## 六、边界案例辨析

### 6.1 原型分类算不算智慧模型?

| 特征 | 是否具备 |
| --- | --- |
| 内部状态 | ✅ 原型向量 |
| 世界表征 | ✅ 典型样例 |
| 预测 | ✅ 分类 |
| 学习 | ✅ 原型更新 |
| 类比 | ⚠️ 简单相似性 |

**判定**:**基础类比模型**,有表征与预测,但类比简单,属于类比模型的初级形式。

### 6.2 大语言模型的类比能力

| 特征 | 是否具备 |
| --- | --- |
| 跨域映射 | ✅ 强(训练中学到) |
| 结构迁移 | ✅ 强 |
| 创造性 | ✅ 表面强 |
| 因果正确 | ❌ 不保证 |
| 真正理解 | ⚠️ 争议 |

**判定**:**强大的表面类比能力**,但可能缺乏深层结构理解,容易产生误导性类比。

### 6.3 科学类比算不算智慧模型?

| 特征 | 是否具备 |
| --- | --- |
| 跨域映射 | ✅ 显式 |
| 结构迁移 | ✅ 深层 |
| 创造性 | ✅ 强 |
| 可验证 | ✅ 实验检验 |
| 因果 | ⚠️ 需后续验证 |

**判定**:**高级类比模型**。科学类比是人类智慧的高级形式,但类比本身不保证正确,需实验验证。

## 七、与其他模型的关系

### 7.1 可与哪些模型混合

| 混合对象 | 混合方式 | 示例 |
| --- | --- | --- |
| 隐式模型 | 度量学习、原型网络 | 小样本学习 |
| 符号模型 | 类比逻辑编程 | 结构映射引擎 |
| 因果模型 | 类比因果迁移 | 跨域因果迁移 |
| 概率模型 | 概率类比 | 贝叶斯类比 |

### 7.2 类比模型的独特地位

类比模型是**唯一以创造性为核心**的模型形式,这使它成为:

- **科学发现的引擎**:重大突破常源于类比
- **人类思维的本质**:认知科学认为类比是思维的核心
- **小样本学习的关键**:突破数据饥渴
- **跨域创新的桥梁**:连接不同领域

## 八、演化逻辑

类比模型的出现与生命演化一致:

1. **模式匹配**:动物的简单相似性识别
2. **迁移学习**:动物将经验迁移到新情境
3. **直觉类比**:人类的日常类比("这个像那个")
4. **隐喻语言**:人类用类比构造语言
5. **科学类比**:系统化的跨域映射
6. **类比算法**:CBR、度量学习、原型网络
7. **大模型类比**:LLM 的跨域生成能力

每一层都让生命在**面对新情境、创造新方案**方面更有效,与 [生命定义](life.md) 和 [智慧定义](20wisdom.md) 一脉相承。

## 九、一句话总结

> **类比/原型模型通过将新情境与已知原型/案例进行相似性映射来表征世界,是创造性与跨域迁移的核心机制。原型理论、结构映射理论、案例推理是其典型代表。它是人类科学发现的引擎(太阳系-原子、人工选择-自然选择),也是小样本学习的关键。不精确、无因果保证,但灵活、创造性强的特性,使其成为高级智慧不可或缺的组成部分。**
