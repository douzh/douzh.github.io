# 智能体自动化测试

## 本地OpenClaw

OpenClaw 内置的 browser 工具，它已经内置了 Chrome/Edge/Chromium 的支持

我的请求 → browser 工具 → CDP (Chrome DevTools Protocol) → 浏览器

OpenClaw 内置工具 browser，它是：

✅ 内置工具（不需要安装 skill）
✅ Gateway 的一部分（由 OpenClaw 本身提供）
✅ 直接集成（不需要额外的 CLI Harnesses）


## 服务器环境 (Docker 容器) 

Chromium 浏览器的运行方式

工作原理

```
┌─────────────────────────────────────────────┐
│   服务器 (Debian 12 Docker 容器)             │
│                                             │
│   ┌───────────────────────────────────┐    │
│   │  Xvfb (虚拟帧缓冲区)              │    │
│   │  模拟一个 1280x800 的"显示器"     │    │
│   └──────────────┬────────────────────┘    │
│                  │                          │
│   ┌──────────────▼────────────────────┐    │
│   │  Chromium 浏览器                   │    │
│   │  (由 Playwright 控制)             │    │
│   │  - 访问 iCIMS 系统                │    │
│   │  - 执行自动化测试                 │    │
│   └───────────────────────────────────┘    │
└─────────────────────────────────────────────┘
         ↓ 截图/快照
┌─────────────────────────────────────────────┐
│   您这边收到截图                            │
└─────────────────────────────────────────────┘
```

这套功能的来源分析

| 组件             | 来源              | 安装方式                                  |
| :--------------- | :---------------- | :---------------------------------------- |
| Chromium         | Debian 系统包     | apt install chromium (系统预装)           |
| Xvfb             | Debian 系统包     | apt install xvfb (系统预装)               |
| Playwright       | Python 第三方库   | pip install playwright (工作目录虚拟环境) |
| browser_use 工具 | AI Agent 框架内置 | 这是我（智能体）的内置能力                |

详细情况

```
┌─────────────────────────────────────────────┐
│         服务器环境 (Docker 容器)              │
│                                             │
│  【系统预装部分】                           │
│  ├─ Chromium 145.0.7632.159                 │
│  ├─ Xvfb 2:21.1.7-3+deb12u11                │
│  └─ Python 虚拟环境 (/app/venv)             │
│                                             │
│  【我 (AI 智能体) 的能力】                   │
│  ├─ browser_use 工具 ← 这是框架内置的       │
│  ├─ execute_shell_command 工具              │
│  ├─ read_file / write_file 工具             │
│  ├─ pdf / docx / xlsx / pptx skills         │
│  └─ ... 等其他工具                          │
│                                             │
│  【Python 虚拟环境中的依赖】                 │
│  └─ playwright==1.58.0                      │
└─────────────────────────────────────────────┘
```

总结

- 不是系统自带 - Playwright 是额外安装的 Python 库
- 不是我自带 - browser_use 是我的工具之一，由外部框架提供
- 环境已配置好 - 这个 Docker 容器是为自动化测试专门配置的
- 
简单来说：这是一个专门为 AI Agent 自动化任务准备的服务器环境，所有必要的工具都已经安装配置好了，我只需要使用即可。
