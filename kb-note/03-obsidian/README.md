# Obsidian 档案

[返回总览](../note-soft.md)

- 官网:https://obsidian.md(核心闭源,个人永久免费)
- 定位:完全本地、纯 Markdown、可双向链接、不绑架数据的知识库
- 一句话:**插件生态之王(2000+)——纯 Markdown 文件即数据主权,任何需求都有社区方案**

## 开源情况

| 维度 | 说明 |
| --- | --- |
| 许可证 | ❌ **专有软件(闭源)**——八款中唯一核心不开源 |
| 开放范围 | 仅插件 API、主题 CSS、发布格式开放;编辑器与同步引擎完全闭源 |
| 治理主体 | Dynalist Inc.(商业公司,Obsidian 团队) |
| 商业模式 | 个人使用永久免费(含商用);付费项 = Sync 同步云 / Publish 发布服务 / Catalyst 赞助 |
| 闭源的风险 | 程序随时可变付费、可停止开发;无法审计代码(对隐私敏感者是硬伤) |
| 风险对冲 | **数据是纯 Markdown 文本,闭源不构成数据锁定**——程序消失,文件用任何编辑器都能读;这是"闭源但无锁定"的特殊形态 |

核心理念:
1. Local-first 本地优先:笔记全部是本地 Markdown 文件
2. 核心功能个人永久免费,无需注册账号
3. 高度可扩展,开放插件 API,交给社区扩展能力

## 二、存储方式

**范式:纯文本文件夹**

```
MyVault/                 # 任意位置的"库"文件夹
├── note1.md             # 每篇笔记一个文件
├── folder/note2.md      # 文件夹即目录树
├── attachments/         # 附件(可配置)
└── .obsidian/           # 配置:插件、主题、工作区
```

| 维度 | 说明 |
| --- | --- |
| 存储形态 | 纯 Markdown 文件夹 |
| 数据主权 | ✅ 终极形态,任何文本编辑器可打开,百年可读 |
| Git | ✅ 每次修改可 diff 可回滚 |
| 迁移 | ✅ 零成本(直接就是 MD) |
| 同步 | 自由(Git/Syncthing/任意网盘);官方同步收费 |
| 多库并用 | ✅ 每个文件夹一个库 |
| 大数据量 | ⚠️ 文件多时启动扫描变慢 |
| 一致性 | ⚠️ 并发写/同步冲突需自己处理 |

**优点**:数据永久可读、Git 友好、工具无关、同步自由、文件系统级搜索(ripgrep)可直接用。
**缺点**:海量小文件启动慢;双链等元数据依赖工具索引;附件配置散落。

## 三、链接功能

**评级:L2-L3(双链+块引用成熟;L4 需 Dataview 插件补)**

**原生链接语法**:

| 语法 | 功能 |
| --- | --- |
| `[[页面]]` | 页面双链 |
| `[[页面\|别名]]` | 带别名链接 |
| `[[页面#标题]]` | 链接到标题 |
| `[[页面^块ID]]` | 链接到块 |
| `![[页面]]` / `![[图片]]` | 嵌入(Transclusion) |
| `#标签` / `#嵌套/标签` | 标签 |

**反链面板**:自动列出"链接了本页的页面"及引用上下文,还有**未解析链接**(提到但未创建的页面)——发现知识空白点的利器。

**图谱**:全局 + 局部图谱,节点可过滤/着色(按文件夹/标签),但**不区分关系类型**。

**关键局限**:
- 链接只是正文文本字面量,**链接本身不能带属性**——"鲁迅 --[作者]--> 狂人日记"的语义关系无处安放
- 社区补位:**Dataview 插件**——内联字段(`作者:: [[鲁迅]]`)+ 类 SQL 查询聚合,可模拟三元组,但语法生僻、非原生视图

## 四、MCP 与 AI 接入

**评级:T1 —— 插件生态路线**

| 维度 | 说明 |
| --- | --- |
| 官方 MCP | ❌ |
| 主路径 | Local REST API 插件(本地开 REST 端点,可鉴权)→ mcp-obsidian 等适配器 → AI 客户端 |
| 配置难度 | 中(装 2 个组件 + 配 key/token) |
| 应用内 AI | Smart Connections / Copilot 等插件(支持 Ollama) |
| 旁路方案 | ✅ **文件系统旁路:AI 不经任何 API 直接读写 Markdown 文件** |

**三条路径**:
1. Local REST API 插件 + MCP 适配器(标准 MCP 链路)
2. 应用内 AI 插件(Copilot 等,"AI 进笔记")
3. **文件系统旁路**(最简单):笔记是纯文件,AI 用文件系统工具直接读写——零配置零插件

**优势**:生态最活跃,方案迭代快;纯文件特性让 AI 集成门槛最低。

## 五、便携支持

**评级:数据便携极佳,程序需安装(策略 B)**

| 维度 | 说明 |
| --- | --- |
| 官方便携版 | ❌(社区有绿色包,官方未承诺) |
| 程序 | 安装版(Electron,~200MB) |
| 数据 | ✅ **库 = 任意文件夹**,建库时直接选 U 盘路径 |
| 数据跨机 | ✅ 任何机器"打开文件夹作为库"即识别 |
| 脱离程序可读 | ✅ U 盘纯 Markdown 任何编辑器可开 |
| AI 旁路 | ✅ 无程序也能被 AI 文件读写 |

**方案**:U 盘只放库文件夹;每台机器装一次 Obsidian(或用社区绿色包);即使没装程序,数据本身依然可读可用——抗锁定性五款最强。

## 六、适用场景与总结

| 场景 | 匹配度 |
| --- | --- |
| 插件生态/高度定制 | ⭐⭐⭐⭐⭐ 2000+ 插件 |
| 数据主权/永不锁定 | ⭐⭐⭐⭐⭐ 纯 Markdown |
| Git 版本管理 | ⭐⭐⭐⭐⭐ 文本 diff |
| 长文写作/学术 | ⭐⭐⭐⭐⭐ |
| 移动端 | ⭐⭐⭐⭐ 官方 App |
| AI 全自动改文件(旁路) | ⭐⭐⭐⭐⭐ 零配置 |
| 三元组/知识图谱建模 | ⭐⭐ 链接不带属性,需 Dataview 补 |
| 程序免安装 U 盘一体 | ⭐⭐ 官方仅安装版 |

> **总结:Obsidian 是"插件生态之王"——三个最强:插件生态最强(2000+,任何需求都有社区方案)、数据主权最强(纯 Markdown 文件夹,任何编辑器可读,Git 友好,零迁移成本,百年可读)、AI 集成门槛最低(纯文件特性,存在零配置的"文件系统旁路")。代价:核心功能闭源、官方同步收费、任务/闪卡/数据库等依赖插件拼装、链接本身不带属性(三元组建模弱,需 Dataview 补位)。最适合:重生态定制、重数据主权、重长文写作的用户。**
