# Roam Research 档案

[返回总览](../note-soft.md)

- 官网:https://roamresearch.com(闭源,纯云端订阅制)
- 定位:网状思维工具(networked thought),双链笔记品类的开创者
- 一句话:**双链笔记的"鼻祖"——块级双链/引用/日记流的原创者,但创新停滞、定价最贵、无免费版,如今更多是"历史地标"而非首选**

## 开源情况

| 维度 | 说明 |
| --- | --- |
| 许可证 | ❌ **专有软件(完全闭源)** |
| 开放范围 | 仅提供官方 REST 风格 API(读写图谱);客户端、同步引擎、数据层全部闭源 |
| 治理主体 | Roam Research 公司(创始人 Conor White-Sullivan,小团队) |
| 商业模式 | **订阅制且无免费版**:Pro $15/月($165/年)、Believer $500/5 年;31 天试用 |
| 闭源+云端的双重风险 | 数据存在 Roam 服务器上,无本地文件;导出 JSON/Markdown 混乱且有损(丢失块级结构);公司停摆即数据悬空 |
| 风险对冲 | 唯一对冲是导出+迁移:主流工具(Obsidian/Logseq)都有 Roam 导入器;社区已大量完成"出逃" |

## 发展历史

| 时间 | 里程碑 |
| --- | --- |
| 前史 | 创始人 Conor White-Sullivan 曾任 HuffPost(赫芬顿邮报)创新实验室负责人,长期思考"群体如何更好地思考" |
| 2019 | 发布内测版,凭邀请码传播,"Roam Cult"社区氛围形成;块引用/双链/日记流范式确立 |
| 2020 | 正式商业化;Product Hunt 2020 年度产品第 2 名;A 轮融资 $900 万(估值约 $2 亿);**掀起全行业"双链笔记运动"**——Obsidian、Logseq 等跟随者当年涌现 |
| 2021 | 声量与用户峰值;承诺的 multiplayer 协作、API 升级、移动端改进此后多数未完整兑现 |
| 2021–2025 | **开发明显放缓**:小团队、低频更新、无原生 AI;社区大规模流失至 Obsidian/Logseq;2021 年的 feature request 至今悬置 |
| 2026 | 维持 $15/月定价不变、无免费版;出现社区 MCP 适配器(roam-research-mcp 等,走 Roam API);性能问题依旧(图谱大了页面加载以秒计) |

**演进主线**:范式开创者 → 资本宠儿 → 停滞贵族。Roam 的历史意义在于**发明了现代网状笔记品类**(每日笔记为默认入口、双链为核心机制、块级粒度、图谱视图皆为它首创并成为行业标准),但其"云端闭源 + 最贵定价 + 缓慢迭代"的组合,使它几乎被每个维度上都更优的开源替代品(Logseq 直接复刻其模型且本地免费)包围。2026 年新用户选它的理由已不多:除非是深度依赖其块引用手感或已有多年存量图谱的用户。

## 一、笔记功能

| 功能 | 支持情况 |
| --- | --- |
| 编辑范式 | **大纲块级编辑**(原创者:每行一个块,无限缩进嵌套) |
| 组织结构 | 页面 + 块;默认入口是**每日笔记(Daily Notes)** |
| 双向链接 | ✅ 核心卖点(品类发明者),含 Unlinked References(提及未链接的发现) |
| 块引用/嵌入 | ✅ **原创且最流畅**:任意块可引用/嵌入/转clusion,跨页面组合 |
| 全文搜索 | ✅(图谱大时变慢) |
| 查询 | ✅ Datalog 查询(强大但学习曲线陡) |
| 图谱视图 | ✅ 原创的标志性功能 |
| 闪卡 | ⚠️ /sr 语法或 Delta 插件(间隔重复) |
| PDF 标注 | ⚠️ 基础嵌入,标注弱于 Logseq |
| 多人协作 | ✅ **实时协作编辑多用户图谱**(相对 Logseq 的主要优势) |
| 移动端 | ✅ iOS/Android(功能性可用,Web 套壳感) |
| 离线 | ❌ 云依赖,离线模式形同虚设 |

**短板**:最贵($15/月无免费版);性能随图谱增长明显退化;无离线;开发停滞;数据无文件主权;原生 AI 几乎为零。

## 二、存储方式

**范式:纯云端图谱数据库(闭源)**

| 维度 | 说明 |
| --- | --- |
| 存储形态 | Roam 服务器上的图数据库(Clojure 技术栈),本地无任何文件 |
| 数据主权 | ❌ 最弱:数据在厂商服务器,日常依赖其存活 |
| 备份 | 仅能靠导出(手工触发) |
| 纯文本 | ❌ |
| 导出 | JSON / Markdown / EDN——**导出混乱且丢失块级结构** |
| 迁移 | 主流工具(Obsidian/Logseq/思源)有 Roam 导入器,社区迁移路径成熟 |
| 离线 | ❌ |
| 大数据量 | ⚠️ 数千块以上页面加载/搜索明显变慢 |

**优点**:零运维、打开浏览器即用、实时协作。
**缺点**:数据主权十款中最弱(闭源 + 云端 + 有损导出三重叠加);断网即瘫痪。

## 三、链接功能

**评级:L3-L4 —— 块级双链的原教祖,但链接不带属性**

| 能力 | 说明 |
| --- | --- |
| 页面双链 | ✅ `[[页面]]`,品类发明者 |
| 块引用/嵌入 | ✅ `((块ID))` 引用、`{{embed}}` 嵌入——**手感公认最流畅** |
| 反链面板 | ✅ Linked References + **Unlinked References**(提及未链接,独门发现空白点利器) |
| 属性/三元组 | ⚠️ 块属性(`键:: 值`)+ Datalog 查询可模拟,但非结构化一等公民 |
| 知识图谱 | ✅ 标志性图谱视图(不区分关系类型) |
| 查询 | ✅ Datalog(强但陡) |

**定位**:与 Logseq 同级(L3-L4)——链接粒度到块,但链接本身不带语义属性;三元组建模弱于 Trilium/思源。

---

## 四、MCP 与 AI 接入

**评级:T2 —— 无官方支持,靠社区适配器**

| 维度 | 说明 |
| --- | --- |
| 官方 MCP | ❌ |
| 官方 API | ⚠️ Roam API(POST JSON 查询/动作到 api.roamresearch.com),功能可用但长期未升级 |
| 社区 MCP 适配器 | ✅ roam-research-mcp(npx 可装)等,走 Roam API 读写图谱 |
| 内置 AI | ❌ 几乎为零(第三方扩展为主,官方未投入) |
| 配置难度 | 中高(API token + 社区工具,无人保障) |

**现实**:AI 时代 Roam 基本缺位——既无内置 AI,也无官方 MCP;社区适配器解决"能用",但不解决"可靠"。若要"AI + 双链 + 本地",Logseq/Obsidian 路线全面占优。

## 五、便携支持

**评级:无便携性(纯云服务,策略 D)**

| 维度 | 说明 |
| --- | --- |
| 官方便携版 | ❌(纯 Web + 移动 App) |
| 数据目录 | ❌ 无本地数据 |
| 程序+数据 U 盘一体 | ❌ |
| 数据脱离程序可读 | ❌ 仅导出文件 |

**方案**:无。U 盘只能存导出的 JSON/MD 备份;换机 = 登录账号。

## 六、适用场景与总结

| 场景 | 匹配度 |
| --- | --- |
| 深度网状思考/研究型笔记 | ⭐⭐⭐⭐ 范式原创,块引用手感最佳 |
| 多人实时协作同一图谱 | ⭐⭐⭐⭐ 十款中少有的原生支持 |
| 已有大型 Roam 图谱的存量用户 | ⭐⭐⭐⭐ 迁移成本高,留着合理 |
| 数据主权/离线/隐私 | ⭐ 十款最弱 |
| 性价比 | ⭐ 最贵且无免费版 |
| AI/MCP 接入 | ⭐ 官方零投入 |
| 新用户首选 | ⭐⭐ 2026 年已无充足理由 |

> **总结:Roam Research 是双链笔记的"活化石"——它发明的范式(块级大纲、每日笔记、双向链接、块引用、图谱)已成为全行业标准,被 Obsidian/Logseq 免费复刻并发扬。如今它的护城河只剩三样:原汁原味的块引用手感、原生实时协作、存量用户的迁移惯性。对多数人而言,它的历史意义大于现实选择价值:想体验其范式,Logseq 是免费本地的直接镜像;想要关系建模,Trilium/思源更强;想要 AI,几乎任何其他工具都比它强。**
