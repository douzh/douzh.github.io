覆盖工具:Trilium Notes / lapisnote / Obsidian / Logseq / 思源笔记

> 便携目标:**程序+数据全放 U 盘,免安装即插即用,不写系统盘/注册表,换电脑零痕 迹**。分两个层次评估:① 官方是否提供 Portable 便携版;② 数据目录能否自定义(数据便携与程序便携分离)。

## 二、两种便携策略

```
策略 A:全便携(程序+数据一体上U盘)
    → 换任何电脑,插入U盘即用,拔出走人零残留
    → 要求:官方 Portable 版 + 数据目录跟随程序

策略 B:半便携(U盘只放数据,程序各机自装)
    → 笔记数据随身,程序每台机器装一次
    → 要求:数据目录可自定义(五款全部满足)
```

---

## 三、各工具便携方案详述

### 3.1 Trilium Notes —— 官方原生全便携(标杆)

- **官方直接提供 Portable 便携压缩包**:解压到 U 盘即可运行
- **数据默认就在程序目录下** `trilium-data/`(含 `document.db` 单文件)——程序与数据天然一体
- **完全不写系统盘和注册表**:插任何电脑直接打开,拔掉零残留
- **备份=复制**:整个 `trilium-data/` 文件夹或仅 `document.db` 一个文件
- **结论**:五款中唯一官方原生满足"程序+SQLite 全放U盘、免安装即插即用"的完整需求

### 3.2 lapisnote —— 数据便携,程序安装

- 程序:基于 Tauri 2 + Rust,**安装包小巧**——需安装(安装器会写系统),但体积小、启动快,重装成本低
- 数据:默认 `%APPDATA%/com.jdnotes.app/`,**设置中可自定义存储位置** → 把 SQLite 库指到 U 盘目录,即实现数据随身
- 适用策略 B:每台机器装一次程序(包小,负担低),U 盘只挂数据库
- 注意:换机时 MCP 自动注册依赖程序运行,U 盘数据 + 本机程序组合不影响 MCP(详见 [MCP 支持](04-mcp-support.md))

### 3.3 Obsidian —— 库即文件夹,天然数据便携

- 官方仅提供安装版(Windows 安装器/ Scoop/ winget 等),程序本身需安装
- **核心便携特性:库(Vault)= 任意文件夹**——建库时直接选 U 盘路径,或把整个库文件夹拷到 U 盘,任何机器上的 Obsidian "打开文件夹作为库"即识别
- 纯 Markdown 文件夹的额外好处(见 [存储方式](02-storage.md)):
  - U 盘数据可直接被任何编辑器/其他工具打开,不依赖 Obsidian 本身
  - AI 可旁路直接读写文件(无需 API)
- 社区便携法:Obsidian 是 Electron 应用,有第三方制作的可解压绿色包;官方未承诺,稳定性自担
- 适用策略 B(数据便携性极佳)

### 3.4 Logseq —— 同 Obsidian,图谱即文件夹

- 官方仅安装版(Electron)
- **图谱(Graph)= 任意文件夹**,journals/pages/assets 全在内 → 拷走文件夹即带走全部数据
- 纯 Markdown/Org 文本,U 盘直插任何机器可读(即使没装 Logseq)
- 社区同样有绿色打包方案,官方未承诺
- 适用策略 B

### 3.5 思源笔记 —— 官方便携版,程序+数据可一体

- **官方提供 Windows 便携版(Portable zip)**:解压即用,不写注册表
- 工作空间(workspace)可自选位置——选 U 盘目录,则程序(解压在U盘)+ 数据(workspace在U盘)一体便携
- 注意:
  - 便携版与安装版勿混用同一 workspace
  - `.sy` 数据结构完整,但脱离思源程序不可直接阅读(见 [存储方式](02-storage.md))
- 适用策略 A(官方支持)与策略 B 皆可

## 四、便携方案选型

| 便携需求 | 推荐 | 方案 |
| --- | --- | --- |
| **程序+数据全U盘,插上就用** | **Trilium(首选)/ 思源(次选)** | 官方 Portable 包 |
| 数据随身,程序无所谓(各机自装) | **Obsidian / Logseq** | 库/图谱放U盘,数据纯文本任何机器可读 |
| 数据随身 + AI 自动接管(MCP) | **lapisnote** | U 盘挂 SQLite 库,程序小重装快,MCP 零配置 |
| 只求备份最简 | **Trilium** | 复制单文件 document.db |
| 换机频率极高、零残留 | **Trilium** | 拔U盘即走 |

**U 盘使用注意**(通用):
- SQLite 系(Trilium/lapisnote)在 U 盘上运行需**安全弹出**再拔,避免数据库写半截损坏
- 纯文本系(Obsidian/Logseq)抗拔性强,最坏丢最近未保存修改
- U 盘建议选高耐久型号(频繁小文件写入磨损闪存)

---

## 五、一句话总结

> **便携支持三档:Trilium Notes 是唯一官方原生"全便携"标杆——Portable 压缩包+数据默认在程序目录 trilium-data/,不写系统盘注册表,程序+SQLite 一体上U盘即插即用;思源笔记官方提供便携版 zip+workspace 可自选,同样可实现程序数据一体便携;Obsidian/Logseq 官方仅安装版但"库/图谱=任意文件夹"使数据便携性极佳——纯 Markdown 拷到U盘任何机器可读,甚至不依赖程序本身;lapisnote 走"数据便携+轻程序"路线——安装包小(Tauri+Rust)重装成本低,SQLite 路径可自定义到U盘,且 MCP 自动注册让换机后 AI 接管零成本。选型:要全U盘免安装选 Trilium(或思源),要数据抗锁定+跨机可读选 Obsidian/Logseq,要 U 盘数据+AI 无缝接管选 lapisnote。通用提醒:SQLite 系在U盘务必安全弹出防库损坏,纯文本系抗拔性最好。**
