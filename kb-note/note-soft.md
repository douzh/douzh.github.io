## Trilium Notes

https://github.com/TriliumNext/Trilium

结合你「程序+SQLite全放U盘、免安装即插即用」的核心需求，同时兼顾上一轮提到的MCP接入AI能力，按匹配度整理如下方案：

- **便携方式**：官方直接提供 **Portable 便携压缩包**，解压到U盘即可运行，默认数据就存放在程序目录下的 `trilium-data` 文件夹中，完全不写入系统盘和注册表，插任何电脑都能直接打开。
- **存储形式**：所有笔记、附件、配置、版本历史全部存在单个 `document.db` SQLite 数据库中，备份只需复制这一个文件。
- **核心功能**：树状层级笔记、双向链接、笔记克隆、富文本+Markdown双模式、JavaScript脚本扩展、端到端加密、完整版本历史，支持十万级笔记体量。
- **MCP扩展**：自带 REST API，可通过第三方 MCP 适配器接入AI，社区已有成熟的对接方案。

## lapisnote

https://github.com/zexadev/lapisnote

- **本地安装**：基于 Tauri 2 + Rust 构建的原生桌面应用，支持 Windows / macOS / Linux，安装包小巧、启动速度快
- **SQLite 存储**：所有笔记数据完整存储在本地 SQLite 数据库中，默认路径 `%APPDATA%/com.jdnotes.app/`，可在设置中自定义存储位置
- **MCP 集成**：应用启动时自动在 `127.0.0.1:19230` 开启 MCP Server，并自动注册到 Claude Code，AI 可直接读写笔记

**额外亮点**：
- 内置 AI 写作助手，支持 DeepSeek、OpenAI、Claude、Gemini、Ollama 本地模型，可同时配置多模型切换
- 支持 Markdown 编辑、标签系统、日历视图、全文搜索、废纸篓、提醒等完整笔记功能
- 支持导出 Markdown / PDF

## Obsidian

完全本地、纯 Markdown、可双向链接、不绑架数据的知识库

1. Local‑first 本地优先：笔记全部是本地 Markdown 文件；
2. 核心功能个人永久免费，无需注册账号；
3. 高度可扩展，开放插件 API，交给社区扩展能力。

## logseq

https://github.com/logseq/logseq

Logseq 是一款**开源、本地优先、高度注重隐私**的大纲式双链知识管理工具，常被视为 Roam Research 的主流开源替代方案。它以「块」为最小信息单位，主打非线性笔记、双向链接与知识网络构建，核心设计原则是「用户完全拥有数据」——官方服务器永远不会存储、分析你的私人笔记内容，同时提供可选的端到端加密协作能力。

一、核心隐私与存储机制

- **数据完全本地可控**：所有笔记内容以 **Markdown / Org-mode 纯文本文件** 存储在你指定的本地文件夹，无强制云端、无账号绑定，离线状态下可完整使用所有核心功能。
- **开源可审计**：核心代码基于 MIT 协议开源，可自由查看、二次开发，不存在暗箱收集数据的黑盒逻辑。
- **索引机制**：软件启动时将纯文本数据加载到内存中的 Datascript 图数据库引擎做索引，本地缓存文件用于加速启动。**主存储并非 SQLite**（这一点和你之前关注的 SQLite 原生存储有本质区别），所有原始笔记都是通用纯文本格式，不会被平台锁定。
- **同步与协作**：官方提供可选付费的端到端加密同步服务，支持多人协作编辑同一知识库；也可完全自行搭配 Git、坚果云、任意网盘等文件同步工具，自由度极高。

二、核心知识管理能力

大纲块级编辑

每一行内容都是一个独立的「块」，支持无限缩进嵌套，通过 Tab/Shift+Tab 快速调整层级，非常适合快速记录、梳理逻辑、拆解复杂任务。块可以独立引用、嵌入、跨页面移动，修改源块后所有引用位置自动同步，避免内容重复维护。

日记流（Journal）工作流

打开软件默认进入当日日记页，无需提前创建分类目录，想到什么直接记录，后续通过 `[[页面引用]]`、`#标签` 自动归类到对应主题，是典型的「先捕捉、后整理」低门槛工作流，适合日常碎片化记录。

双向链接与知识图谱

- 通过 `[[页面名]]` 创建页面级链接，`((块ID))` 创建精确到段落的块引用，系统自动在目标页面生成反向链接面板，所有关联内容一键追溯。
- 原生自带**全局知识图谱视图**，可直观查看所有页面的关联网络，支持缩放、节点筛选、快速定位，帮助发现知识间的隐性关联。

高级查询与扩展

内置 Datalog 查询引擎，可通过语法按属性、标签、链接关系、任务状态等条件批量筛选笔记，比如“找出本月所有未完成的项目相关任务”；同时支持白板、看板、思维导图、任务管理等插件扩展，覆盖从记录到项目管理的全流程。

三、链接与属性能力（对应你关注的「链接带属性」）

Logseq 的属性体系是**页面级 / 块级的键值对属性**，并非「链接实体本身带独立属性」，但可以通过属性表达链接的语义关系：
- **自定义属性语法**：在页面顶部或块内通过 `key:: value` 格式添加任意属性，例如 `类型:: 书籍`、`作者:: [[鲁迅]]`、`发布年份:: 1918`，属性值可以是普通文本，也可以是页面链接。
- **语义化关联表达**：通过属性可以定义带类型的关系，比如在「狂人日记」页面写 `作者:: [[鲁迅]]`，就相当于给这条链接赋予了「作者」的语义；在鲁迅页面的反向引用中，可筛选出所有通过「作者」属性关联的作品。
- **能力边界**：原生知识图谱不支持按关系类型区分颜色、标注关系名称，链接本身没有独立的多属性扩展；如果需要「关系作为一等公民、单条关系带多个附加属性」的三元组建模，其结构化能力弱于 Trilium Notes。
