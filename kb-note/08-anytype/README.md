# Anytype 档案

[返回总览](../note-soft.md)

- 项目:https://github.com/anyproto(协议 MIT 开源,客户端 source-available)
- 定位:本地优先 + 端到端加密 + P2P 同步的去中心化"Notion"
- 一句话:**唯一"关系是一等公民"理念对标 Trilium 的 Notion 系工具——对象+类型+关系建模,E2EE 零知识加密,P2P 无中心服务器;但不可编程、生态封闭**

## 开源情况

| 维度 | 说明 |
| --- | --- |
| 许可证 | **混合模式**:核心协议库 anytype-heart 为 **MIT**;客户端为 source-available(源码可见但非 OSI 认证开源许可)——八款中最特殊 |
| 开放范围 | ⚠️ 半开源:数据协议层完全开放(任何人可写兼容客户端);官方客户端源码公开但许可受限 |
| 治理主体 | **瑞士 ANY Association 非营利协会**——八款中唯一非营利治理,无商业变现压力,长期存续动机最纯粹 |
| 商业模式 | 免费(含 1GB 加密备份);付费项 = Builder 订阅(256GB 备份空间) |
| 社区规模 | anyproto 组织多仓库,移动端质量高,社区论坛活跃 |
| 开放的深层意义 | MIT 协议层 = 即使公司消失,社区可用 anytype-heart 重建客户端读出数据——**开放协议是加密数据的逃生门** |
| 风险残留 | 无助记词则数据物理不可恢复;导出通道弱 |

## 一、笔记功能

| 能力 | 说明 |
| --- | --- |
| 编辑范式 | 块编辑 + **对象模型**:一切皆 Object(笔记/任务/联系人/项目/文件) |
| **Types 类型** ⭐ | 对象有类型(类 Notion 模板/数据库),可自建:书库、CRM、项目 |
| **Relations 关系** ⭐ | 类型化属性(text/tag/date/object 引用),对象间链接即关系 |
| **Sets 集合** | 按类型+过滤条件聚合视图(类 Notion 数据库视图) |
| 任务管理 | Task 类型 + 集合视图 |
| 图谱视图 | ✅ 全局 Graph View,可视化对象关联网络 |
| 协作 | Multiplayer 实时协作(2024 起),Space 共享 |
| 移动端 | ✅ iOS/Android 原生,离线可编辑 |
| 模板 | ANY Experience Gallery 社区模板市场 |

## 二、存储方式

**本地优先 + 零知识加密 + P2P,无中心服务器可读你的数据**

| 维度 | 说明 |
| --- | --- |
| 第一副本 | 数据默认存本地设备,离线全功能 |
| 加密 | **E2EE 零知识加密**:出设备前加密,官方也无法解密;12 词助记词=主密钥(类比特币钱包) |
| 同步 | **P2P 协议**(CRDT + 加密签名差异同步),可自托管备份节点或 local-only 局域网模式 |
| 备份 | 官方加密备份节点:免费 1GB,Builder $9.99/月 256GB |
| 数据格式 | 本地文件 + IPFS 兼容结构(CID 寻址),但**未提供直接可用的导出通道** |
| Git diff | ❌ |
| 迁移成本 | ⚠️ 导入 Notion;导出能力弱,有锁定风险 |

**技术栈**:桌面 TypeScript,移动 Swift/Kotlin(原生),核心与后端 Golang(anytype-heart);月度跨平台发版。

## 三、链接功能

**评级:L4 —— 关系是一等公民(理念与 Trilium 同源)**

| 能力 | 说明 |
| --- | --- |
| 对象链接 | ✅ 任何对象可链接任何对象,双向 |
| **关系带类型** ⭐ | Relations 有类型与名字,链接即结构化关系(非裸跳转) |
| 三元组建模 | ✅ (对象, 关系, 对象) 原生模型,集合按关系过滤聚合 |
| 链接带属性 | ✅ 关系可带类型约束;弱于 Trilium 之处:**无 SQL 直查**,查询限于集合视图 |
| 图谱视图 | ✅ 原生全局图 |
| 引用完整性 | ✅ 对象删而不毁关系结构 |

> 与 Trilium 的 L5 差在哪:Trilium 的 relation 可用 SQL 任意查询、AI 可直读写;Anytype 的关系强在 UI 层(集合过滤),**无开放查询接口**。

## 四、MCP 与 AI 接入

**评级:T2 —— 无官方 API,社区库路线,内置 AI 缺位**

| 维度 | 说明 |
| --- | --- |
| 官方 MCP | ❌ |
| 自有 API | ❌ 无公开 API(anytype-heart Go 共享库存在,社区可自行构建) |
| MCP 路径 | 社区探索(anytype-heart 封装),无成熟适配器 |
| 内置 AI | ❌ 基本缺位(AI 落后 Notion/AFFiNE 一代) |

**短板**:这是三款中 AI/自动化能力最弱的——既是隐私哲学使然(数据不出设备),也是接口封闭的结果。AI 想读 Anytype 数据,当前几乎没有正规通道。

## 五、便携支持

| 维度 | 说明 |
| --- | --- |
| 官方便携版 | ❌ |
| 数据目录自选 | ⚠️ 本地数据库在用户目录,但**绑定账户加密**,换机靠助记词恢复同步 |
| 程序+数据 U 盘一体 | ❌ |
| 数据脱离程序可读 | ❌(加密 + 私有格式) |

⚠️ 特别注意:数据 E2EE 加密意味着**没有助记词,数据物理上不可恢复**——便携性最差的形态,安全与便携在此互斥。

## 六、适用场景评分

| 场景 | 评分 | 说明 |
| --- | --- | --- |
| 隐私敏感笔记(日记/健康/法律) | ⭐⭐⭐⭐⭐ | 唯一"官方也看不了"的成熟方案 |
| 类型化知识库(书库/人物/项目) | ⭐⭐⭐⭐ | Types+Relations 建模舒适 |
| 无网/弱网环境 | ⭐⭐⭐⭐⭐ | 本地优先+P2P,零云端依赖 |
| AI 集成/自动化 | ⭐ | 无 API 无 AI,基本无门 |
| 数据导出自由度 | ⭐⭐ | 导入易导出难,有锁定感 |
| 团队协作 | ⭐⭐⭐ | Multiplayer 可用,打磨不及 Notion |

## 总结

Anytype 是**理念上最接近 Trilium 的 Notion 系工具**——"关系是一等公民"同一个哲学,但走向了两个极端:Trilium 把关系做成**可编程可查询的数据库**(开放、极客、AI 友好),Anytype 把关系做成**加密自洽的私有宇宙**(封闭、安全、AI 无门)。隐私优先选 Anytype,可编程与 AI 集成选 Trilium。它是三款中唯一由非营利协会(Swiss ANY Association)运营的产品,长期存续动机最纯粹。
