## 二、各工具详述

### 2.1 Trilium Notes

- **定位**:个人知识库/维基,适合构建大型私有知识体系
- **编辑范式**:树状无限层级为骨架,笔记内容支持富文本与 Markdown 双模式切换;笔记克隆(同一内容多位置引用)是其特色
- **独有功能**:
  - **关系属性系统**:`relation` 类型属性可把链接变成带语义的一等公民(详见 [链接功能](03-link-features.md))
  - **JavaScript 脚本引擎**:内置脚本笔记,可自动化任何操作(渲染自定义视图、定时任务、API 调用),可编程性最强的笔记工具之一
  - **端到端加密**:对单个子树加密,保护敏感笔记
  - **同步**:自建同步服务端(Trilium Server),多端同步
- **短板**:无官方移动端;界面偏极客;上手门槛高于 Obsidian

### 2.2 lapisnote

- **定位**:轻量本地笔记 + 深度 AI 集成的新兴工具
- **技术栈**:Tauri 2 + Rust,安装包小、启动快、内存占用低
- **功能面**:Markdown 编辑、标签系统、日历视图、全文搜索、废纸篓(软删除)、提醒
- **独有功能**:
  - **内置 AI 写作助手**:支持 DeepSeek/OpenAI/Claude/Gemini/Ollama 本地模型,多模型同时配置切换
  - **自动 MCP Server**:启动即在 `127.0.0.1:19230` 开启 MCP 并自动注册 Claude Code(详见 [MCP 支持](04-mcp-support.md))
- **短板**:新兴项目,生态与成熟度不及其他四款;无移动端;链接/双链能力未在资料中确认,组织方式以标签+日历为主

### 2.3 Obsidian

- **定位**:纯本地 Markdown 知识库,以插件生态著称,"你的数据永远是你的"
- **编辑范式**:标准 Markdown 文件 + 文件夹结构,实时预览/源码模式/阅读视图
- **功能面**(内置):
  - 双链 `[[ ]]`、嵌入 `![[ ]]`、块引用、标签、反向链接面板
  - 全局关系图谱 + 局部图谱(可视化核心卖点)
  - Canvas 白板(官方内置,无限画布放卡片/图片/链接)
  - 每日笔记、独特笔记、大纲、工作区
  - 命令面板 + 图形化设置,不用配置文件
- **插件生态(最强项)**:2000+ 社区插件,如 Dataview(数据库查询)、Tasks(任务管理)、Excalidraw(手绘)、Kanban(看板)、Calendar、Spaced Repetition(闪卡)等;还有大量主题与 CSS 片段
- **短板**:任务管理/闪卡/表格视图等依赖插件,数据分散在各插件配置中;官方同步收费;核心闭源(免费但非开源)

### 2.4 Logseq

- **定位**:大纲式、块级、本地优先、隐私优先的开源双链工具(Roam 开源替代)
- **编辑范式**:以"块"为最小单位,每行是块,无限缩进嵌套;典型的大纲流笔记,适合"先捕捉后整理"
- **工作流特色**:
  - **Journal 日记流**:默认进入当日日记页,无需预先建目录,`[[页面]]`、`#标签` 自动归类——低门槛记录工作流
  - **任务状态内置**:TODO/DOING/DONE/LATER/NOW 等关键字原生支持
- **高级能力**:
  - **Datalog 查询引擎**:按属性/标签/链接/任务状态批量筛选,如"本月所有未完成任务"
  - **白板 Whiteboards**:官方内置
  - 知识图谱视图原生内置
- **短板**:不是传统富文本编辑器,长文写作不如 Obsidian 顺手;索引加载在内存,超大库启动慢;对纯文件夹管理弱(以日期页面为主)

### 2.5 思源笔记

- **定位**:块级、本地优先的国产全功能知识库,"重构你的思维"
- **编辑范式**:块级编辑(段落、列表项、标题均为块),使用 Markdown 语法输入但存储为自有 `.sy` JSON 格式
- **功能面**(内置,官方功能覆盖面最广):
  - 块级双链与引用、反向链接面板、关系图谱
  - **属性数据库视图**:给文档/块挂属性,提供表格/看板/日历/画廊等多视图(类 Notion Database)——五款中内置数据库能力最强
  - **闪卡**:官方内置间隔重复(SRS)
  - 模板、每日笔记、标签、书签、收集箱
  - **同步**:官方付费同步/对象存储,也支持完全手动同步(数据本地)
  - **人工智能助手**:内置 AI 功能(付费订阅,支持自配 API)
  - 导出丰富:MD/PDF/HTML/Word/图片
- **多端**:桌面 + 移动 App + Docker 自部署(浏览器访问)
- **短板**:核心闭源(个人版免费);存储非纯 Markdown(详见 [存储方式](02-storage.md)),迁移到其他工具需要导出转换

## 三、按使用场景选型

| 场景 | 推荐 | 理由 |
| --- | --- | --- |
| 个人大型知识库/维基 | **Trilium Notes** | 树状结构+克隆+关系属性,十万级体量 |
| 极客可编程知识库 | **Trilium Notes** | 内置 JS 脚本引擎 |
| 插件生态/高度定制 | **Obsidian** | 2000+ 插件,任何需求都有社区方案 |
| 快速记录/大纲流/任务 | **Logseq** | Journal 日记流 + 块级 TODO + Datalog 查询 |
| All-in-one(数据库+闪卡+多端) | **思源笔记** | 官方内置功能最全,类 Notion 数据库 |
| AI 原生/MCP 优先 | **lapisnote** | 内置多模型 AI + 自动 MCP Server |
| 长文写作/学术 | **Obsidian** | 纯 Markdown + 主题生态 |
| 数据主权/纯文本可迁移 | **Obsidian / Logseq** | 纯 Markdown 文件,永不锁定 |

## 四、一句话总结

> **五款工具的笔记功能定位分明:Trilium Notes 是"可编程树状知识库"(JS 脚本+克隆+关系属性,极客向);Obsidian 是"插件生态之王"(2000+ 插件覆盖一切,核心免费);Logseq 是"大纲块级记录流"(Journal+块级 TODO+Datalog,先捕捉后整理);思源笔记是"内置功能最全的 All-in-one"(属性数据库+闪卡+多端+AI);lapisnote 是"AI 原生轻量新锐"(内置多模型助手+自动 MCP)。选型:要生态选 Obsidian,要大纲流选 Logseq,要数据库/闪卡/多端选思源,要可编程选 Trilium,要 AI 深度集成选 lapisnote。**
