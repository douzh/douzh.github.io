## 二、存储方式

**范式:单文件数据库(SQLite)**

```
trilium-data/
├── document.db      # 核心:所有笔记+附件+版本+配置,单 SQLite
├── backup/          # 自动定时备份
└── log/             # 日志
```

| 维度 | 说明 |
| --- | --- |
| 存储形态 | 单个 `document.db` SQLite 文件 |
| 备份 | 复制一个文件即全部备份 |
| 纯文本 | ❌ 二进制,无法 Git diff |
| 迁移 | 导出 MD/OPML(有损) |
| 锁定风险 | 中,依赖导出功能 |
| 版本历史 | 入库(同一 DB) |
| 加密 | 保护模式下整库加密 |
| 十万级体量 | ✅ 数据库索引优化 |

**优点**:备份极简、事务一致性强、大数据量性能好、结构化查询(SQL)。
**缺点**:二进制不可 diff、脱离工具不可直读、单点故障需勤备份。

## 三、链接功能(五款中最强)

**评级:L5 —— 关系作为一等公民**

链接体系两层:

1. **普通链接**:正文内部链接,仅跳转。

2. **关系属性(Relation)—— 核心特色**:
   - 每个笔记可挂属性,分两类:
     - `label`:键值对标量(如 `类型:: 书籍`、`评分:: 5`)
     - `relation`:**指向另一笔记的带名链接** —— 带属性的三元组
   - 结构等价于知识三元组:`(本笔记, 关系名, 目标笔记)`

```
示例:
笔记《狂人日记》
  ├─ label:    类型 = 书籍
  ├─ label:    发布年份 = 1918
  ├─ relation: 作者 ──► 笔记《鲁迅》
  └─ relation: 收录于 ──► 笔记《呐喊》
```

- **关系可查询**:内置搜索语法或 SQL 直接查图("所有作者=鲁迅的作品"、"被 ≥3 篇笔记引用的来源")
- **关系可视化**:Relation Map 按关系类型渲染
- **链接本身带元数据**:关系是数据库记录而非正文文本

**结论**:最接近 Palantir 式本体/知识图谱建模的笔记工具。

## 四、MCP 与 AI 接入

**评级:T1+ —— 官方内置 AI + 官方 MCP + ETAPI(2026 年 v0.104+ 起全面升级)**

| 维度 | 说明 |
| --- | --- |
| 官方 MCP | ✅ 官方 MCP Server(已上架腾讯云 MCP 广场,2026-08;桌面版提供 MCP 端点供 AI 助手读写笔记) |
| 自有 API | ✅ ETAPI(REST),覆盖笔记 CRUD、搜索、附件、属性(含 relation) |
| 社区 MCP 适配器 | ✅ triliumnext-mcp / @aimbitgmbh/trillium-mcp 等(走 ETAPI,含权限控制 READ / READ;WRITE) |
| **内置 AI** | ✅ **官方 LLM 集成(设置面板可配置 LLM 提供商)**;v0.104 起**可直接复用 Claude Code 订阅**(无需 API Key、无额外费用) |
| AI 聊天功能 | ✅ 引用笔记内容、AI 回答保存为子笔记、重新生成、多会话管理、打印等(v0.104 LLM UI 大改版) |
| 配置难度 | 低(内置 AI 在设置中配 LLM 即用;MCP 端点开箱可用) |

**版本要点(v0.104.0,史上最大更新)**:
- **内置 AI 飞跃**:LLM 集成支持 Claude Code 订阅直连;聊天 UI 全面改进(引用内容、回答存为子笔记、重命名/删除会话、note-tooltip 等)
- **官方 MCP 端点**:供外部 AI 助手(Claude Code/Cursor 等)直接读写笔记
- ⚠️ **安全收紧(影响 AI 接入)**:桌面版**默认不再对局域网开放 ETAPI 端口**,使用 ETAPI/MCP/桌面间同步需在 Options → Security 手动开启;后端脚本与 SQL 控制台默认禁用(config.ini 可重新启用)

**优势场景**:
- **结构化读写**:ETAPI/MCP 直接操作 relation 属性,AI 可做知识图谱级检索("列出作者=鲁迅的所有笔记")
- **应用内 AI**:内置聊天直接引用笔记提问,AI 回答一键存为子笔记沉淀进知识库
- JS 脚本引擎可调 OpenAI/Claude API 批处理笔记、定时自动化(注意 v0.104 起后端脚本默认禁用)

**短板**:内置 AI 功能较新,成熟度待验证;MCP 生态(客户端适配)不如 lapisnote 的自动注册顺手;使用 ETAPI/MCP 需注意 v0.104+ 的安全默认值。
