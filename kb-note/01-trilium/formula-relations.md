# 数学与物理公式的推理关系

[返回 Trilium 档案](README.md) | [属性系统:标签/关系与定义](attributes.md) | [返回总览](../note-soft.md)

> 公式之间的推理关系分四层:**逻辑变换关系、推导关系、结构对应关系、物理特有关系**。核心区分维度是**保真度**:等价(无损)→ 演绎(保真)→ 极限/特例(条件保真)→ 近似(有损)→ 类比(仅结构相似,不保真)。文末给出知识图谱建模谓词表(Trilium relation 用法)。

## 一、逻辑变换关系(真值不变)

| 关系 | 含义 | 示例 |
| --- | --- | --- |
| **等价变形** | A ⇔ A',双向,恒等 | 勾股定理 a²+b²=c² ⇔ cosC=(a²+b²-c²)/2ab |
| **逆/否/逆否命题** | 命题的逻辑变换 | "可导→连续"与"不连续→不可导"(逆否等价) |
| **对偶** | 交换角色后结构不变 | 平面几何中点与直线的对偶;电路的电压-电流对偶 |
| **变量代换/坐标变换** | 形式变、内容不变 | 直角坐标 → 极坐标下的拉普拉斯算子 |

## 二、推导关系(单向,保真或降真)

| 关系 | 含义 | 示例 |
| --- | --- | --- |
| **演绎推导** | 前提+规则 → 结论,逻辑保真 | 牛顿第二定律 + 万有引力 → 开普勒第三定律 |
| **特例化** | 一般 → 特殊(代入参数/条件) | 二项式定理取 n=2;闵可夫斯基度规取 c→∞ 得欧氏度规 |
| **推广/一般化** | 特殊 → 一般(归纳跳跃,需重新证明) | 欧氏几何 → 黎曼几何;实数 → 复数 |
| **数学归纳** | 有限验证 → 无穷命题 | Σ(2i-1)=n² |
| **联立消元** | 多定律约束 → 新定律 | 动量守恒+能量守恒联立 → 弹性碰撞末速度公式 |
| **变分 ⇄ 微分** | 积分表述与微分表述等价互换 | 最小作用量原理 ⇔ 拉格朗日方程 ⇔ 牛顿方程 |

## 三、结构对应关系(跨域映射)

| 关系 | 含义 | 示例 |
| --- | --- | --- |
| **同构/类比** | 数学结构相同,物理对象互换 | 热传导 ⇄ 扩散 ⇄ 布朗运动(同一扩散方程);RLC 电路 ⇄ 阻尼振子 |
| **数学工具应用** | 纯数学结构 → 物理实在的解释 | 群论 → 粒子分类;微分几何 → 广义相对论 |
| **模型化** | 现实 → 数学方程(有损压缩) | 理想气体状态方程是对真实气体的模型化 |

## 四、物理特有关系

| 关系 | 含义 | 示例 |
| --- | --- | --- |
| **对称性 → 守恒律**(Noether) | 数学对称推出物理守恒 | 时间平移不变 → 能量守恒;空间旋转不变 → 角动量守恒 |
| **对应原理(极限回归)** | 新理论在极限下退回旧理论 | 相对论力学 v≪c → 牛顿力学;量子力学 ℏ→0 → 经典力学 |
| **近似/微扰** | 精确方程 → 可解近似 | 单摆 sinθ≈θ;量子微扰论逐阶展开 |
| **量纲分析/标度** | 量纲一致性 → 函数形式约束 | π 定理推出湍流能谱 -5/3 律 |
| **唯象 ⇄ 微观** | 宏观定律由微观理论推导 | 热力学 ← 统计力学推导;连续介质 ← 分子动理论 |
| **有效理论降级** | 高能理论在低能下"积掉"自由度 | 标准模型 → 费米理论;量子电动力学 → 几何光学 |

## 五、知识图谱建模谓词表

映射到 [30-wisdom-model.md](../../99ai/1life/30-wisdom-model.md) 的模型分类:等价/演绎/归纳 → 符号模型;对称性/量纲/变分 → 物理模型;类比/同构 → 类比模型;对应原理/近似 → 模型间约化。

用 Trilium 关系建模时的谓词建议:

```
~等价于        equivalentTo     (对称)
~推导自        derivedFrom      (符号演绎)
~特例于        specialCaseOf    (与 推广于 互逆)
~极限于        limitOf          (对应原理)
~近似于        approximates
~类比于        analogousTo      (同构)
~对称性源于    fromSymmetry     (Noether)
~消元自        combinedFrom     (联立)
```

谓词用法见 [attributes.md](attributes.md) 第三节;建好后可用 Relation Map(`~map:推导自` 等)把公式网络可视化,用 SQL 直查推理链(如"欧拉公式的一切特例")。
