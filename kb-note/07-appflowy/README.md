# AppFlowy 档案

[返回总览](../note-soft.md)

- 项目:https://github.com/AppFlowy-IO/AppFlowy
- 定位:开源 Notion 替代,"Bring projects, wikis, and teams together with AI"
- 一句话:**Notion 像素级开源克隆——本地 SQLite、全平台含移动原生、AI 会议纪要独一份;但移动同步与大数据量性能是短板**

## 开源情况

| 维度 | 说明 |
| --- | --- |
| 许可证 | **AGPL-3.0**(客户端 + Cloud 服务端) |
| 开放范围 | ✅ 全部开源:Flutter 前端 + Rust 本地引擎 + AppFlowy Cloud 自托管栈,无功能阉割 |
| 治理主体 | AppFlowy-IO(Y Combinator 孵化的商业公司)+ 社区 |
| 商业模式 | 单机完全免费;付费项 = AppFlowy Cloud 订阅(协作/AI 额度) |
| 社区规模 | GitHub 67.5k+ stars(八款中最高),迭代极快 |
| AGPL 的影响 | 个人使用无义务;商用自托管对外提供服务需开源修改 |
| 风险对冲 | 单机模式 = 本地 SQLite,官方云可不用;导出 Markdown 完整 |

## 发展历史

| 时间 | 里程碑 |
| --- | --- |
| 2022-06 | GitHub 开源发布(AGPL-3.0),定位"Notion 开源替代",数月内 stars 破万,成为现象级项目 |
| 2022–2023 | AppFlowy Cloud Beta 上线;接入 AI(ChatGPT 集成);Flutter + Rust 架构铺开全平台(含移动原生) |
| 2023–2024 | 协作与数据库视图完善;AppFlowy AI 升级(写作/总结/会议纪要);进入 Y Combinator 孵化 |
| 2024–2025 | 67.5k+ stars(八款中最高),迭代极快;云订阅商业模式成熟,AI 会议纪要成差异化卖点 |

**演进主线**:Notion 像素级克隆 → 全平台 + AI 差异化 → YC 商业化。以"开源替代"红利起家,靠 Flutter 跨端与 Rust 本地引擎建立工程壁垒。

## 一、笔记功能

| 能力 | 说明 |
| --- | --- |
| 编辑范式 | 块编辑器(Flutter):页面/嵌套块/`/` 命令,Notion 手感 |
| 数据库 | Grid/Board/Calendar 多视图;状态/标签/日期等字段类型;**relation 列可关联行** |
| 模板 | 项目管理/CRM/知识库模板,页面可存为模板 |
| 任务管理 | 待办 + 看板 + 日历,筛选排序 |
| **AI 三件套** ⭐ | **AI Meeting Notes**(实时转录+说话人识别+纪要)、AI Transcript(音频转录)、AI Chat(多文档 RAG 上下文) |
| 协作 | 自托管/云同步,实时协作尚在成熟中 |
| 移动端 | ✅ iOS/Android 原生(三款中移动覆盖最全) |
| 导入/导出 | Notion 导入(Markdown+CSV;公式与关联列保真度降低)、Markdown 导出 |

## 二、存储方式

**本地优先:Rust 后端 + 本地 SQLite,云同步可选**

| 维度 | 说明 |
| --- | --- |
| 单机模式 | 默认离线使用,数据写本地 SQLite,无需注册 |
| 云/自托管 | AppFlowy Cloud 官方 Docker Compose 一键部署;桌面端改 URL 即接入自托管 |
| 备份 | 单机=复制 SQLite 文件;自托管=数据库+数据盘快照 |
| Git diff | ❌ 二进制不可读 |
| 十万级 | ⚠️ 数千行数据库首开有感知延迟(Flutter 渲染整表重绘) |

**架构**:Flutter(跨平台前端)+ Rust(本地引擎)——启动快、内存占用低,是三款中桌面客户端最轻的。

## 三、链接功能

**评级:L3 —— 页面引用 + 数据库关联列**

| 能力 | 说明 |
| --- | --- |
| 页面引用 | ✅ `@提及` 引用页面 |
| 数据库 relation | ✅ 表格列可建行级关联(类 Notion 数据库关联) |
| 链接带属性 | ⚠️ relation 仅数据库内,自由页面间无属性关系 |
| 三元组建模 | ⚠️ 借数据库 relation 可拼出有限三元组,不可全局查询 |
| 图谱视图 | ❌ |

## 四、MCP 与 AI 接入

**评级:T1 —— 官方 API(自托管)+ 内置 AI,无官方 MCP**

| 维度 | 说明 |
| --- | --- |
| 官方 MCP | ❌ |
| 自有 API | ✅ AppFlowy Cloud(含自托管)提供 API;客户端无开放 API |
| MCP 路径 | 社区适配器 → Cloud API → 工作区 |
| 内置 AI | ✅ 会议纪要/转录/Chat;**自托管可指向本地模型(Ollama 等),数据不出网** |

**优势场景**:
- 会议场景独一份:边开会边转录,说话人自动区分,纪要直接成页
- AI Chat 可选多个页面作上下文(多文档 RAG)

**短板**:无官方 MCP;单机模式数据无开放接口;Android 同步偶发滞后(需强杀重启)。

## 六、适用场景评分

| 场景 | 评分 | 说明 |
| --- | --- | --- |
| Notion 平替(个人) | ⭐⭐⭐⭐ | 数据库/看板/日历最接近 Notion |
| 会议记录自动化 | ⭐⭐⭐⭐⭐ | 实时转录+说话人+纪要,开源独此一家 |
| 移动端使用 | ⭐⭐⭐⭐ | iOS/Android 原生,但同步可靠性打折 |
| 知识图谱/三元组建模 | ⭐⭐ | 数据库 relation 有限,无全局查询 |
| 大库性能 | ⭐⭐ | 数千行数据库首开变慢 |
| 团队实时协作 | ⭐⭐⭐ | 可用但不如 Notion/Outline 打磨 |

## 总结

AppFlowy 是"**最像 Notion 的开源软件**"——数据库功能对齐度最高,加上 AI 会议纪要这个差异化杀手锏。技术选型(Flutter+Rust)换来了全平台原生覆盖和轻量客户端。但它是"工作台"而非"知识图谱":要 Trilium 式关系建模、脚本引擎、便携带走,都没有。适合从 Notion 迁出且重度依赖数据库视图的用户。

- 许可证:AGPL-3.0
- 技术栈:Flutter + Rust
