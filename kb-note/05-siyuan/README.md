## 二、存储方式

**范式:自有格式(.sy JSON)+ SQLite 索引混合**

```
SiYuanWorkspace/         # 工作空间(可自选位置)
├── data/                # 用户数据核心
│   ├── notebook1/
│   │   ├── doc.sy       # 文档块树(JSON)
│   │   └── assets/      # 附件
│   └── notebook2/
└── conf/                # 配置
(另有本地 SQLite 索引,可从 .sy 重建)
```

| 维度 | 说明 |
| --- | --- |
| 存储形态 | `.sy` 文件(JSON 块树)+ SQLite 索引 |
| 块结构 | ✅ 完整保留(JSON 描述块树,块有全局 ID),功能上限高 |
| 纯文本 | ⚠️ JSON 半开放,理论可程序化解析,但人类直接阅读困难 |
| Git | ⚠️ 可 diff 但不可读 |
| 迁移 | ⚠️ 依赖导出功能(MD 导出损失块级信息/属性数据库) |
| 索引 | 本地 SQLite,丢失可从 .sy 重建 |
| 大数据量 | ✅ 数据库优化,十万级块 |

**优点**:块级结构完整、有索引性能好、功能上限高。
**缺点**:半锁定(迁移有损)、JSON 人类不可读。

## 三、链接功能

**评级:L4-L5(块引用最精细 + 属性数据库可做关系建模)**

**链接语法**:

| 语法 | 功能 |
| --- | --- |
| `[[文档名]]` | 文档链接 |
| `((块ID))` | **块引用**(搜索式插入,五款中最精细) |
| `((块ID "文本"))` | 带锚文本的块引用 |
| 静态原型块 | 动态/静态引用 |
| 嵌入块 | 块嵌入(Transclusion) |

**块级粒度**:任何块(段落/列表项/表格行)有全局 ID,引用、反链、**提及检测**(正文文字提及但未链接)都以块为单位——块级能力五款最精细。

**属性 + 数据库视图**(与 Trilium 关系系统呼应):
- 文档/块可挂属性(键值对)
- **属性数据库视图**:带属性的文档聚合为表格/看板/日历/画廊,可筛选、可分组——相当于把三元组变成可多视图的"关系表"

**三元组建模专项**:强(⭐⭐⭐⭐)——块属性 + 数据库视图,仅次于 Trilium 的原生 relation。

## 四、MCP 与 AI 接入

**评级:T1 —— 官方 API 最完整(含 SQL 查询)**

| 维度 | 说明 |
| --- | --- |
| 官方 MCP | ❌(社区适配) |
| **官方 HTTP API** | ✅ **kernel,默认 `127.0.0.1:6806`,token 鉴权,功能最完整之一** |
| API 覆盖 | 块级 CRUD、**SQL 查询**、模板、导出、笔记本管理 |
| MCP 路径 | 社区 siyuan-mcp-server 等适配器 → 官方 API → 笔记库 |
| 配置难度 | 中(token + 适配器;本地 API 需手动开启) |
| 内置 AI | ✅ 官方 AI 助手(**付费订阅**,可自配 API Key 走自有模型) |

**优势**:
- **SQL 查询接口让 AI 检索最精确**(比全文检索精准)
- 块级 API 与块级双链天然匹配,适配器能力上限高

**短板**:官方 AI 收费;MCP 依赖社区适配;需手动开启本地 API。

## 五、便携支持

**评级:官方便携版,程序+数据可一体(策略 A 可行)**

| 维度 | 说明 |
| --- | --- |
| 官方便携版 | ✅ **官方提供 Windows Portable zip**,解压即用,不写注册表 |
| 数据位置 | ✅ workspace 可自选(选 U 盘目录则程序+数据一体便携) |
| 免安装跨机 | ✅ 便携版解压即用 |
| 注意事项 | 便携版与安装版勿混用同一 workspace;.sy 数据脱离程序不可直读 |

**方案**:官方便携版解压到 U 盘 + workspace 指向 U 盘目录 = 程序数据一体便携(与 Trilium 同级的策略 A 支持)。
