# AFFiNE 档案

[返回总览](../note-soft.md)

- 项目:https://github.com/toeverything/AFFiNE
- 定位:"All-In-One KnowledgeOS",Notion + Miro 的开源替代
- 一句话:**文档 + 无限白板 + 数据库三合一的唯一开源方案,CRDT 本地优先,内置多模态 AI,但无脚本引擎、无关系属性**

## 一、笔记功能

| 能力 | 说明 |
| --- | --- |
| 编辑范式 | 块编辑器(BlockSuite):段落/标题/媒体/数据库一切皆块,`/` 命令 |
| **双模式** ⭐ | **Page(文档)⇄ Edgeless(无限画布)一键切换**——白板元素是活数据对象,可转任务/数据库行/链接文档 |
| 数据库 | 表格/看板/日历/画廊多视图,同一数据多视角(类 Notion) |
| 任务管理 | 看板 + 数据库视图 |
| 内置 AI | ✅ 多模态:写作/总结/整理/翻译,自托管可配自己的模型 |
| 协作 | CRDT 实时多人编辑(离线可用,重连合并) |
| 移动端 | PWA(非原生 App) |
| 导入/导出 | Notion 导入;Markdown 导出 |

## 二、存储方式

**三层架构:元数据与内容分离,CRDT 操作日志为底**

| 层 | 技术 | 职责 |
| --- | --- | --- |
| OctoBase | Rust CRDT 引擎 | 冲突解决、实时同步、持久化(扁平操作日志) |
| BlockSuite | TypeScript | 块编辑框架,文档/白板同一数据模型渲染 |
| AFFiNE App | React + Electron | 桌面/Web/自托管服务 |

- **本地优先**:每次按键先落本地 SQLite,离线全功能;P2P 或自托管服务器同步
- **自托管**:Docker Compose 四件套 —— AFFiNE server + PostgreSQL 16 + Redis 7 + 对象存储(blob 文件);默认端口 3010,首个注册用户即管理员
- **备份**:桌面单机模式=本地 SQLite 文件;自托管=PostgreSQL + 对象存储快照
- **Git diff**:❌ 二进制/操作日志不可读
- ⚠️ 数据模型为块结构,导出 Markdown 有损(白板/数据库视图退化)

## 三、链接功能

**评级:L2-L3 —— 双链可用,关系无属性**

| 能力 | 说明 |
| --- | --- |
| 双链 | ✅ `[[页面]]` 引用 |
| 块引用 | ✅ 块级引用 |
| 白板连线 | ✅ Edgeless 模式卡片连线(视觉关系,非结构化数据) |
| 链接带属性 | ❌ 无 relation 概念,边不存属性、不可查询 |
| 三元组建模 | ❌ 需外挂数据库视图变通 |
| 图谱视图 | ⚠️ 无 Obsidian 式全局图谱 |

## 四、MCP 与 AI 接入

**评级:T1 —— 官方 API + 内置 AI,无官方 MCP**

| 维度 | 说明 |
| --- | --- |
| 官方 MCP | ❌ |
| 自有 API | ✅ 自托管提供 REST API(工作区/文档 CRUD),云端有 API v1 |
| MCP 路径 | 社区适配器 → REST API → 工作区 |
| 内置 AI | ✅ **三款中最强**:多模态写作/总结/翻译;自托管可指向本地或自有模型 |

**优势场景**:
- 应用内 AI 直接改写、总结、翻译文档,AI 编辑体验最顺
- 白板+文档同一数据模型,AI 生成的结构可在两种视图复用

**短板**:无官方 MCP;桌面单机模式无开放 API(需自托管);链接无语义,AI 做不了图谱级检索。

## 总结

AFFiNE 的不可替代点是 **Edgeless 双模式**——文档和白板是同一份数据的两种视图,白板上的便签能直接变成数据库行。内置 AI 在三款 Notion 系替代中最强。但**哲学与 Trilium 相反**:AFFiNE 追求"大而全的统一工作台",Trilium 追求"可编程的树+关系"。要白板选 AFFiNE,要图谱和脚本选 Trilium。
