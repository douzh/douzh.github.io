# Notion 档案

[返回总览](../note-soft.md)

- 官网:https://www.notion.com(闭源,云端订阅制)
- 定位:All-in-one 工作空间(笔记 + 知识库 + 项目管理 + 数据库 + AI)
- 一句话:**块 + 数据库范式的定义者与商业标杆——内置 AI 最成熟、官方托管 MCP 最完善,但纯云端闭源,数据主权最弱一档**

## 开源情况

| 维度 | 说明 |
| --- | --- |
| 许可证 | ❌ **专有软件(完全闭源)** |
| 开放范围 | 官方 REST API(公开完善)+ 官方托管 MCP Server;客户端与数据层完全闭源 |
| 治理主体 | Notion Labs Inc.(旧金山,创始人 Ivan Zhao/赵奕 + Simon Last) |
| 商业模式 | 免费版 + 订阅:Plus $10-12/人/月、Business $18-20/人/月、Enterprise 定制;**2025-05 起取消独立 $10 AI 附加费,AI 直接捆绑进付费计划**(个人用 AI 约 $18/月起) |
| 闭源+云端的双重风险 | 数据存厂商服务器;导出 Markdown/CSV/HTML 有损(块结构/数据库关联丢失);免费版历史仅 7 天 |
| 风险对冲 | API 完备可编程导出;社区有 notion2md 等备份工具;但无本地文件兜底 |

## 二、存储方式

**范式:纯云端块数据库(闭源)**

| 维度 | 说明 |
| --- | --- |
| 存储形态 | Notion 服务器上的块结构数据库,本地无文件 |
| 数据主权 | ❌ 弱:云端闭源,依赖厂商存活 |
| 备份 | 导出 Markdown/CSV/HTML/PDF 或走 API 编程备份 |
| 纯文本 | ❌ |
| 导出 | ⚠️ MD/CSV/HTML;**块结构、数据库关联、内嵌视图导出有损** |
| 迁移 | AppFlowy/AFFiNE 有 Notion 导入器(官方 2022 年后开放 API 支持);文本可迁,复杂数据库半损 |
| 离线 | ⚠️ 有限 |
| 大数据量 | ⚠️ 单页数千块后明显变慢 |

**优点**:零运维、协作最强、API 完备可编程访问、多端一致。
**缺点**:无本地文件兜底;深度依赖后任何导出都是"降级副本"。

## 三、链接功能

**评级:L3-L4 —— 正文链接弱,数据库 Relation 强**

| 能力 | 说明 |
| --- | --- |
| 页面链接 | ✅ `@提及`/`[[页面]]` |
| 反链面板 | ✅ Linked Mentions(含上下文) |
| 块级引用 | ✅ 可链接到块/数据库行(同步块 Synced Blocks 可跨页复用) |
| 属性/三元组 | ✅ **数据库 Relation 是带属性的结构化关系**——两表互链、Rollup 取对方属性,等价于关系型外键 |
| 知识图谱 | ⚠️ 无原生图谱视图(第三方工具或 SoQn 类嵌入) |

**定位**:两条腿——正文 mentions 只是跳转(L2),但数据库层面的 Relation/Rollup 是真正的结构化关系(可达 L4)。三元组建模能力 ≈ 思源(数据库派),弱于 Trilium(全局任意笔记挂 relation)。

---

## 四、MCP 与 AI 接入

**评级:T1+ —— 官方托管 MCP + 最成熟内置 AI(闭源阵营里最开放)**

| 维度 | 说明 |
| --- | --- |
| 官方 MCP | ✅ **官方托管 MCP Server**(https://mcp.notion.com/mcp),OAuth 授权,Claude/ChatGPT 等直接连接 |
| MCP 能力 | 搜索/读取/创建/更新页面、复制页面(支持异步任务)、查诂数据库(Business+AI 计划)、身份识别 |
| 官方 API | ✅ REST API 完备(页面/数据库/用户/搜索),2026 年新增 Developer Portal + 个人访问令牌(PAT) |
| 社区生态 | ✅ 大量第三方 MCP(improved-notion-mcp 等,token 优化 ~80%) |
| 内置 AI | ✅ **最成熟**:AI 写作/翻译/总结、AI Q&A 跨空间问答、AI Connectors(跨 Slack/Drive/GitHub/Jira 检索)、**自定义 AI Agents**(自动工作流)、会议纪要 |
| 配置难度 | 低(官方连接器走 OAuth 一键授权;API/PAT 走 token) |

**亮点**:Notion 是十款中唯一"官方托管 MCP + OAuth"的——无需本地起服务、无需手工 token 配置,Claude/ChatGPT 里点一下授权即用;且 MCP 能力与计划等级联动(数据库查询需 Business+AI)。
**短板**:AI 能力与订阅深度绑定(免费版 AI 额度极少);MCP 读写范围受工作区权限约束;闭源云端,自动化全部过厂商服务器。

## 五、便携支持

**评级:无便携性(纯云服务,策略 D)**

| 维度 | 说明 |
| --- | --- |
| 官方便携版 | ❌(桌面端为 Electron 壳) |
| 数据目录 | ❌ 无本地数据 |
| 程序+数据 U 盘一体 | ❌ |
| 数据脱离程序可读 | ❌ 仅导出文件/API 备份 |

**方案**:无。换机 = 登录账号;U 盘只能放导出备份。便携性诉求应直接排除 Notion,选 Trilium(全便携)或 Obsidian/Logseq(数据便携)。

## 六、适用场景与总结

| 场景 | 匹配度 |
| --- | --- |
| 团队协作/权限管理/评论流 | ⭐⭐⭐⭐⭐ 十款最强 |
| 项目管理(数据库+多视图) | ⭐⭐⭐⭐⭐ 品类定义者 |
| 应用内 AI 办公(Q&A/Agent/纪要) | ⭐⭐⭐⭐⭐ 最成熟全家桶 |
| AI 客户端官方 MCP 直连 | ⭐⭐⭐⭐⭐ 唯一官方托管+OAuth |
| 个人免费长期使用 | ⭐⭐ 免费版限制多 |
| 数据主权/离线/隐私 | ⭐ 纯云端闭源 |
| 便携/U 盘方案 | ❌ 无 |
| 性价比(个人) | ⭐⭐ 用 AI 约 $18/月起 |

> **总结:Notion 是"块 + 数据库"范式的定义者和商业标杆——协作、数据库、AI、MCP 四项都是十款中的天花板,官方生态(AppFlowy/AFFiNE/Anytype)全部以它为对标。代价同样极端:纯云端 + 闭源 + 订阅制,数据主权与便携性垫底,免费版限制逐年收紧。选型逻辑很清晰——团队协作/AI 办公/项目制工作选它;个人知识库重数据主权,则 01-05 开源系或 06-08 本地优先系全面占优。它与 Trilium 恰好是光谱两端:一个把一切交给云端换来最强协作,一个把一切握在本地换来最强自主。**
