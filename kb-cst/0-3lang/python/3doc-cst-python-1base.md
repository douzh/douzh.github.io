## 快速获取信息：dir help doc

**doc：查询命名空间所有名字**

dir([obj]) 显示对象的属性，如果没有提供参数， 则显示全局变量的名字

**help: 查询对象帮助或交互式帮助**

help([obj]) 以一种整齐美观的形式 显示对象的文档字符串， 如果没有提供任何参数， 则会进入交互式帮助。

**type: 查看对象类型**

type(obj)

**查看模块地址**

模块名.__file__

**Pip3**

如果通过命令安装，也可以每次都指定源

命令如：

```
 pip install SQLAlchemy -i https://pypi.doubanio.com/simple
-i https://pypi.tuna.tsinghua.edu.cn/simple
```
