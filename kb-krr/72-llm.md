# 本体与大模型：显式知识 × 隐式知识的双向增强

## 一句话定位

**本体是"显式、可推理、可审计"的知识，大模型（LLM）是"隐式、概率性、会幻觉"的知识——两者不是替代关系，而是互补：LLM 能加速建本体，本体能纠正并增强 LLM。** 这是当前本体领域最热的方向（GraphRAG、知识增强、本体学习）。

---

## 一、为什么不能互相替代

| 维度 | 本体 | LLM |
|---|---|---|
| 知识形式 | 显式公理（人可读、机器可验证）| 参数里的统计规律（不可直接读）|
| 正确性 | 逻辑保证（必然正确）| 概率正确（可能幻觉）|
| 可解释 | 推导链可回放 | 难以解释"为什么这么答"|
| 更新 | 精确可控（改一条公理）| 需重训或 RAG 注入 |
| 覆盖面 | 窄而深（建模过的领域）| 广而浅（海量文本）|
| 门槛 | 建模成本高 | 使用门槛极低 |

> 关键结论：**高确定性领域（医疗、法律、规范、金融风控）必须靠本体的"可证明"；开放场景（闲聊、创意、信息汇总）靠 LLM 的"广覆盖"。**

---

## 二、方向一：LLM 帮我们建本体（本体学习）

LLM 能把"自然语言 → 形式化公理"的成本大幅降低：

| 用法 | 示例 | 注意 |
|---|---|---|
| 术语抽取 | 从领域文档抽出候选概念/关系 | 需人工审核 |
| 生成类层级 | "把这些人组织成语义树" | 检查是否真 is-a |
| 生成 OWL 公理 | "用 OWL 表达：父亲=男人且有孩子" | 用推理器验证可满足性 |
| 补全/扩展本体 | 给现有本体提"缺哪些属性" | 别盲信，逐条验 |

**工作流建议**：LLM 草稿 → 人审 → **推理器验证**（[[40-reasoning]]）→ 入库。LLM 负责"提产能"，推理器负责"兜底正确性"，人负责"拍板"。

---

## 三、方向二：本体增强 LLM（知识注入与检索增强）

这是目前工程落地最热的点：

### ① RAG（检索增强生成）
```
用户问题
   ↓
在【知识库/图谱】检索相关片段
   ↓
拼进 prompt 喂给 LLM
   ↓
LLM 基于给定材料作答（减少幻觉）
```
- 纯文本 RAG：简单，但检索不到"隐含关系"；
- **本体/图谱 RAG**：把关系与规则也喂进去，能答"跨实体推理"问题。

### ② GraphRAG（图检索增强）
- 先把文档抽成实体-关系图（可用 LLM 抽、本体定 schema）；
- 检索时先定位子图（邻居/路径），再让 LLM 生成；
- **优势**：回答"多个实体间的关系/归纳性问题"远强于纯向量 RAG；
- 微软 GraphRAG 是代表性开源实现。

### ③ 用本体做"推理校验器"
- LLM 给答案 → 把答案转成断言 → 用本体推理器检查**一致性**（是否与公理矛盾）；
- 不矛盾才放行 → 能拦截一批"幻觉但逻辑矛盾"的输出。

---

## 四、一个综合架构示例

```
              ┌──────────────┐
  领域文本 ──→│ LLM 抽取实体/关系 │──→ 本体工程(TBox) 对齐
              └──────────────┘              │
                                            ↓
              ┌──────────────┐       知识图谱(实例数据)
  用户问题 ──→│ GraphRAG 检索 │←───────┘
              └──────────────┘
                        ↓
              LLM 生成 + 本体一致性校验
                        ↓
                    最终答案
```

---

## 五、边界与趋势

- **边界**：LLM 不能替代本体的"可证明性"；本体也不能覆盖 LLM 的"开放性"。二者各司其职。
- **趋势**：
  - 本体自动学习（LLM+推理器协同）逐步成熟；
  - GraphRAG 成为企业知识问答标配；
  - 智能体（Agent）用本体做"工具与知识的路由/校验"（工具调用前的 schema 校验）。

---

## 记忆口诀

- **本体 = 显式可证明，LLM = 隐式广覆盖**；
- **LLM 建本体**：草稿 → 人审 → 推理器验；
- **本体助 LLM**：RAG（检索）、GraphRAG（子图）、校验（拦幻觉）。

一句话总结：**本体与 LLM 是"知识的一体两面"——让 LLM 出产能、本体保正确，组合起来才是既广又准、既灵活又可审计的知识系统。**
