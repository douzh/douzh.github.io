# 人工合成淀粉

- who: 中国科学院
- when: 2021年9月23日
- what: 非光合作用人工合成淀粉

2021年9月23日，中国科学院召开本年度首场新闻发布会，介绍该院天津工业生物技术研究所在人工合成淀粉方面取得的重要进展。该所研究人员提出了一种颠覆性的淀粉制备方法，不依赖植物光合作用，以二氧化碳、电解产生的氢气为原料，成功生产出淀粉，在国际上首次实现了二氧化碳到淀粉的从头合成，使淀粉生产从传统农业种植模式向工业车间生产模式转变成为可能，取得原创性突破。相关研究成果9月24日在线发表于《科学》杂志。

目前，淀粉主要由绿色植物通过光合作用固定二氧化碳进行合成。在玉米等农作物中，将二氧化碳转变为淀粉涉及60余步的代谢反应和复杂的生理调控，太阳能的理论利用效率不超过2%。农作物的种植通常需要数月的周期，使用大量的土地、淡水、肥料等资源。

中科院天津工业生物所研究人员从头设计了11步主反应的非自然二氧化碳固定与人工合成淀粉新途径，在实验室中首次实现了从二氧化碳到淀粉分子的全合成。

研究团队采用了一种类似“搭积木”的方式，联合中科院大连化学物理研究所，利用化学催化剂将高浓度二氧化碳在高密度氢能作用下还原成碳一（C1）化合物，然后通过设计构建碳一聚合新酶，依据化学聚糖反应原理将碳一化合物聚合成碳三（C3）化合物，最后通过生物途径优化，将碳三化合物又聚合成碳六（C6）化合物，再进一步合成直链和支链淀粉（Cn化合物）。

“这一人工途径的淀粉合成速率是玉米淀粉合成速率的8.5倍，向设计自然、超越自然目标的实现迈进了一大步，为创建新功能的生物系统提供了新的科学基础。”

在充足能量供给的条件下，按照目前的技术参数推算，理论上1立方米大小的生物反应器年产淀粉量相当于我国5亩土地玉米种植的平均年产量。这一成果使淀粉生产的传统农业种植模式向工业车间生产模式转变成为可能，并为二氧化碳原料合成复杂分子开辟了新的技术路线。

该成果为从二氧化碳到淀粉生产的工业车间制造打开了一扇窗，如果未来该系统过程成本能够降低到与农业种植相比具有经济可行性，将会节约90%以上的耕地和淡水资源，避免农药、化肥等对环境的负面影响，提高人类粮食安全水平，促进碳中和的生物经济发展，推动形成可持续的生物基社会。

截至2026年1月，人工合成淀粉领域的最新进展集中在**降本增效、工程化放大与多路径拓展**三方面，以中国科学院天津工业生物技术研究所的成果最为突出，技术正加速迈向工业化示范阶段。以下是核心信息：

一、CO₂合成淀粉核心突破（2026年1月最新）

1.  **产量与效率飞跃**：天津工生所团队完成新一轮测试，淀粉合成产量较2021年原始版本提高10倍以上，生产强度较1.0版本提升136倍；合成速率是玉米的8.5倍，能量转化效率达自然光合作用的3.5倍。
2.  **关键酶优化**：核心的甲醛聚合酶活性大幅提升，用量减少、酶成本显著降低，同时反应体系通过化学—生物耦合催化优化，路径更精简高效。
3.  **工程化推进**：2022年底建成工程化测试平台，2025年进入吨级中试阶段，千吨级示范线建设提速，单反应器日产淀粉量已可匹配5亩玉米田年产量，且摆脱耕地、淡水等资源依赖。

二、纤维素合成淀粉新路径（2025年11月）

天津工生所张以恒团队实现纤维素全碳素利用合成淀粉，核心成果包括：

1.  创新葡萄糖回收与活化机制，理论淀粉得率从50%提升至100%，解决碳损耗问题。
2.  筛选热稳定酶元件，将反应温度提至50℃，增强酶活性并降低用量，纤维素到淀粉真实转化率达93.3%。
3.  产物为结构均一的纯直链淀粉，聚合度可控，已应用于手性分离填料，实现部分医药材料国产替代。

三、产业化与应用前景

1.  **成本与场景**：当前核心目标是将成本降至农业种植水平，若达成，可节约耕地淡水、减少农业污染，同时助力“双碳”，还能为特殊环境（如太空、荒漠）提供粮食解决方案。
2.  **市场与资本**：2025年全球相关潜在市场超百亿美元，产业联盟（科研+能源+生物企业）加速形成，专利布局密集，2026年有望迎来首条千吨级示范线投产。
3.  **产物定制化**：可定向合成直链/支链淀粉，适配食品、医药、生物基材料等多元需求，高纯度淀粉在高端领域已展现独特价值。

## 成本

截至2026年1月，人工合成淀粉吨完全成本约1.85万元（约18.5元/公斤），远高于玉米淀粉市场价（2.5-3元/公斤），核心成本集中在酶制剂（占比约65%）与绿氢（占比约24%），规模化与绿电替代是关键降本路径。以下是成本详情、对比与降本预测：

一、当前成本构成（吨淀粉）

- 酶制剂：约1.2万元，核心是甲醛聚合酶等10余种酶，活性与稳定性不足导致用量大、成本高。
- 绿氢：约4500元，占能源成本大头，依赖可再生电能制氢，当前绿氢价格约30元/公斤。
- 其他（含设备折旧、电能、辅料、人工等）：约2000元，规模化后可显著摊薄。

二、与传统种植的成本对比

- 玉米淀粉：市场价2.5-3元/公斤，成本含耕地租金、种子、化肥、灌溉、机械等，受自然条件与周期影响大。
- 人工合成淀粉：当前成本为传统的6-7倍，但能耗效率是玉米的3.5倍，且节约耕地、淡水，碳减排潜力大。

三、降本关键路径与目标

1. 酶制剂降本：通过AI设计高活性突变体、提高热稳定性（如50℃反应）、实现酶重复利用，每提升1倍酶活性，成本下降约15%，目标2027年酶成本降至3000元/吨以内。
2. 绿氢与电能降本：布局可再生能源富集区（如内蒙古、宁夏），2027年绿氢成本有望降至18-20元/公斤，绿电度电成本降至0.1-0.2元，可显著降低能源成本。
3. 规模化效应：10kl中试线可摊薄设备与管理成本，2027年吨成本有望降至6800元（6.8元/公斤）；2030年千吨级扩产叠加碳价收益（碳价≥80元/吨时，吨淀粉可额外收益约120元），成本或降至与玉米淀粉持平。

四、挑战与变量

- 酶稳定性与规模化工艺待完善，连续化生产中酶失活问题仍需解决。
- 绿氢与绿电供应能力是外部关键变量，若可再生能源产能不足，降本周期可能延长。

## 各类淀粉

截至2026年1月30日，国内各类淀粉现货价格分化明显，玉米淀粉价格最低，马铃薯淀粉最高，人工合成淀粉成本仍显著高于传统品种，以下是分品类价格详情、期货参考与影响因素：

主流淀粉现货价格（元/吨，1月30日）

1. 玉米淀粉：现货主流2500-2810，山东2780、东北2500-2630，生意社基准价2810，期货主力约2529；价格受玉米成本、库存与副产品收益影响，近期稳中小涨。
2. 木薯淀粉：泰国粉3500-3750，越南粉3280-3400，广西边贸3200-3500；港口低库存与节前备货支撑价格，泰粉因原料紧张偏强。
3. 马铃薯淀粉：一级粉主流5700，优级粉7800；主产区开工率与库存低位，挺价心态明显，下游需求缓慢恢复。
4. 红薯淀粉：食品级主流6000-7000，因季节性供应与手工/半机械化生产，价格波动大，节日备货期略涨。
5. 豌豆淀粉：食品级主流4500-5000，受进口豌豆成本与国内加工产能影响，近期稳定。
6. 人工合成淀粉：吨完全成本约18500（18.5元/公斤），远高于传统品种，核心成本为酶制剂与绿氢。

价格影响因素

- 原料成本：玉米、木薯、马铃薯等原料价格直接决定传统淀粉成本，人工合成则依赖酶与绿氢价格。
- 供需与库存：节前备货、主产区开工率、港口/工厂库存影响短期价格波动。
- 工艺与规模：传统淀粉依赖种植与加工规模，人工合成受酶活性、绿电成本与规模化程度制约。

## 不同淀粉用途

不同淀粉因**分子结构（直链/支链占比）、糊化特性、粘度、稳定性、凝沉性**等差异，用途高度细分，核心分为**工业级、食品级、专用功能性**三大类，玉米淀粉是基础通用款，薯类/豆类淀粉主打高端食品应用，人工合成淀粉目前聚焦高纯度专用场景，以下是主流淀粉的核心特性与细分用途（按市场规模排序），同时标注适配场景的关键特性，方便对应选型：

玉米淀粉（市场占比超70%，最通用）

**核心特性**：糊化温度中等（62-72℃）、粘度适中、成本最低，直链淀粉占25%-30%，支链占70%-75%
**核心用途**：
1. 基础工业原料：造纸（施胶、涂层，提升纸张强度）、纺织（浆纱，增加纱线韧性）、建材（腻子、涂料，增稠保水）、日化（牙膏、洗面奶，增稠定型）；
2. 食品通用款：方便面、饼干、糕点的原料填充，肉制品保水增弹，勾芡（普通菜肴），淀粉糖（葡萄糖、果葡糖浆，饮料/烘焙用）；
3. 深加工基底：生产变性淀粉（醋酸酯、磷酸酯淀粉），适配各行业定制需求，是变性淀粉最主要原料。

木薯淀粉（进口主流，第二大通用款）

**核心特性**：支链淀粉占比超80%（高直链品种除外）、糊化温度低（52-59℃）、糊液透明、冻融稳定性好、凝沉性弱
**核心用途**：
1. 速冻食品核心：速冻水饺、汤圆、烧麦，避免冷冻后开裂、回生，保持口感软糯；
2. 休闲食品与烘焙：薯片、虾条的膨松剂，蛋糕、慕斯的增稠剂，提升成品细腻度；
3. 工业与深加工：饲料粘结剂（颗粒饲料，防止破碎），生产变性淀粉（醚化淀粉），适配印染、石油钻井（降滤失剂）；
4. 饮品与酱料：奶茶、椰果的增稠剂，甜面酱、沙拉酱的定型剂，糊液透明不影响外观。

马铃薯淀粉（高端食品款，价格最高）

**核心特性**：支链淀粉占比75%-80%、颗粒大、糊化粘度极高、糊液透明、成膜性好、口感爽滑
**核心用途**：
1. 高端餐饮勾芡：鲁菜、粤菜等精致菜肴，勾芡后汤汁清亮、挂汁不浑，如糖醋鱼、高汤羹；
2. 高端食品原料：粉丝、粉条（纯马铃薯粉条耐煮、不粘条），火锅丸子、鱼豆腐（提升弹脆度），酸奶、果冻的增稠剂；
3. 烘焙与面点：高端蛋糕、泡芙，提升蓬松度与细腻度，速冻面点的品质改良剂；
4. 精细工业：医药胶囊（成膜材料），高端造纸（艺术纸、铜版纸），化妆品（粉底、面膜，增稠且肤感顺滑）。

红薯（甘薯）淀粉（中式特色款）

**核心特性**：粘度高、筋度强、成丝性好，中式传统工艺适配性佳，分精制粉与粗粉
**核心用途**：
1. 中式特色食品：红薯粉丝、粉条、粉皮（传统经典，口感筋道），凉粉、凉面的原料，炸酥肉（裹粉，提升酥脆度且不易回软）；
2. 中式烹饪：湘、川、豫菜的勾芡，如酸辣粉、胡辣汤，提升汤汁浓稠度与筋度，肉制品滚揉保水；
3. 农家与地方食品：红薯糕、糍粑，特色糕点的原料，部分饲料粘结剂。

豌豆淀粉（高直链特色款，专用性强）

**核心特性**：高直链淀粉品种占比超50%、糊化后凝胶强度高、成丝性极佳、口感筋道耐煮
**核心用途**：
1. 纯淀粉制品核心：龙口粉丝、水晶粉丝（主打豌豆淀粉，透明、耐煮、不粘），凉粉、刮凉粉的专用原料；
2. 食品改良剂：肉制品（火腿、香肠），提升凝胶强度与切片性，烘焙食品的抗老化剂；
3. 功能性食品：高直链豌豆淀粉可生产抗性淀粉，适配低升糖、膳食纤维食品，医药辅料（片剂粘结剂）。

小麦淀粉（澄粉，中式面点专用）

**核心特性**：直链淀粉占比20%-25%、糊化后成膜性好、口感软糯、无小麦面筋
**核心用途**：
1. 中式特色面点：水晶虾饺、烧卖、肠粉的皮料（透明软糯，无筋度），冰皮月饼、糯米糍的原料；
2. 食品加工：面筋生产的副产品，肉制品保水，酱料增稠，部分烘焙食品的低筋填充料。

人工合成淀粉（新一代专用款，目前小众）

**核心特性**：**结构可控（可定向合成纯直链/纯支链）、纯度100%、无杂质、理化特性均一**，区别于天然淀粉的成分复杂性
**当前核心用途**（尚未产业化，聚焦高附加值场景）：
1. 高端医药：手性分离填料（纯直链淀粉适配），药物载体、医用敷料的原料，纯度高无杂质，符合医药级标准；
2. 功能性食品：精准定制的抗性淀粉、低升糖淀粉，适配特殊膳食（糖尿病、减脂人群）；
3. 生物基材料：高纯度支链淀粉生产可降解塑料、生物粘合剂，性能优于天然淀粉；
4. 科研与定制化：适配合成生物学、材料科学的实验原料，可按需调整聚合度与结构。

补充：变性淀粉（各类原淀粉深加工产物，定制化适配）

由玉米/木薯/马铃薯淀粉经化学/物理/生物改性制成，是各行业**定制化专用款**，比如：
- 醋酸酯淀粉：食品保鲜、造纸涂层，提升耐水性；
- 交联淀粉：肉制品、罐头，耐酸耐温，不易糊化；
- 醚化淀粉：石油钻井、印染，提升粘度稳定性；
- 预糊化淀粉：速食粥、代餐粉，冷水即可溶解，无需加热糊化。

核心选型总结（按场景快速匹配）

1. 成本优先、通用工业/普通食品→玉米淀粉；
2. 速冻食品、透明糊液需求→木薯淀粉；
3. 高端勾芡、粉丝粉条、高粘度需求→马铃薯淀粉；
4. 中式特色粉丝、凉粉→豌豆淀粉/红薯淀粉；
5. 水晶面点、无筋度面点→小麦淀粉；
6. 高端医药、生物基材料、定制化功能→人工合成淀粉（未来方向）。

## 粮食消耗

2024年中国粮食总消费量约8.25亿吨，以下按消费用途与粮食品种分类，结合权威机构估算数据（农业农村部、中国农业展望报告等）详细统计。

一、按消费用途分类（单位：亿吨，占比）

1. 口粮消费：约2.95亿吨，占比35.8%。居民直接食用的粮食，以稻谷、小麦为主（占口粮90%以上），人均口粮消费124.4公斤（原粮口径），同比略降，因膳食结构升级，米面主食需求减少。
2. 饲料用粮：约2.8亿吨，占比33.9%。用于畜禽养殖，玉米、豆粕是核心原料，因生猪产能稳定、禽类养殖增长，饲料用粮较2023年小幅上升，占比提升明显。
3. 工业用粮：约1.92亿吨，占比23.3%。用于淀粉、酒精、调味品等食品加工及生物能源等，玉米、小麦、大豆、薯类是主要原料，需求基本稳定，食品加工领域占比超70%。
4. 其他消费及损耗：约0.58亿吨，占比7.0%。含种子用粮（约0.12亿吨）、储存运输损耗等，损耗率随仓储物流技术提升继续下降，比2023年减少0.26亿吨。


二、按粮食品种分类（单位：亿吨）

1. 稻谷：约1.92亿吨，口粮消费占比85%以上，主要用于居民直接食用，少量用于饲料和工业加工，消费量与2023年基本持平。
2. 小麦：约1.21亿吨，口粮消费（制粉为主）约0.83亿吨，占比68.6%，饲用消费约0.22亿吨（因玉米价格回落，同比大幅减少0.13亿吨），工业及种用约0.16亿吨。
3. 玉米：约3.6亿吨，饲料消费占比62%（约2.23亿吨），工业消费占比28%（约1.01亿吨），口粮消费占比不足5%，是消费总量最大的品种，同比增长约0.1亿吨。
4. 大豆：约1.22亿吨，压榨需求约1.05亿吨（产豆油和豆粕，豆粕用于饲料），食用消费约0.17亿吨，消费量较2023年略有增加，进口依赖度仍超80%。
5. 薯类（折原粮）：约0.31亿吨，部分作为口粮，部分用于食品加工和饲料，需求稳定。
6. 其他谷物（高粱、大麦等）：约0.89亿吨，主要用于饲料和工业用粮，因养殖需求带动，同比增长约0.07亿吨。

三、核心变化与说明

1. 消费结构变化：饲料用粮占比首次超33%，成为第一大消费领域；口粮占比持续小幅下降，符合居民膳食结构升级趋势。
2. 数据来源：部分为《中国农业展望报告（2024—2033）》估算值，最终官方数据以国家统计局、农业农村部发布为准。
3. 统计口径：均为原粮口径，不含加工后的副产品（如米糠、麸皮），与部分行业统计口径可能存在差异。
