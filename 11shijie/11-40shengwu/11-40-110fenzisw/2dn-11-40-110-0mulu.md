# 分子生物学

分子生物学是研究生物大分子（DNA、RNA、蛋白质、酶等）的结构、功能、相互作用及生命活动分子机制的核心学科，其研究领域随技术发展不断细分和拓展，以下按“核心机制→技术方法→应用方向→前沿交叉”的逻辑，结构化梳理分子生物学的所有研究领域，明确每个方向的研究对象与核心内容：

### 一、核心分子机制研究（分子生物学的基础核心）
1. **遗传信息传递机制**
   - 研究对象：DNA、RNA、聚合酶、转录因子等
   - 核心内容：DNA复制（起点识别、引物合成、链延伸、修复耦合）、转录（启动子结合、RNA剪接、终止机制）、翻译（核糖体组装、密码子识别、肽链合成与折叠）、逆转录（逆转录酶功能、cDNA合成）
2. **基因表达调控**
   - 研究对象：调控序列（启动子、增强子、沉默子）、转录因子、非编码RNA、表观修饰酶
   - 核心内容：转录水平调控（转录因子结合、染色质构象变化）、转录后调控（mRNA稳定性、miRNA/lncRNA介导的沉默）、翻译水平调控（核糖体结合效率、翻译抑制因子）
3. **分子间相互作用**
   - 研究对象：蛋白-蛋白、蛋白-核酸（DNA/RNA）、蛋白-小分子（激素、药物）复合物
   - 核心内容：相互作用的特异性识别机制、结合动力学与亲和力、复合物结构解析（如转录复合物、DNA修复复合物）
4. **DNA损伤与修复**
   - 研究对象：DNA损伤（断裂、甲基化、嘧啶二聚体）、修复酶（DNA连接酶、聚合酶、内切酶）
   - 核心内容：碱基切除修复、核苷酸切除修复、同源重组修复、非同源末端连接、错配修复，以及修复缺陷与疾病的关联

### 二、表观遗传学（基因表达的表观调控）
1. **DNA甲基化与去甲基化**
   - 研究对象：CpG岛、DNA甲基转移酶、去甲基化酶
   - 核心内容：甲基化位点的建立与维持、对基因沉默的调控作用、发育过程中的表观遗传重编程
2. **组蛋白修饰**
   - 研究对象：组蛋白（H1、H2A、H2B、H3、H4）、修饰酶（乙酰转移酶、甲基转移酶、激酶）
   - 核心内容：乙酰化、甲基化、磷酸化等修饰的功能、修饰之间的交叉对话、染色质状态调控（常染色质/异染色质转换）
3. **非编码RNA调控**
   - 研究对象：miRNA、lncRNA、circRNA、siRNA
   - 核心内容：非编码RNA的合成与加工、靶向mRNA的机制、在细胞分化、肿瘤发生中的调控作用
4. **染色质重塑**
   - 研究对象：染色质重塑复合物（SWI/SNF、ISWI等）、核小体
   - 核心内容：核小体滑动与组装、染色质空间构象变化、对基因表达的影响

### 三、分子进化与比较分子生物学
1. **分子进化机制**
   - 研究对象：不同物种的同源基因、DNA/蛋白质序列
   - 核心内容：基因突变率、自然选择与中性进化、分子钟理论、物种分化的分子证据
2. **比较基因组学**
   - 研究对象：不同物种的全基因组序列、基因家族
   - 核心内容：基因家族的扩张与收缩、保守序列分析、物种特异性基因的功能的研究
3. **分子系统发育学**
   - 研究对象：序列比对数据、分子标记（如16S rRNA、COI基因）
   - 核心内容：系统发育树构建、物种亲缘关系推断、水平基因转移的检测

### 四、技术方法与工具开发（分子生物学的技术支撑）
1. **基因克隆与载体构建**
   - 研究对象：目的基因、克隆载体（质粒、噬菌体、病毒载体）、宿主细胞（大肠杆菌、酵母、哺乳动物细胞）
   - 核心内容：PCR扩增、限制性内切酶切割、DNA连接、载体转化与筛选、重组蛋白表达系统优化
2. **测序技术与应用**
   - 研究对象：DNA/RNA片段、测序文库、测序平台（一代Sanger、二代Illumina、三代PacBio/Nanopore）
   - 核心内容：测序文库构建、序列拼接与组装、差异表达基因分析、甲基化测序、单细胞测序
3. **基因编辑技术**
   - 研究对象：CRISPR-Cas9系统、碱基编辑器、Prime Editing、锌指核酸酶（ZFN）、TALEN
   - 核心内容：编辑工具的优化（特异性提升、脱靶率降低）、体内/体外编辑效率、编辑后的修复机制
4. **分子检测与定量技术**
   - 研究对象：核酸（DNA/RNA）、蛋白质、小分子标志物
   - 核心内容：实时荧光定量PCR（qPCR）、Western Blot、ELISA、原位杂交（FISH）、流式细胞术、生物传感器开发

### 五、应用导向的分子生物学研究
1. **分子医学与转化研究**
   - 研究对象：疾病相关基因、肿瘤细胞、病原体（病毒/细菌）、药物靶点
   - 核心内容：疾病的分子机制（如肿瘤驱动基因、遗传病致病基因定位）、分子诊断标志物筛选、靶向药物设计与研发、基因治疗载体构建
2. **农业分子生物学**
   - 研究对象：作物/畜禽的功能基因、抗逆/优质相关基因、转基因受体
   - 核心内容：抗虫/抗病/抗逆基因克隆、转基因作物培育、分子标记辅助育种（MAS）、基因编辑作物研发
3. **工业与环境分子生物学**
   - 研究对象：工业微生物（如酵母菌、细菌）、降解酶基因、环境污染物
   - 核心内容：工业酶的分子改造（提高活性/稳定性）、微生物代谢通路优化（发酵产物增产）、污染物降解基因的克隆与应用

### 六、前沿交叉领域（分子生物学与其他学科的融合）
1. **结构分子生物学**
   - 研究对象：生物大分子（DNA、蛋白质、复合物）的三维结构
   - 核心内容：X射线晶体学、核磁共振（NMR）、冷冻电镜（Cryo-EM）解析结构、结构与功能的关联分析
2. **单细胞分子生物学**
   - 研究对象：单个细胞的核酸（DNA/RNA）、蛋白质
   - 核心内容：单细胞测序（转录组、基因组、甲基化组）、细胞异质性分析、稀有细胞的分子特征鉴定
3. **合成分子生物学**
   - 研究对象：人工设计的基因回路、合成生物模块、代谢通路
   - 核心内容：生物零件的标准化、基因回路的构建（如 toggle switch、振荡器）、人工细胞合成、定制化代谢产物生产
4. **计算分子生物学与生物信息学**
   - 研究对象：生物大数据（序列、结构、表达谱数据）、算法模型
   - 核心内容：蛋白质结构预测（如AlphaFold）、基因功能预测、分子对接（药物设计）、调控网络建模、机器学习在分子生物学中的应用

### 七、特殊生物体系的分子生物学
1. **微生物分子生物学**
   - 研究对象：细菌、古菌、病毒、真菌的基因与分子机制
   - 核心内容：微生物的代谢调控、耐药基因的传播机制、病毒的复制与致病机制、微生物组的分子互作
2. **植物分子生物学**
   - 研究对象：植物激素信号通路、光合作用相关基因、抗逆基因、植物-微生物互作分子机制
   - 核心内容：植物发育的分子调控（开花、结果、衰老）、光信号传导、固氮作用的分子机制、植物免疫的分子基础
3. **动物分子生物学**
   - 研究对象：动物激素调控、免疫相关基因、神经信号分子、发育相关基因
   - 核心内容：动物胚胎发育的分子调控、免疫细胞的活化机制、神经递质合成与传递的分子机制、动物行为的分子基础
