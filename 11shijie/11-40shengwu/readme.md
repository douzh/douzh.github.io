# 生物学研究领域

### 一、基础生物学（聚焦生命本质的核心研究对象）
1. **分子生物学**
   - 研究对象：生物大分子（DNA、RNA、蛋白质、酶、糖类、脂质）
   - 核心方向：大分子结构与功能、遗传信息传递（复制/转录/翻译）、基因表达调控、分子相互作用、表观遗传修饰
   - [[2dn-11-40-110-0mulu]]
2. **细胞生物学**
   - 研究对象：细胞（原核细胞、真核细胞）及细胞器（线粒体、叶绿体、核糖体等）
   - 核心方向：细胞结构与分工、细胞代谢、分裂（有丝/减数分裂）、分化、凋亡、自噬、细胞信号传导、细胞膜运输机制
   - [[2dn-11-40-120-0mulu]]
3. **遗传学**
   - 研究对象：基因、染色体、遗传物质（核酸）
   - 核心方向：遗传规律（分离/自由组合定律）、基因传递与变异、基因突变与重组、群体遗传结构、基因定位与克隆、基因编辑
   - [[2dn-11-40-130-0mulu]]
4. **发育生物学**
   - 研究对象：生物个体（从受精卵到成熟个体）、胚胎、器官原基
   - 核心方向：胚胎发育（卵裂、分化、器官发生）、再生机制、发育调控网络（基因/激素）、个体发育与进化的关联
   - [[2dn-11-40-140-0mulu]]
5. **进化生物学**
   - 研究对象：生物类群（物种、种群）、遗传变异库、化石
   - 核心方向：生物起源、物种形成、演化规律（趋同/趋异进化）、系统发育关系、进化动力（自然选择/遗传漂变）、分子进化
   - [[2dn-11-40-150-0mulu]]
6. **生理学**
   - 研究对象：生物机体（器官、系统、组织）
   - 核心方向：器官/系统功能（呼吸、循环、消化等）、生理调节机制（神经/体液/免疫调节）、应激反应、稳态维持
   - [[2dn-11-40-160-0mulu]]
7. **生物化学**
   - 研究对象：生命活动中的化学物质（代谢底物、产物、酶、辅酶）
   - 核心方向：物质代谢通路（糖/脂/蛋白/核酸代谢）、酶促反应机制、代谢调控、生物能量转换（光合作用/呼吸作用）
   - [[2dn-11-40-170-0mulu]]

### 二、分类生物学（按生物类群划分的研究对象）
1. **微生物学**
   - 研究对象：微生物（细菌、古菌、病毒、真菌、原生生物、放线菌）
   - 核心方向：微生物分类与鉴定、代谢机制、致病性与耐药性、生态分布、工业应用（发酵、产酶）、微生物组互作
   - [[2dn-11-40-210-0mulu]]
2. **植物学**
   - 研究对象：植物（藻类、苔藓、蕨类、裸子植物、被子植物）
   - 核心方向：植物分类与系统发育、光合作用、激素调控、抗逆性（抗旱/抗虫）、生殖发育、植物与环境互作
   - [[2dn-11-40-220-0mulu]]
3. **动物学**
   - 研究对象：动物（无脊椎动物：昆虫、环节动物等；脊椎动物：鱼、两栖、爬行、鸟、哺乳类）
   - 核心方向：动物分类、行为学（迁徙/繁殖/社会行为）、生理适应性、免疫机制、物种保护
   - [[2dn-11-40-230-0mulu]]
4. **人类生物学**
   - 研究对象：人类个体、人类种群、人类细胞/组织
   - 核心方向：人类遗传规律、发育过程、生理机能、进化历程、人类与环境的相互作用、健康与疾病的生物学基础
   - [[2dn-11-40-240-0mulu]]

### 三、应用生物学（面向实际需求的研究对象与应用方向）
1. **医学/临床医学**
   - 研究对象：人类疾病（感染性疾病、遗传病、肿瘤等）、人体组织/细胞、药物靶点
   - 核心方向：疾病机制解析、诊断技术（分子诊断/影像诊断）、治疗方案（药物/手术/基因治疗）、疫苗研发、病理分析
2. **农业生物学**
   - 研究对象：农作物、畜禽、农业病虫害、土壤微生物
   - 核心方向：作物/畜禽育种（杂交/转基因/基因编辑）、病虫害生物防治、抗逆作物培育、肥料高效利用、农产品品质改良
3. **生物技术/生物工程**
   - 研究对象：工程菌、细胞系（CHO细胞、干细胞等）、生物大分子（重组蛋白/抗体）、代谢通路
   - 核心方向：基因工程改造、细胞工程（培养/融合）、发酵工程（产物规模化生产）、酶工程（酶固定化/改造）、生物制药/生物燃料生产
4. **生物信息学**
   - 研究对象：生物大数据（基因组序列、转录组数据、蛋白质结构数据）
   - 核心方向：序列比对与分析、基因功能预测、蛋白质结构建模、生物数据库构建、数据分析算法开发
5. **法医遗传学**
   - 研究对象：人体遗传标记（DNA片段、STR位点）、法医物证（血液、毛发等）
   - 核心方向：DNA指纹鉴定、亲子鉴定、嫌疑人溯源、物证保存与检测
6. **食品科学**
   - 研究对象：食品原料、食品微生物、食品添加剂、营养成分
   - 核心方向：食品加工工艺优化、保鲜技术、微生物污染控制、营养强化、食品安全性评估

### 四、生态与环境生物学（生物与环境的相互作用研究）
1. **生态学**
   - 研究对象：生物个体、种群、群落、生态系统（森林、草原、海洋等）、非生物环境（气候、土壤、水）
   - 核心方向：种群动态（增长/衰退）、群落演替、生态系统能量流动与物质循环、种间关系（捕食/竞争/共生）、景观生态格局
2. **环境生物学**
   - 研究对象：环境污染物（重金属、有机物、塑料）、受污染环境中的生物、生物监测指标生物
   - 核心方向：生物对污染物的响应机制、生物降解与环境修复（植物/微生物修复）、环境毒理学评估、生物监测技术
3. **保护生物学**
   - 研究对象：濒危物种、生物多样性（基因/物种/生态系统多样性）、自然保护区
   - 核心方向：物种濒危机制、保护策略（迁地/就地保护）、保护区规划、生物入侵防治、生物多样性评估与监测
4. **全球变化生物学**
   - 研究对象：全球变化因子（气候变暖、CO₂浓度升高、酸雨）、受影响的生物类群与生态系统
   - 核心方向：生物对全球变化的适应性进化、物种分布变迁、生态系统韧性、碳循环调控

### 五、交叉学科与前沿领域（多学科融合的研究对象）
1. **合成生物学**
   - 研究对象：人工设计的生物模块、合成细胞、重构代谢通路
   - 核心方向：生物体系人工设计与合成、生物传感器构建、生物制造（定制化产物）、人工酶设计
2. **组学领域（基因组学/转录组学/蛋白质组学/代谢组学）**
   - 研究对象：全基因组、转录组（mRNA/非编码RNA）、蛋白质组、代谢物组
   - 核心方向：全组学测序与分析、基因/蛋白/代谢物网络调控、疾病标志物筛选
3. **单细胞生物学**
   - 研究对象：单个细胞（体细胞、免疫细胞、肿瘤细胞等）
   - 核心方向：单细胞测序、细胞异质性分析、胚胎发育单细胞追踪、肿瘤细胞分型
4. **神经科学**
   - 研究对象：神经系统（大脑、脊髓、神经细胞）、神经信号、行为活动
   - 核心方向：神经细胞结构与功能、神经信号传导、认知/记忆/情绪的神经机制、脑机接口、神经退行性疾病
5. **生物物理学**
   - 研究对象：生物大分子、细胞膜、细胞骨架、生物电信号
   - 核心方向：生物大分子结构解析（X射线晶体学/NMR）、生物力学特性、生物电现象、分子马达机制
6. **生物数学**
   - 研究对象：生命现象（种群增长、疾病传播、生物节律）
   - 核心方向：数学模型构建（微分方程/统计模型）、生命过程定量分析、预测与模拟
7. **计算生物学**
   - 研究对象：生物数据、蛋白质/核酸结构、生物网络
   - 核心方向：人工智能辅助蛋白质结构预测、药物分子设计、生物图像分析、调控网络建模

### 六、关键技术支撑领域（服务于各研究的技术对象与方向）
- 研究对象：基因编辑工具（CRISPR-Cas9、碱基编辑器）、测序设备与试剂、成像仪器（冷冻电镜、超分辨显微镜）、细胞培养体系（培养基、类器官）、生物信息学软件（BLAST、SAMtools）
- 核心方向：技术优化与创新、高灵敏度检测方法开发、实验流程标准化、工具的通用性与特异性提升
