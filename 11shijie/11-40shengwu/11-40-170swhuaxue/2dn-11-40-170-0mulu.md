# 生物化学

生物化学是研究生命活动化学本质的核心学科，聚焦生物体内物质的组成、结构、代谢反应及调控机制，贯穿“分子→细胞→个体”的多层级，融合了化学、分子生物学、遗传学等多学科方法。以下按“核心物质与结构→代谢通路与调控→分子机制与功能→技术方法→应用方向→前沿交叉”的逻辑，结构化梳理生物化学的所有研究领域，明确每个方向的研究对象与核心内容：

### 一、生物大分子的结构与功能（生物化学的基础核心）
1. **蛋白质化学**
   - 研究对象：蛋白质（结构蛋白、酶、抗体、激素等）、氨基酸、肽键
   - 核心内容：蛋白质的一级结构（氨基酸序列）、二级结构（α-螺旋、β-折叠）、三级结构（空间构象）、四级结构（亚基组装）、蛋白质折叠与去折叠机制、蛋白质修饰（磷酸化、糖基化、乙酰化）、蛋白质结构与功能的关联（如酶的活性中心、抗体的抗原结合位点）
2. **核酸化学**
   - 研究对象：DNA、RNA（mRNA、tRNA、rRNA、非编码RNA）、核苷酸、核苷
   - 核心内容：核酸的一级结构（核苷酸序列）、二级结构（DNA双螺旋、RNA茎环结构）、三级结构（染色质包装、tRNA三维构象）、核酸的物理化学性质（变性、复性、杂交）、核酸与蛋白质的相互作用（如转录因子结合DNA）
3. **糖类化学（糖生物学）**
   - 研究对象：单糖（葡萄糖、果糖）、二糖（蔗糖、乳糖）、多糖（淀粉、糖原、纤维素）、糖复合物（糖蛋白、糖脂、蛋白聚糖）
   - 核心内容：糖类的结构解析（单糖组成、糖苷键类型）、糖复合物的合成与修饰、糖类的生理功能（能量供给、细胞识别、信号传导）、糖代谢与疾病的关联（如糖尿病、糖原累积症）
4. **脂质化学**
   - 研究对象：脂肪酸、甘油三酯、磷脂、固醇（胆固醇）、类脂（脂溶性维生素、激素）
   - 核心内容：脂质的结构与分类、脂质的物理化学性质（疏水性、相变）、脂质在生物膜中的作用（磷脂双分子层）、脂质的生理功能（能量储存、信号分子、膜结构组成）

### 二、生物代谢与能量转换（生命活动的化学动力）
1. **糖代谢**
   - 研究对象：葡萄糖、糖原、糖酵解/糖异生相关酶、三羧酸循环中间体
   - 核心内容：糖酵解（细胞质中葡萄糖分解为丙酮酸）、丙酮酸脱氢酶复合体反应、三羧酸循环（线粒体中能量生成）、糖异生（非糖物质合成葡萄糖）、糖原合成与分解、磷酸戊糖途径（NADPH生成与戊糖合成）
2. **脂质代谢**
   - 研究对象：脂肪酸、甘油三酯、胆固醇、酮体、代谢相关酶
   - 核心内容：脂肪酸合成（细胞质）与β-氧化（线粒体）、甘油三酯的合成与分解、胆固醇合成（甲羟戊酸途径）与代谢转化、酮体的生成与利用、脂质代谢紊乱（如高血脂、脂肪肝）
3. **蛋白质与氨基酸代谢**
   - 研究对象：氨基酸、肽、尿素、转氨酶、脱羧酶
   - 核心内容：蛋白质的消化吸收与降解（泛素-蛋白酶体途径）、氨基酸的脱氨基作用（转氨基、氧化脱氨基）、尿素循环（氨的解毒）、氨基酸的合成与分解（如芳香族氨基酸代谢）、生糖/生酮氨基酸的代谢去向
4. **核酸代谢**
   - 研究对象：核苷酸、嘌呤/嘧啶碱基、核酸合成相关酶（DNA聚合酶、RNA聚合酶）
   - 核心内容：嘌呤核苷酸的从头合成与补救合成、嘧啶核苷酸的合成与分解、DNA复制（半保留复制）、RNA转录（不对称转录）、核酸降解与核苷酸循环
5. **能量代谢与生物氧化**
   - 研究对象：线粒体、呼吸链复合体、ATP合酶、NADH/FADH₂
   - 核心内容：生物氧化的特点（温和条件、逐步释放能量）、呼吸链的组成与电子传递顺序、氧化磷酸化（ATP生成的核心机制）、底物水平磷酸化、胞质NADH的穿梭机制（α-磷酸甘油穿梭、苹果酸-天冬氨酸穿梭）

### 三、生物分子的合成与调控（生命过程的化学调控）
1. **酶化学与酶促反应**
   - 研究对象：酶（氧化还原酶、转移酶、水解酶等）、辅酶/辅基、底物、抑制剂/激活剂
   - 核心内容：酶的催化机制（活性中心、诱导契合模型）、酶促反应动力学（米氏方程、温度/pH对酶活性的影响）、酶的抑制类型（竞争性、非竞争性、反竞争性抑制）、酶的调节方式（变构调节、共价修饰、酶原激活）、同工酶的功能差异
2. **生物膜与物质运输**
   - 研究对象：生物膜（细胞膜、细胞器膜）、膜蛋白（载体蛋白、通道蛋白、泵蛋白）、小分子物质（离子、葡萄糖、氨基酸）
   - 核心内容：生物膜的流动镶嵌模型、物质跨膜运输机制（被动运输：自由扩散/协助扩散；主动运输：ATP驱动泵/协同运输）、膜泡运输（胞吞/胞吐）、膜受体介导的信号传导
3. **信号分子与细胞信号传导**
   - 研究对象：信号分子（激素、细胞因子、神经递质）、受体（膜受体/胞内受体）、第二信使（cAMP、cGMP、Ca²⁺、IP3/DAG）、蛋白激酶/磷酸酶
   - 核心内容：信号分子的合成与释放、受体激活机制、胞内信号通路的级联放大（如MAPK通路、PI3K-Akt通路）、信号传导的终止与脱敏、信号通路的交叉对话
4. **代谢调控网络**
   - 研究对象：代谢通路关键酶、调控分子（激素、变构效应剂）、基因表达调控因子
   - 核心内容：代谢的细胞水平调控（酶活性调节）、激素水平调控（如胰岛素/胰高血糖素调节糖代谢）、基因水平调控（转录因子调控代谢酶基因表达）、代谢网络的协同平衡（如糖-脂-蛋白代谢的相互转化）

### 四、关键技术方法与工具开发
1. **生物大分子分离与分析技术**
   - 研究对象：蛋白质、核酸、糖类、脂质提取物
   - 核心内容：色谱技术（凝胶过滤、离子交换、亲和色谱、高效液相色谱HPLC）、电泳技术（SDS-PAGE、等电聚焦、双向电泳）、超速离心（生物大分子分离与纯度鉴定）、质谱技术（蛋白质/肽段鉴定、分子量测定）
2. **结构解析技术**
   - 研究对象：生物大分子（蛋白质、核酸、复合物）
   - 核心内容：X射线晶体学（三维结构解析）、核磁共振（NMR，溶液状态结构分析）、冷冻电镜（Cryo-EM，大分子复合物结构）、圆二色谱（蛋白质二级结构分析）
3. **分子生物学与酶学技术**
   - 研究对象：目的基因、酶制剂、重组载体、宿主细胞
   - 核心内容：PCR扩增、基因克隆与重组蛋白表达、酶活性测定（比色法、荧光法）、酶动力学参数拟合、定点突变（酶结构与功能改造）
4. **代谢组学与高通量分析技术**
   - 研究对象：代谢物提取物、生物体液（血液、尿液）、细胞裂解液
   - 核心内容：代谢物分离（气相色谱GC、液相色谱LC）、代谢物鉴定（质谱MS、核磁共振NMR）、代谢组数据定量分析、差异代谢物筛选、代谢通路富集分析

### 五、应用导向的生物化学研究
1. **医学生物化学**
   - 研究对象：疾病相关代谢物、致病蛋白、药物靶点（酶、受体）、生物标志物
   - 核心内容：疾病的生物化学机制（如糖尿病的糖代谢紊乱、肿瘤的代谢重编程、神经退行性疾病的蛋白错误折叠）、临床生物化学检验（血糖、血脂、肝功能指标检测）、药物设计（酶抑制剂、受体拮抗剂）、生物制药（重组蛋白药物、核酸药物）
2. **农业生物化学**
   - 研究对象：作物/畜禽的代谢酶、抗逆相关蛋白、营养成分（淀粉、蛋白、油脂）
   - 核心内容：作物光合作用的生物化学调控（提高产量）、畜禽饲料营养的消化吸收机制、抗逆作物的代谢适应（抗旱/抗寒的物质合成）、作物品质改良（如蛋白质含量提升、油脂组成优化）
3. **工业生物化学**
   - 研究对象：工业酶（淀粉酶、纤维素酶、蛋白酶）、微生物代谢通路、发酵产物
   - 核心内容：酶的分子改造（提高活性、稳定性、耐酸碱/高温性）、微生物发酵的代谢调控（如乙醇、乳酸、抗生素生产）、生物燃料合成（纤维素乙醇、生物柴油）、食品添加剂生产（氨基酸、维生素）
4. **环境生物化学**
   - 研究对象：污染物（重金属、有机物）、降解酶、微生物代谢系统
   - 核心内容：污染物的生物化学降解机制（如微生物分泌酶降解塑料、重金属螯合蛋白解毒）、环境毒理学（污染物对生物代谢的影响）、生物修复技术（酶制剂、工程菌应用）

### 六、前沿交叉领域（多学科融合的创新方向）
1. **结构生物化学**
   - 研究对象：生物大分子复合物（转录复合物、信号通路复合物）、膜蛋白、病毒颗粒
   - 核心内容：大分子复合物的组装机制、结构与功能的动态关联、药物与靶点蛋白的结合模式解析、冷冻电镜与AI辅助结构预测（如AlphaFold）的结合应用
2. **分子生物物理学**
   - 研究对象：生物大分子的物理化学性质、分子间相互作用、生物膜的力学特性
   - 核心内容：蛋白质折叠的热力学与动力学、核酸的分子力学模拟、生物膜的相变与流动性、单分子技术（原子力显微镜AFM、光镊）研究分子互作
3. **计算生物化学**
   - 研究对象：生物大分子结构数据、代谢通路网络、药物分子结构
   - 核心内容：分子动力学模拟（蛋白质/核酸构象变化）、酶促反应机制的量子化学计算、代谢网络建模与预测、AI辅助药物分子设计（虚拟筛选、分子对接）
4. **糖生物化学与糖组学**
   - 研究对象：糖复合物（糖蛋白、糖脂）、糖基转移酶、聚糖结构
   - 核心内容：聚糖的生物合成与调控、糖基化修饰对蛋白质功能的影响、糖-蛋白/糖-糖相互作用（细胞识别、病原体感染）、糖组学技术与疾病诊断
5. **代谢组学与系统生物学**
   - 研究对象：全代谢组数据、多组学（基因组/转录组/蛋白质组/代谢组）整合数据
   - 核心内容：代谢网络的系统分析、疾病的代谢组学特征、环境因素对代谢的影响、个性化代谢调控策略
6. **合成生物化学**
   - 研究对象：人工设计的代谢通路、合成酶、生物模块
   - 核心内容：代谢通路的人工重构（如合成特定天然产物）、人工酶的设计与合成、生物催化体系的构建、定制化代谢产物（药物前体、高价值化学品）的生物合成
