# 核心基础理论（声学的“公理体系”）

## 核心概念

1.  **声波**：它是由声源振动引发的机械波，传播必须依赖空气、水、固体等弹性介质，无法在真空中传播。作为纵波，声波传播方向与介质质点振动方向一致，传播时会使介质形成疏密相间的状态，本质是介质中压力、密度等物理量的周期性扰动。依据频率差异，可分为频率低于20Hz的次声波、20 - 20kHz的可听声波以及高于20kHz的超声波，不同频率的声波应用场景差异显著，比如超声波常用于医学成像。

2.  **声场**：指声波传播所波及的空间范围，用于描述声波在空间中的分布状态。根据声波传播的波形不同，常见的有平面波声场、球面波声场等，像点声源发出的声波形成的就是球面波声场，而远处传来的声波可近似看作平面波声场。

3.  **声压**：即声波传播时介质中的交变压力，具体是介质中的瞬时压力与静压力的差值，单位为帕斯卡。声压是衡量声波强弱的关键物理量，人耳能感知的声压范围十分狭窄，通常在2×10^-5 Pa - 20Pa之间。

4.  **声速**：是介质中微弱压力扰动的传播速度，其大小由介质自身的性质决定。一般来说，声速在固体中最快，液体中次之，气体中最慢。比如20℃时，空气中声速约343m/s，水中约1480m/s，钢铁中更是高达5960m/s左右，同时气体中的声速还会随温度变化而改变。

5.  **声阻抗**：指介质波阵面某面积上的声压与通过该面积的体积速度的复数比值，它体现了介质对声波传播的阻碍作用。声阻率ρc是声阻抗的重要特例，这个物理量仅和介质的密度以及声速相关，两种介质的声阻抗差异大小，会影响声波在两种介质界面处的反射和透射程度。

6.  **声强**：单位时间内垂直通过单位面积的声能，单位为瓦/平方米。声强直接反映了声波能量的传播强度，它和声音的响度感知相关，通常声强越大，人耳感受到的声音越响亮，且点声源的声强会随传播距离的增大而衰减。

7.  **频率与周期**：频率是单位时间内声源振动的次数，单位为赫兹；周期则是声源完成一次全振动所需的时间，单位为秒。二者互为倒数关系，频率决定了声音的音调，频率越高，音调通常越高。

8.  **波长**：声波在一个周期内传播的距离，单位为米。波长与声速、频率紧密相关，是描述声波空间周期性的重要物理量。

## 核心理论与公式

1.  声速相关公式

   - 气体中：$c=\sqrt{\gamma RT}$，其中γ为气体绝热指数，R为气体常数，T为热力学温度；

   - 固体中：$c=\sqrt{\frac{Y(1-\mu)}{\rho(1+\mu)(1 - 2\mu)}}$，其中Y是杨氏模量，μ是泊松比，ρ是固体密度；

   - 液体中：$c=\sqrt{\frac{B}{\rho}}$，其中B为液体的体积弹性模量，ρ为液体密度；

   - 空气经验公式：$v \approx 331 + 0.6t$，其中t为摄氏温度。

2.  波动方程

   - 三维形式：$\nabla^2p=\frac{1}{c^2}\frac{\partial^2p}{\partial t^2}$，其中∇²为拉普拉斯算子，p为声压，t为时间；

   - 一维形式：$\frac{\partial^2p}{\partial x^2}=\frac{1}{c^2}\frac{\partial^2p}{\partial t^2}$，其中x为声波传播方向的坐标，是描述声波传播规律的核心方程。

3.  声强相关公式

   - 基础公式：$I=\frac{p^2}{2\rho c}$ 或 $I=\frac{1}{2}\rho c v^2$，其中p为声压幅值，v为质点振动速度幅值；

   - 点声源声强：$I = P/(4\pi r^2)$，其中P为声源的功率，r为到声源的距离；

   - 声强级：$L_I = 10 \lg(I/I_0)$，其中$I_0 = 10^{-12} W/m^2$，是人类能感知的最低声强。

4.  波速、波长与频率关系公式：$c = \lambda f$，可推导得$\lambda = c/f$、$f = c/\lambda$，其中λ为波长，f为频率，是连接声波时空特性与振动特性的关键。

5.  声学欧姆定律：$p = \rho c v$，类比电路欧姆定律，p类比电压，v类比电流，ρc类比电阻，直观反映声压与质点振动速度的关联。

6.  声阻抗公式

   - 复数形式：$Z=\frac{p}{U}$，其中U为体积速度；

   - 平面波特例：$Z=\rho c$，此时声阻抗为实数，仅由介质自身属性决定。

## 关键公式证明

1.  证明对象：气体中声速公式$c=\sqrt{\gamma RT}$

   - 前提假设：声波在气体中传播极快，属于绝热过程（无热量交换）；声波引发的扰动微弱，可近似处理。

   - 第一步：建立守恒方程。取随压缩波运动的控制体，根据质量守恒得$\rho_2(c - \delta u)=\rho_1c$（$\rho_1$、$\rho_2$为控制体前后介质密度，c为波速，$\delta u$为质点振动速度变化量）；根据动量守恒得$p_2 - p_1=\rho_1c\delta u$（$p_1$、$p_2$为控制体前后压力）。

   - 第二步：联立消元。消去$\delta u$得$c=\frac{\rho_2}{\rho_1}\cdot\frac{p_2 - p_1}{\rho_2 - \rho_1}$，因扰动微弱$\rho_2\approx\rho_1$，转化为微分形式$c=\sqrt{\frac{dp}{d\rho}}$。

   - 第三步：结合物态方程。绝热过程遵循$p\rho^{-\gamma}=C$（C为常数），求导得$\frac{dp}{d\rho}=\gamma\frac{p}{\rho}$；代入理想气体状态方程$p=\rho RT$（$\frac{p}{\rho}=RT$），最终推得$c=\sqrt{\gamma RT}$。

2.  证明对象：一维声波波动方程$\frac{\partial^2p}{\partial x^2}=\frac{1}{c^2}\frac{\partial^2p}{\partial t^2}$

 - 推导基础：需结合运动方程、连续性方程和绝热物态方程三大核心方程。

   - 第一步：推导运动方程。取长度Δx、横截面积S的介质体积元，由牛顿第二定律，压力差等于动量变化率，即$-\frac{\partial p}{\partial x}S\Delta x=\rho S\Delta x\frac{\partial v}{\partial t}$，简化得$\frac{\partial p}{\partial x}=-\rho\frac{\partial v}{\partial t}$。

   - 第二步：推导连续性方程。基于质量守恒，体积元密度变化率与速度梯度相关，得$\frac{\partial \rho}{\partial t}=-\rho\frac{\partial v}{\partial x}$。

   - 第三步：分析绝热物态方程。绝热过程$p=CB^{\gamma}$微分得$dp=\gamma\frac{p}{\rho}d\rho$，结合声速公式知$\gamma\frac{p}{\rho}=c^2$，故$\frac{\partial p}{\partial t}=c^2\frac{\partial \rho}{\partial t}$。

   - 第四步：联立消元。将连续性方程代入物态方程得$\frac{\partial p}{\partial t}=-c^2\rho\frac{\partial v}{\partial x}$，对其关于x求偏导，同时对运动方程关于t求偏导，联立消去v，得到一维波动方程。

3.  证明对象：声强公式$I=\frac{p^2}{2\rho c}$

   - 定义基础：声强是单位时间内通过单位面积的声能，即$I=\frac{\langle P\rangle}{A}$（$\langle P\rangle$为平均功率，A为面积）。

   - 第一步：关联声压与振动速度。由声学欧姆定律$p = \rho c v$，推得$v=\frac{p}{\rho c}$（v为质点振动速度）。

   - 第二步：推导声功率。声压对应的作用力$F = pS$，声功率$P=Fv=pSv$（S为作用面积）。

   - 第三步：时间平均运算。对于周期性声波，对功率取一个周期的时间平均，会产生系数1/2；将$v=\frac{p}{\rho c}$代入平均功率公式，再结合声强定义，最终推得$I=\frac{p^2}{2\rho c}$。
