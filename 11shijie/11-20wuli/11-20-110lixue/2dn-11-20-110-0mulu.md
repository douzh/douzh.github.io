# 经典力学

经典力学是物理学的基础分支，研究宏观物体（速度远小于光速）的机械运动规律，其研究领域可按 **研究对象、运动形式、应用场景** 分为以下结构化体系，涵盖核心理论、分支方向及实际应用，便于系统性梳理：

### 一、核心基础理论（经典力学的“公理体系”）
是所有分支的理论基石，定义基本概念和普适规律：
1. **牛顿力学（矢量力学）**
   - 核心内容：牛顿三大运动定律（惯性、F=ma、作用力与反作用力）、万有引力定律
   - 研究对象：质点、质点系的平动/转动、抛体运动、天体运动等
   - 关键工具：牛顿方程、动量/角动量守恒、机械能守恒（理想约束下）
   - [[2dn-11-20-110-lixue01]]
2. **分析力学（分析方法的延伸）**
   - 核心内容：拉格朗日力学（基于拉格朗日量和变分原理）、哈密顿力学（基于哈密顿量和正则方程）
   - 研究对象：复杂约束系统（如多自由度刚体、耦合振动）
   - 关键工具：拉格朗日方程、哈密顿正则方程、泊松括号、最小作用量原理
3. **静力学（运动的特殊情况：加速度为0）**
   - 核心内容：力的平衡（共点力平衡、刚体平衡）、力矩平衡、约束反力计算
   - 应用场景：结构力学基础（桥梁、建筑的受力分析）、机械零件的静态设计


### 二、按运动形式划分的分支领域
聚焦物体不同运动状态的规律研究：
1. **质点运动学/动力学**
   - 研究内容：位置、速度、加速度的描述（匀速/匀变速/曲线运动）、受力与运动的关系
   - 典型问题：自由落体、平抛/斜抛运动、圆周运动（向心力计算）
2. **刚体力学**
   - 研究内容：刚体的平动、转动、平面运动（如车轮滚动）、定点转动（如陀螺）
   - 关键概念：转动惯量、角加速度、力矩、角动量守恒（如花样滑冰旋转）
3. **流体力学（经典流体：理想流体+粘性流体）**
   - 研究内容：流体的静止（流体静力学：浮力、压强分布）、运动（流体动力学：流线、伯努利方程）
   - 分支：理想流体力学（无粘性、不可压缩）、粘性流体力学（纳维-斯托克斯方程）、空气动力学（低速气流：如飞机机翼升力）
4. **振动与波**
   - 振动部分：简谐振动（弹簧振子、单摆）、受迫振动、共振、阻尼振动
   - 波动部分：机械波（横波/纵波）、波的传播/干涉/衍射/反射/折射、声波（声学基础）


### 三、按研究尺度/场景划分的应用分支
从基础理论延伸到具体宏观系统的研究：
1. **天体力学**
   - 研究内容：天体（行星、卫星、彗星）的运动规律、天体间的引力相互作用
   - 典型成果：开普勒行星运动定律、潮汐现象解释、人造卫星轨道设计（经典近似，高精度需相对论修正）
2. **连续介质力学**
   - 研究内容：将物体视为连续分布的介质（固体、流体），统一描述其变形、运动和受力
   - 关联分支：弹性力学（固体的弹性变形，如弹簧、梁的弯曲）、塑性力学（固体的塑性变形，如金属锻造）
3. **工程力学（经典力学的工程应用）**
   - 核心分支：材料力学（构件的强度、刚度、稳定性分析）、结构力学（桥梁、厂房等结构的受力设计）、机械原理（机构运动设计，如齿轮传动）
4. **声学（机械波的特殊应用）**
   - 研究内容：声波的产生、传播、接收与应用（如超声波检测、噪声控制），本质是机械振动在介质中的传播


### 四、经典力学的边界与关联领域
1. **适用范围**：宏观物体（尺度远大于原子分子）、低速运动（速度v≪光速c，无需相对论修正）、弱引力场（无需广义相对论）
2. **与其他物理分支的关系**：
   - 局限性：无法解释微观现象（需量子力学）、高速运动（需狭义相对论）、强引力场（需广义相对论）
   - 关联性：是热力学（宏观热现象的统计基础）、电磁学（带电体机械运动）的基础，也是工程学科（机械、土木、航空航天）的核心理论支撑


### 总结：经典力学的体系框架
```
核心理论（牛顿力学、分析力学、静力学）
↓
运动形式分支（质点→刚体→流体→振动与波）
↓
应用场景分支（天体→连续介质→工程应用→声学）
```
其核心逻辑是：以“力”和“能量”为核心，通过守恒定律（动量、角动量、机械能）和运动方程，统一描述宏观物体的机械运动，是物理学中最成熟、应用最广泛的分支之一。
