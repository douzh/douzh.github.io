# 电磁波与电磁辐射

## 一、研究对象
1.  电磁波：由**交变电场和交变磁场**相互激发、相互耦合，在空间中传播的横波，是电磁场的一种运动形态。
2.  电磁辐射：电磁波由波源向外传播的过程，以及该过程中电磁波携带能量的发射、传输与接收现象。

## 二、核心理论基础
### 1.  麦克斯韦方程组（电磁学的基石）
麦克斯韦整合库仑定律、安培定律、法拉第电磁感应定律，并补充**位移电流假说**，推导出描述电磁场普遍规律的方程组，直接预言了电磁波的存在。
- 积分形式核心结论：
  1.  电场的高斯定理：静电场是有源场，电场线起始于正电荷、终止于负电荷；变化的磁场激发的涡旋电场是无源场。
  2.  磁场的高斯定理：磁场是无源场，磁感线是闭合曲线，不存在磁单极子。
  3.  法拉第电磁感应定律：变化的磁场激发涡旋电场。
  4.  安培环路定理（含位移电流）：变化的电场（位移电流）激发涡旋磁场，传导电流和位移电流共同产生磁场。
-  麦克斯韦方程组的微分形式揭示：**变化的电场产生磁场，变化的磁场产生电场**，二者相互激发形成电磁波。

### 2.  电磁波的产生条件
-  波源：**做加速运动的电荷**（如振荡电路中的交变电流、原子外层电子的跃迁），静止电荷或匀速运动电荷只能产生静电场、恒定磁场，无法激发电磁波。
-  典型波源：LC振荡电路（需开放电路提高辐射效率）、天线、原子/分子的能级跃迁。

## 三、电磁波的基本性质
### 1.  传播特性
1.  横波特性：电场强度$\vec{E}$和磁感应强度$\vec{B}$相互垂直，且二者均垂直于电磁波的传播方向$\vec{v}$，满足 $\vec{E} \perp \vec{B} \perp \vec{v}$。
2.  传播不需要介质：可在真空中传播，真空中的传播速度 $c = \frac{1}{\sqrt{\mu_0 \varepsilon_0}}$，其中 $\mu_0$ 为真空磁导率，$\varepsilon_0$ 为真空介电常数，计算得 $c \approx 3 \times 10^8 \ \text{m/s}$（光速，证明光属于电磁波）。
3.  频率与波长的关系：$c = \lambda f$（介质中 $v = \lambda f$，$v < c$，频率 $f$ 由波源决定，波长 $\lambda$ 由波源和介质共同决定）。

### 2.  能量与动量特性
1.  能量载体：电磁波携带**电磁能**，能量密度 $w = w_e + w_m = \frac{1}{2}\varepsilon E^2 + \frac{1}{2}\mu H^2$，在真空中 $\varepsilon = \varepsilon_0, \mu=\mu_0$，且 $E = cB$，因此 $w_e = w_m$，总能量密度 $w = \varepsilon_0 E^2$。
2.  能流密度（坡印廷矢量）：$\vec{S} = \vec{E} \times \vec{H}$，表示单位时间内通过垂直于传播方向单位面积的电磁能，方向与传播方向一致。
3.  动量特性：电磁波具有动量，动量密度 $\vec{g} = \frac{\vec{S}}{c^2}$，照射物体时会产生**光压**（如太阳帆的原理）。

### 3.  偏振特性
-  偏振是横波的特有属性，指电场强度$\vec{E}$的振动方向相对传播方向的取向。
-  常见偏振类型：线偏振光（$\vec{E}$振动方向固定）、圆偏振光（$\vec{E}$末端轨迹为圆）、椭圆偏振光、自然光（各方向偏振均匀混合）。

## 四、电磁波谱（按频率/波长分类）
将电磁波按**频率从低到高**（或波长从长到短）排列，形成连续的电磁波谱，不同波段电磁波的特性和应用不同，无明确的波段界限。

1.  无线电波
    -  波长：$10^4 \ \text{m} \sim 10^{-3} \ \text{m}$，频率：$3 \times 10^4 \ \text{Hz} \sim 3 \times 10^{11} \ \text{Hz}$
    -  产生：振荡电路
    -  应用：通信（广播、电视、手机）、雷达、导航。

2.  红外线
    -  波长：$7.6 \times 10^{-7} \ \text{m} \sim 10^{-3} \ \text{m}$
    -  产生：分子的振动和转动
    -  特性：热效应显著（热辐射的主要波段）
    -  应用：红外遥感、加热（红外烤箱）、红外成像。

3.  可见光
    -  波长：$3.9 \times 10^{-7} \ \text{m} \sim 7.6 \times 10^{-7} \ \text{m}$（红、橙、黄、绿、蓝、靛、紫）
    -  产生：原子外层电子的跃迁
    -  应用：视觉感知、照明、光纤通信。

4.  紫外线
    -  波长：$10^{-9} \ \text{m} \sim 3.9 \times 10^{-7} \ \text{m}$
    -  产生：原子外层电子的跃迁
    -  特性：化学效应强（使荧光物质发光）、杀菌消毒、能使臭氧层分解出臭氧
    -  危害：过量照射会损伤皮肤和眼睛。

5.  X射线（伦琴射线）
    -  波长：$10^{-12} \ \text{m} \sim 10^{-9} \ \text{m}$
    -  产生：高速电子撞击金属靶
    -  特性：穿透能力强
    -  应用：医学透视、工业探伤、晶体结构分析。

6.  $\gamma$射线
    -  波长：小于 $10^{-12} \ \text{m}$
    -  产生：原子核的衰变或核反应
    -  特性：穿透能力极强、能量极高
    -  应用：放射性治疗、工业探伤、天体物理研究
    -  危害：对生物组织有强破坏作用。

## 五、电磁辐射的相关概念与影响
### 1.  电磁辐射的分类
-  按辐射源性质：
  1.  天然电磁辐射：太阳辐射、雷电、地球磁场辐射、生物自身辐射。
  2.  人工电磁辐射：无线电通信基站、手机、微波炉、家用电器、雷达等设备产生的辐射。
-  按能量高低：
  1.  电离辐射：能量足够高，能使原子或分子电离（如X射线、$\gamma$射线），过量照射会破坏生物细胞的DNA。
  2.  非电离辐射：能量较低，无法电离物质（如无线电波、红外线、可见光、紫外线中低能量部分），日常接触的大部分人工辐射属于此类。

### 2.  电磁辐射的生物效应与防护
1.  生物效应机制
    -  热效应：非电离辐射的能量被生物组织吸收，转化为热能，导致组织温度升高（如微波炉加热原理，手机通话时头部局部升温）。
    -  非热效应：低强度电磁辐射可能对细胞的生理活动产生影响（如影响酶活性、细胞信号传导），相关研究仍在深入。
2.  防护措施
    -  减少暴露时间：缩短使用手机、微波炉等设备的时间。
    -  增加距离：辐射强度与距离的平方成反比，远离辐射源（如远离基站天线、微波炉工作时保持安全距离）。
    -  屏蔽防护：使用金属材料（如铜、铝）屏蔽电磁波，如防辐射服、屏蔽室。

### 3.  电磁辐射的测量
-  核心指标：电场强度（单位：$\text{V/m}$）、磁感应强度（单位：$\text{T}$）、功率密度（单位：$\text{W/m}^2$）。
-  测量工具：电磁辐射检测仪（可测量不同波段的辐射强度）。

## 六、应用延伸
1.  通信领域：无线电广播、移动通信、卫星通信、光纤通信（利用激光，属于电磁波）。
2.  医疗领域：X射线透视、核磁共振成像（利用磁场和射频电磁波）、紫外线杀菌、$\gamma$射线放疗。
3.  工业领域：红外测温、X射线探伤、微波加热、雷达测速。
4.  科研领域：射电望远镜观测天体电磁辐射、利用电磁波研究物质结构（如晶体的X射线衍射）。
5.  军事领域：雷达探测、电子对抗（干扰敌方电磁通信）。

## 七、常见误区澄清
1.  电磁波≠电磁辐射：电磁波是物质形态，电磁辐射是电磁波的传播过程及能量发射现象。
2.  所有电磁波都具有能量，但并非所有电磁辐射都有害：日常非电离辐射在安全剂量内对人体无显著危害。
3.  光速是电磁波在真空中的传播速度，介质中电磁波速度会降低，且不同频率的电磁波在介质中传播速度不同（色散现象）。
