# 静电学

静电学的研究对象是**静止电荷**及其产生的电场、电场对电荷的作用，以及静电场与导体、电介质的相互作用。

## 一、 核心基础概念
1.  **电荷**
    - 本质：物质的一种基本属性，分为正电荷（如质子）和负电荷（如电子）。
    - 基本性质：同种电荷相互排斥，异种电荷相互吸引。
    - 电荷守恒定律：孤立系统中，电荷的代数和保持不变；电荷只能转移，不能凭空产生或消失。
    - 元电荷：自然界中最小的电荷量，大小为 $e=1.602\times10^{-19}\ \text{C}$，任何带电体的电荷量都是元电荷的整数倍。
    - 点电荷：理想化模型，当带电体的形状、大小与研究问题的距离相比可以忽略时，可视为点电荷。

2.  **库仑定律**
    - 内容：真空中两个静止点电荷之间的相互作用力，与它们的电荷量的乘积成正比，与它们的距离的平方成反比，作用力的方向在它们的连线上。
    - 公式：$F=k\frac{q_1q_2}{r^2}$，其中 $k=9.0\times10^9\ \text{N·m}^2/\text{C}^2$ 为静电力常量。
    - 适用条件：① 真空中；② 静止点电荷。
    - 矢量性：库仑力是矢量，满足矢量叠加原理（多个点电荷对某一电荷的作用力，等于各点电荷单独作用时的力的矢量和）。

## 二、 静电场
1.  **电场的基本概念**
    - 定义：电荷周围存在的一种特殊物质，对放入其中的电荷有力的作用；电场的传递速度为光速 $c$。
    - 电场强度（场强）
      - 定义：放入电场中某点的试探电荷所受的电场力 $F$ 与试探电荷电荷量 $q_0$ 的比值，反映电场的强弱和方向。
      - 公式：$E=\frac{F}{q_0}$（定义式，适用于任何电场）；$E=k\frac{Q}{r^2}$（点电荷的场强公式，$Q$ 为场源电荷）。
      - 单位：$\text{N/C}$ 或 $\text{V/m}$。
      - 矢量性：方向与正试探电荷所受电场力方向相同，与负试探电荷所受电场力方向相反。
      - 电场强度叠加原理：多个场源电荷产生的电场中，某点的场强等于各个场源电荷单独在该点产生的场强的矢量和。

2.  **电场线**
    - 定义：为了形象描述电场而引入的假想曲线，曲线上每一点的切线方向为该点的场强方向，曲线的疏密程度表示场强的大小。
    - 基本性质
      - 电场线起始于正电荷（或无穷远），终止于负电荷（或无穷远），不闭合、不相交。
      - 匀强电场的电场线是平行等距的直线。
    - 常见电场的电场线分布：点电荷（正/负）、等量同种电荷、等量异种电荷、带电平行板电容器的电场线。

3.  **电通量与高斯定理**
    - 电通量（$\Phi_E$）
      - 定义：电场强度 $E$ 与垂直于电场方向的面积 $S$ 的乘积，反映电场穿过某一面积的“电场线根数”。
      - 公式：匀强电场中 $\Phi_E=E\cdot S=ES\cos\theta$（$\theta$ 为 $E$ 与 $S$ 法线方向的夹角）；非匀强电场中需通过积分计算 $\Phi_E=\iint_S E\cdot dS$。
    - 高斯定理
      - 内容：真空中，通过任意闭合曲面的电通量，等于该闭合曲面所包围的所有电荷的代数和除以 $\varepsilon_0$（真空介电常量，$\varepsilon_0=\frac{1}{4\pi k}\approx8.85\times10^{-12}\ \text{C}^2/(\text{N·m}^2)$）。
      - 公式：$\Phi_E=\iint_S E\cdot dS=\frac{\sum q_{\text{内}}}{\varepsilon_0}$。
      - 适用场景：具有对称性的电场（如球对称、柱对称、平面对称），可快速求解场强。

## 三、 电势与电势差
1.  **电场力的功与电势能**
    - 电场力做功的特点：电场力对电荷做功与路径无关，只与初末位置有关（与重力做功类似）。
    - 公式：$W_{AB}=qU_{AB}$（$U_{AB}$ 为 $A、B$ 两点的电势差）。
    - 电势能（$E_p$）
      - 定义：电荷在电场中具有的势能，由电荷和电场共同决定。
      - 电场力做功与电势能变化的关系：$W_{AB}=E_{pA}-E_{pB}=-\Delta E_p$（电场力做正功，电势能减少；电场力做负功，电势能增加）。
      - 电势能的相对性：电势能的大小与零势能点的选择有关，通常选无穷远或大地为零势能点；点电荷 $q$ 在电场中某点的电势能 $E_p=q\varphi$（$\varphi$ 为该点的电势）。

2.  **电势（$\varphi$）**
    - 定义：电场中某点的电势能与试探电荷电荷量的比值，反映电场的能的性质。
    - 公式：$\varphi=\frac{E_p}{q_0}$（定义式，适用于任何电场）；$\varphi=k\frac{Q}{r}$（点电荷电场的电势公式，无穷远为零势能点）。
    - 单位：伏特（$\text{V}$），$1\ \text{V}=1\ \text{J/C}$。
    - 标量性：电势是标量，有正负之分，正负表示该点电势比零势能点高或低。
    - 电势叠加原理：多个场源电荷产生的电场中，某点的电势等于各个场源电荷单独在该点产生的电势的代数和。

3.  **电势差（$U_{AB}$）**
    - 定义：电场中 $A、B$ 两点的电势之差，也叫电压。
    - 公式：$U_{AB}=\varphi_A-\varphi_B=\frac{W_{AB}}{q}$。
    - 特点：电势差与零势能点的选择无关，是描述电场能的性质的物理量。

4.  **等势面**
    - 定义：电场中电势相等的点构成的曲面。
    - 基本性质
      - 等势面与电场线处处垂直。
      - 电场线总是由电势高的等势面指向电势低的等势面。
      - 等势面的疏密程度反映电场强度的大小（等势面越密，场强越大）。
      - 沿等势面移动电荷，电场力不做功。

## 四、 静电场中的导体
1.  **导体的静电平衡**
    - 静电感应：导体放入静电场中，自由电荷在电场力作用下定向移动，使导体两端出现等量异种电荷的现象。
    - 静电平衡状态：导体中（包括表面）没有自由电荷定向移动的状态。
    - 静电平衡的条件
      - 导体内部的电场强度处处为零。
      - 导体表面的电场强度方向垂直于导体表面。
    - 静电平衡时导体的性质
      - 导体是等势体，导体表面是等势面。
      - 导体内部没有净电荷，净电荷只分布在导体的外表面。
      - 导体表面的电荷面密度与表面的曲率有关（曲率越大，电荷面密度越大）。

2.  **静电屏蔽**
    - 定义：利用导体的静电平衡特性，使导体内部不受外部电场影响，或使带电体的电场不对外界产生影响的现象。
    - 两种情况
      - 外屏蔽：导体壳内部不受外部电场的影响。
      - 内屏蔽：接地的导体壳，其内部的带电体产生的电场不对外界产生影响。

## 五、 静电场中的电介质
1.  **电介质的极化**
    - 电介质：绝缘体，内部没有可以自由移动的电荷。
    - 极化现象：电介质放入静电场中，分子的正负电荷中心发生相对位移，使电介质表面出现等量异种束缚电荷的现象。
    - 极化分类：无极分子的位移极化、有极分子的取向极化。

2.  **电介质的介电常量**
    - 相对介电常量（$\varepsilon_r$）：电介质中的场强 $E$ 与真空中的场强 $E_0$ 的比值，$\varepsilon_r=\frac{E_0}{E}$，$\varepsilon_r>1$。
    - 绝对介电常量（$\varepsilon$）：$\varepsilon=\varepsilon_r\varepsilon_0$。

3.  **电容器与电容**
    - 电容器：由两个彼此绝缘又相互靠近的导体组成的装置，用于储存电荷和电能。
    - 电容（$C$）
      - 定义：电容器所带的电荷量 $Q$ 与两极板间电势差 $U$ 的比值。
      - 公式：$C=\frac{Q}{U}$（定义式）；平行板电容器的电容公式 $C=\frac{\varepsilon_r\varepsilon_0S}{d}$（$S$ 为极板面积，$d$ 为极板间距）。
      - 单位：法拉（$\text{F}$），$1\ \text{F}=1\ \text{C/V}$，常用单位有微法（$\mu\text{F}$）、皮法（$\text{pF}$），$1\ \text{F}=10^6\ \mu\text{F}=10^{12}\ \text{pF}$。
    - 电容器的串联与并联
      - 串联：$\frac{1}{C_{\text{串}}}=\frac{1}{C_1}+\frac{1}{C_2}+\dots+\frac{1}{C_n}$，串联电容器的电荷量相等，总电压等于各电容器电压之和。
      - 并联：$C_{\text{并}}=C_1+C_2+\dots+C_n$，并联电容器的电压相等，总电荷量等于各电容器电荷量之和。

4.  **电容器的储能**
    - 电场能：电容器充电后，极板间的电场具有的能量。
    - 储能公式：$W=\frac{1}{2}CU^2=\frac{1}{2}\frac{Q^2}{C}=\frac{1}{2}QU$。

## 六、 静电的应用与危害
1.  **静电的应用**
    - 静电除尘：利用电场使粉尘带电，在电场力作用下定向移动并沉积。
    - 静电复印、静电喷漆：利用静电吸附原理。
    - 电容器：用于电路中的储能、滤波、隔直等。

2.  **静电的危害**
    - 静电放电可能引发火灾、爆炸（如加油站、面粉厂的静电隐患）。
    - 静电会干扰电子设备的正常工作。
    - 预防措施：接地、增加湿度、使用抗静电材料等。

## 静电学核心公式速记清单
### 一、 电场的基本描述与通量
1.  **电场强度定义**
    $\vec{E}=\frac{\vec{F}}{q_0}$（$q_0$ 为试探电荷的电荷量，需满足 $q_0$ 足够小，不影响源电荷分布）
    点电荷的电场强度：$\vec{E}=\frac{1}{4\pi\varepsilon_0}\cdot\frac{q}{r^2}\vec{e}_r$（$\vec{e}_r$ 为场点指向源电荷的单位矢量）

2.  **电场强度叠加原理**
    点电荷系的电场：$\vec{E}=\sum_{i=1}^n\vec{E}_i=\sum_{i=1}^n\frac{1}{4\pi\varepsilon_0}\cdot\frac{q_i}{r_i^2}\vec{e}_{r_i}$
    连续带电体的电场：$\vec{E}=\int d\vec{E}=\int\frac{1}{4\pi\varepsilon_0}\cdot\frac{dq}{r^2}\vec{e}_r$

3.  **电通量**
    $\Phi_E=\iint_S\vec{E}\cdot d\vec{S}$
    电场高斯定理：$\oiint_S\vec{E}\cdot d\vec{S}=\frac{\sum q_i}{\varepsilon_0}$（真空形式，$\sum q_i$ 为闭合曲面 $S$ 内的净电荷）
    真空介电常数：$\varepsilon_0=8.85\times10^{-12}\ \text{C}^2/(\text{N·m}^2)$

### 二、 电势与电势差
1.  **电势定义（电势零点选无穷远）**
    $\varphi=\frac{E_p}{q_0}=\int_P^\infty\vec{E}\cdot d\vec{l}$（$E_p$ 为试探电荷的电势能）

2.  **电势叠加原理**
    点电荷系的电势：$\varphi=\sum_{i=1}^n\varphi_i=\sum_{i=1}^n\frac{1}{4\pi\varepsilon_0}\cdot\frac{q_i}{r_i}$
    连续带电体的电势：$\varphi=\int d\varphi=\int\frac{1}{4\pi\varepsilon_0}\cdot\frac{dq}{r}$

3.  **电势差（电压）**
    $U_{AB}=\varphi_A-\varphi_B=\int_A^B\vec{E}\cdot d\vec{l}$

4.  **电场强度与电势的微分关系**
    $\vec{E}=-\nabla\varphi$（直角坐标系：$\vec{E}=-\left(\frac{\partial\varphi}{\partial x}\vec{i}+\frac{\partial\varphi}{\partial y}\vec{j}+\frac{\partial\varphi}{\partial z}\vec{k}\right)$）

### 三、 电场力与电势能
1.  **库仑定律**
    真空中两个点电荷的相互作用力：$\vec{F}=\frac{1}{4\pi\varepsilon_0}\cdot\frac{q_1q_2}{r^2}\vec{e}_r$

2.  **点电荷的电势能**
    点电荷 $q$ 在电场中的电势能：$E_p=q\varphi$
    两个点电荷的相互作用电势能：$E_p=\frac{1}{4\pi\varepsilon_0}\cdot\frac{q_1q_2}{r}$

### 四、 导体与电介质相关公式
1.  **静电平衡时导体的性质**
    导体内部：$\vec{E}_{\text{内}}=0$；导体表面：$\vec{E}_{\text{表}}=\frac{\sigma}{\varepsilon_0}\vec{n}$（$\sigma$ 为导体表面电荷面密度，$\vec{n}$ 为表面法向单位矢量）

2.  **电容定义**
    孤立导体的电容：$C=\frac{Q}{\varphi}$
    电容器的电容：$C=\frac{Q}{U_{AB}}$

3.  **常见电容器的电容公式**
    - 平行板电容器：$C=\frac{\varepsilon_r\varepsilon_0S}{d}$（$S$ 为极板面积，$d$ 为极板间距，$\varepsilon_r$ 为相对介电常数）
    - 球形电容器：$C=4\pi\varepsilon_0\varepsilon_r\frac{R_1R_2}{R_2-R_1}$（$R_1$、$R_2$ 分别为内外球壳半径）

4.  **电介质的极化**
    电极化强度：$\vec{P}=\chi_e\varepsilon_0\vec{E}$（线性各向同性电介质，$\chi_e$ 为电极化率）
    电位移矢量：$\vec{D}=\varepsilon_0\vec{E}+\vec{P}=\varepsilon_0\varepsilon_r\vec{E}=\varepsilon\vec{E}$
    有电介质时的高斯定理：$\oiint_S\vec{D}\cdot d\vec{S}=\sum q_{0i}$（$\sum q_{0i}$ 为闭合曲面内的自由电荷）

### 五、 电场的能量
1.  **电容器的储能公式**
    $W_e=\frac{1}{2}CU^2=\frac{1}{2}\frac{Q^2}{C}=\frac{1}{2}QU$

2.  **电场的能量密度**
    $w_e=\frac{1}{2}\vec{E}\cdot\vec{D}=\frac{1}{2}\varepsilon E^2$（线性电介质）
    电场的总能量：$W_e=\iiint_V w_e dV$（$V$ 为电场存在的空间体积）
