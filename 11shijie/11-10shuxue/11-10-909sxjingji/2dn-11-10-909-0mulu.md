# 经济数学

经济数学是**应用数学与经济学、管理学交叉的核心学科**，核心是用数学模型、统计方法和优化工具量化经济规律、分析决策行为、解决经济运行中的实际问题。其研究领域覆盖宏观经济、微观经济、计量经济、金融经济等全维度经济场景，具体分类如下：

# 一、 微观经济数学（个体经济行为的量化分析）
聚焦**消费者、生产者、市场的决策规律**，核心是构建个体经济行为的优化模型，揭示供需关系与市场均衡机制。
1.  **消费者理论数学模型**
    - 核心内容：效用函数（如柯布-道格拉斯效用函数 $U(x_1,x_2)=x_1^\alpha x_2^\beta$）、无差异曲线的数学性质；**约束优化问题**（在预算约束 $p_1x_1+p_2x_2\le I$ 下最大化效用），用拉格朗日乘数法求解最优消费组合；收入效应与替代效应的微分分析。
    - 拓展方向：不确定性下的消费决策（期望效用理论、风险厌恶的度量——绝对风险厌恶系数 $A(w)=-\frac{u''(w)}{u'(w)}$）。
2.  **生产者理论数学模型**
    - 核心内容：生产函数（如柯布-道格拉斯生产函数 $Q=AK^\alpha L^\beta$）、边际产量与规模报酬的微积分分析；成本函数（短期成本、长期成本的导数性质）；**利润最大化模型**（在生产技术与要素价格约束下最大化利润）。
    - 拓展方向：生产要素的最优配置、技术进步的量化分析（索洛剩余）。
3.  **市场结构与均衡数学**
    - 核心内容：完全竞争市场的供需均衡（需求函数与供给函数的交点求解）；垄断市场的定价模型（边际收益等于边际成本 $MR=MC$ 的微分条件）；寡头市场的博弈论模型（古诺模型、伯川德模型、斯塔克伯格模型）。
    - 拓展方向：一般均衡理论（瓦尔拉斯均衡的存在性、唯一性证明，涉及拓扑学与不动点定理）。

# 二、 宏观经济数学（国民经济运行的动态建模）
聚焦**经济总量的变化规律**，核心是构建宏观经济变量（GDP、通胀、失业率、利率）的动力学模型，分析经济增长与经济波动机制。
1.  **经济增长模型**
    - 核心内容：**索洛增长模型**（新古典增长模型）——用常微分方程刻画资本积累、人口增长、技术进步与人均产出的关系，求解稳态人均资本与稳态产出；**拉姆齐-卡斯-库普曼斯模型**（内生储蓄率的增长模型，基于最优控制理论）；**内生增长模型**（罗默模型、卢卡斯模型，将技术进步内生化，涉及微分方程与动态优化）。
    - 拓展方向：经济增长的收敛性分析（绝对收敛、条件收敛）、人力资本与创新对增长的贡献量化。
2.  **经济周期模型**
    - 核心内容：凯恩斯主义的总需求-总供给（AD-AS）模型的数学推导；**乘数-加速数模型**（用差分方程描述投资与产出的周期性波动）；真实经济周期（RBC）模型（基于动态随机一般均衡DSGE框架，用随机微分方程刻画技术冲击对经济的影响）。
    - 拓展方向：货币政策、财政政策对经济周期的调控效应分析。
3.  **宏观经济政策的数学分析**
    - 核心内容：IS-LM模型的联立方程求解（产品市场与货币市场的均衡）；菲利普斯曲线（通胀率与失业率的关系）的统计建模；最优政策设计（基于庞特里亚金极大值原理的最优财政/货币政策规则）。

# 三、 计量经济学（经济数据的统计建模与推断）
是经济数学的**数据驱动核心**，核心是用统计学方法构建经济变量之间的因果关系模型，实现经济预测与政策评估。
1.  **经典计量模型**
    - 核心内容：**线性回归模型**（一元线性回归 $y=\beta_0+\beta_1x+\varepsilon$、多元线性回归 $y=\beta_0+\beta_1x_1+\dots+\beta_kx_k+\varepsilon$）的参数估计（最小二乘法OLS）、假设检验（t检验、F检验）、拟合优度分析（$R^2$）；异方差、自相关、多重共线性的诊断与修正方法。
    - 拓展方向：广义最小二乘法（GLS）、工具变量法（IV）、两阶段最小二乘法（2SLS）。
2.  **时间序列计量模型**
    - 核心内容：平稳时间序列分析（自回归AR模型、移动平均MA模型、自回归移动平均ARMA模型、自回归积分移动平均ARIMA模型）；非平稳时间序列的单位根检验（ADF检验）、协整分析（Engle-Granger两步法）；向量自回归（VAR）模型（用于宏观经济变量的动态联动分析）。
    - 拓展方向：GARCH模型（刻画金融时间序列的波动率聚集效应）、状态空间模型（卡尔曼滤波）。
3.  **面板数据计量模型**
    - 核心内容：混合回归模型、固定效应模型（FE）、随机效应模型（RE）；模型选择检验（Hausman检验）；动态面板模型（系统GMM估计）。
    - 应用方向：个体异质性分析、政策评估的双重差分法（DID）、断点回归设计（RDD）。
4.  **非参数与半参数计量模型**
    - 核心内容：核回归、局部线性回归、半参数线性模型；克服参数模型的函数形式假设限制，更灵活地拟合经济数据。

# 四、 数理金融与金融经济数学（金融市场与资产定价）
是经济数学与金融学的交叉领域，核心是量化金融资产价格与风险，优化投资决策（与前文金融数学有重叠，侧重经济视角）。
1.  **资产定价模型**
    - 核心内容：资本资产定价模型（CAPM）——$E(R_i)=R_f+\beta_i(E(R_m)-R_f)$；套利定价理论（APT）——多因子定价模型；有效市场假说的数学验证。
    - 拓展方向：期权定价模型（Black-Scholes模型）、信用风险定价模型（KMV模型）。
2.  **投资组合优化**
    - 核心内容：马科维茨均值-方差模型（在收益约束下最小化风险，或风险约束下最大化收益，二次规划求解）；资本配置线（CAL）与有效前沿。
    - 拓展方向：行为金融中的投资决策模型（考虑非理性行为的资产配置）。

# 五、 博弈论与产业组织数学（策略性行为的量化分析）
聚焦**经济主体的策略互动**，核心是用博弈论工具分析寡头竞争、契约设计、机制设计等问题。
1.  **非合作博弈论**
    - 核心内容：纳什均衡的定义与求解（纯策略纳什均衡、混合策略纳什均衡）；完全信息静态博弈（囚徒困境、智猪博弈）、完全信息动态博弈（子博弈完美纳什均衡，逆向归纳法）；不完全信息博弈（贝叶斯纳什均衡）。
    - 应用方向：寡头市场的价格竞争、产量竞争模型。
2.  **合作博弈论**
    - 核心内容：联盟博弈、沙普利值（Shapley Value）的计算与分配规则；核心解、核仁解。
    - 应用方向：供应链合作、公共产品供给的成本分摊。
3.  **机制设计理论**
    - 核心内容：激励相容原理、显示原理；最优拍卖设计、公共品的有效供给机制。
    - 应用方向：政府采购机制、税收政策设计。

# 六、 最优化理论与运筹学在经济中的应用
核心是用**优化工具解决经济资源的最优配置问题**，覆盖生产、物流、供应链等场景。
1.  **线性规划与整数规划**
    - 核心内容：线性规划的标准型、单纯形法；整数规划的分支定界法、割平面法。
    - 应用方向：生产计划的资源分配、运输问题（表上作业法）、供应链的库存优化。
2.  **动态规划**
    - 核心内容：贝尔曼方程、最优性原理；离散时间与连续时间动态规划。
    - 应用方向：企业的跨期投资决策、消费者的生命周期储蓄模型。
3.  **多目标优化**
    - 核心内容：帕累托最优解、加权和法、目标规划法。
    - 应用方向：经济发展与环境保护的平衡、企业利润与社会责任的多目标决策。

# 七、 新兴交叉领域（数据驱动的经济数学）
随着大数据与人工智能技术发展，经济数学与前沿技术融合形成新方向。
1.  **机器学习与经济预测**
    - 核心内容：用回归树、随机森林、神经网络、LSTM模型预测经济指标（GDP增速、通胀率、股价走势）；用因果推断模型（如双重差分法、合成控制法）评估政策效应。
    - 应用方向：宏观经济预警系统、金融风险监测。
2.  **行为经济数学**
    - 核心内容：量化投资者的非理性行为（过度自信、损失厌恶），构建包含行为因素的效用函数与定价模型；用实验经济学方法验证数学模型的合理性。
    - 应用方向：消费行为预测、金融市场异象解释。
