# 数列与简单函数

核心结论：数列是定义域为正整数集（或其有限子集）的特殊函数，初等函数（一次、二次、反比例等6类）是基于“变量对应关系”的基础模型，二者以函数定义和实数运算公理为核心，结合数列核心公式、求和方法及函数性质，可系统解决递推关系、变化规律、优化等问题。

### 一、数列相关公理、定理、公式与求和方法
#### 1. 数列的定义公理
对于正整数集N⁺（或其有限子集{1,2,...,n}）中的每一个数k，都有唯一确定的实数aₖ与之对应，则{aₖ}称为数列，记为{aₙ}（n∈N⁺）。

#### 2. 等差数列核心定理与公式
- 定义：从第二项起，每一项与前一项的差为常数d（公差），即aₙ₊₁ - aₙ = d（n∈N⁺）。
- 通项公式：aₙ = a₁ + (n - 1)d（a₁为首项）
  - 证明：由定义递推，a₂ = a₁ + d，a₃ = a₂ + d = a₁ + 2d，…，用归纳法验证，n=1时成立，假设n=k时aₖ=a₁+(k-1)d，则n=k+1时aₖ₊₁=aₖ+d=a₁+kd，结论成立。
- 前n项和公式：
  1. Sₙ = n(a₁ + aₙ)/2（已知a₁、aₙ、n）
  2. Sₙ = na₁ + n(n - 1)d/2（已知a₁、d、n）
  - 证明：用“倒序相加法”，Sₙ = a₁ + a₂ +... + aₙ，Sₙ = aₙ + aₙ₋₁ +... + a₁，两式相加得2Sₙ = n(a₁ + aₙ)，化简得第一个公式；代入通项公式推导第二个公式。
- 中项性质：若a、A、b成等差数列，则A = (a + b)/2（A为等差中项）
  - 证明：由等差数列定义，A - a = b - A，移项得2A = a + b，故A = (a + b)/2。

#### 3. 等比数列核心定理与公式
- 定义：从第二项起，每一项与前一项的比为常数q（公比，q≠0），即aₙ₊₁/aₙ = q（n∈N⁺）。
- 通项公式：aₙ = a₁qⁿ⁻¹（a₁为首项，a₁≠0）
  - 证明：递推得a₂ = a₁q，a₃ = a₂q = a₁q²，…，归纳法验证，n=1时成立，假设n=k时aₖ=a₁qᵏ⁻¹，则n=k+1时aₖ₊₁=aₖq=a₁qᵏ，结论成立。
- 前n项和公式：
  1. 当q=1时，Sₙ = na₁（各项均为a₁）
  2. 当q≠1时，Sₙ = a₁(1 - qⁿ)/(1 - q) = (a₁ - aₙq)/(1 - q)
  - 证明：q=1时，各项相等，和为na₁；q≠1时，用“错位相减法”，Sₙ = a₁ + a₁q +... + a₁qⁿ⁻¹，qSₙ = a₁q +... + a₁qⁿ，两式相减得(1 - q)Sₙ = a₁(1 - qⁿ)，化简得公式。
- 中项性质：若a、G、b成等比数列，则G² = ab（G为等比中项，ab>0）
  - 证明：由定义，G/a = b/G，交叉相乘得G² = ab。

#### 4. 数列极限基本公理
- 唯一性公理：收敛数列的极限唯一（若limₙ→∞aₙ = A且limₙ→∞aₙ = B，则A=B）。
- 有界性定理：收敛数列必有界（存在M>0，对所有n∈N⁺，|aₙ|≤M）。
- 保号性定理：若limₙ→∞aₙ = A>0（或A<0），则存在N∈N⁺，当n>N时，aₙ>0（或aₙ<0）。

#### 5. 数列求和方法（裂项相消、错位相减）
##### （1）裂项相消法
- 定义：将通项拆分为两个项的差，累加时中间项抵消，保留首尾少数项求和。
- 适用场景：通项为分式形式，分母可分解为两个等差数项的乘积（如1/[n(n+k)]）。
- 核心步骤：
  1. 裂项：aₙ = f(n) - f(n+1)（或f(n-1) - f(n)）；
  2. 累加：Sₙ = [f(1)-f(2)] + [f(2)-f(3)] +... + [f(n)-f(n+1)]；
  3. 抵消：化简得Sₙ = f(1) - f(n+1)。
- 示例：求aₙ=1/[n(n+1)]的前n项和
  - 裂项：1/[n(n+1)] = 1/n - 1/(n+1)
  - 累加抵消：Sₙ = (1-1/2)+(1/2-1/3)+...+(1/n-1/(n+1)) = 1 - 1/(n+1) = n/(n+1)

##### （2）错位相减法
- 定义：针对“等差数列×等比数列”形式的数列（aₙ = bₙ·cₙ），通过“乘公比→错位→相减”求和。
- 适用场景：通项为(aₙ=(kn+b)·qⁿ⁻¹，q≠1)。
- 核心步骤：
  1. 写Sₙ：Sₙ = b₁c₁ + b₂c₂ +... + bₙcₙ；
  2. 乘公比：qSₙ = b₁c₂ +... + bₙcₙ₊₁；
  3. 相减：(1 - q)Sₙ = b₁c₁ + (b₂ - b₁)c₂ +... - bₙcₙ₊₁；
  4. 化简：中间等比数列求和，解出Sₙ。
- 示例：求aₙ=(2n-1)·2ⁿ⁻¹的前n项和
  - Sₙ=1×2⁰+3×2¹+...+(2n-1)×2ⁿ⁻¹ ①；2Sₙ=1×2¹+...+(2n-1)×2ⁿ ②
  - ①-②：-Sₙ=1+2×(2¹+2²+...+2ⁿ⁻¹)-(2n-1)×2ⁿ
  - 中间等比和为2ⁿ⁺¹-4，代入化简得Sₙ=(2n-1)×2ⁿ -1

### 二、初等函数相关公理、定义与性质
#### 1. 函数的定义公理
设A、B是非空数集，若对任意x∈A，都有唯一确定的y∈B与之对应，则称y是x的函数，记为y=f(x)（x为自变量，y为因变量）。

#### 2. 各类初等函数的定义与性质（单调性、奇偶性）
##### （1）一次函数（y = kx + b，k≠0）
- 定义：形如y=kx+b（k、b为常数，k≠0），定义域、值域均为R。
- 单调性：k>0时R上单调递增；k<0时R上单调递减（b不影响单调性）。
- 奇偶性：b=0时为奇函数；b≠0时非奇非偶。

##### （2）反比例函数（y = k/x，k≠0）
- 定义：形如y=kx⁻¹（k≠0），定义域、值域均为(-∞,0)∪(0,+∞)。
- 单调性：k>0时，在(-∞,0)和(0,+∞)上单调递减；k<0时单调递增（不可说定义域上单调）。
- 奇偶性：对任意x≠0，f(-x)=-f(x)，为奇函数（图像关于原点对称）。

##### （3）二次函数（y = ax² + bx + c，a≠0）
- 定义：形如y=ax²+bx+c（a≠0），顶点式为y=a(x+b/(2a))²+(4ac-b²)/(4a)。
- 定义域：R；值域：a>0时[(4ac-b²)/(4a),+∞)，a<0时(-∞,(4ac-b²)/(4a)]。
- 单调性：对称轴x=-b/(2a)；a>0时，左减右增；a<0时，左增右减。
- 奇偶性：b=0时为偶函数；b≠0时非奇非偶。

##### （4）幂函数（y = xᵅ，α为常数）
- 定义：形如y=xᵅ（α为实数），底数为自变量，指数为常数。
- 定义域：随α变化（如α=1/2时x≥0，α=-1时x≠0）。
- 单调性：α>0时，[0,+∞)上单调递增；α<0时，(0,+∞)上单调递减。
- 奇偶性：α为偶数时为偶函数；α为奇数时为奇函数；定义域不关于原点对称则非奇非偶。

##### （5）指数函数（y = aˣ，a>0且a≠1）
- 定义：形如y=aˣ（a>0且a≠1），指数为自变量，底数为常数。
- 定义域：R；值域：(0,+∞)（图像过(0,1)）。
- 单调性：a>1时R上单调递增；0<a<1时R上单调递减。
- 奇偶性：f(-x)=1/aˣ≠±f(x)，非奇非偶。

##### （6）对数函数（y = logₐx，a>0且a≠1）
- 定义：形如y=logₐx（a>0且a≠1），是指数函数y=aˣ的反函数。
- 定义域：(0,+∞)（真数>0）；值域：R（图像过(1,0)）。
- 单调性：a>1时(0,+∞)上单调递增；0<a<1时(0,+∞)上单调递减。
- 奇偶性：定义域不关于原点对称，非奇非偶。

#### 3. 函数单调性与奇偶性判定定理
- 单调性判定：对任意x₁<x₂∈区间I，f(x₁)<f(x₂)则递增，f(x₁)>f(x₂)则递减（如一次函数y=kx+b，k>0时递增）。
- 奇偶性判定：定义域关于原点对称时，f(-x)=f(x)为偶函数，f(-x)=-f(x)为奇函数（如y=ax²为偶函数，y=k/x为奇函数）。

### 三、应用场景
#### 1. 数列的应用场景
- 数学内部：递推关系求解、级数求和、函数极限铺垫、概率分布列分析。
- 实际场景：分期付款（等比数列求和）、复利计息（等比数列）、材料堆放（等差数列求和）、人口增长/元素衰变（等比数列模型）。

#### 2. 初等函数的应用场景
- 数学内部：方程零点求解、不等式证明、图像分析。
- 实际场景：成本预算（一次函数）、利润最大化（二次函数）、压强计算（反比例函数）、人口增长（指数函数）、数据统计分析（对数函数）。

### 四、综合应用示例
#### 1. 数列示例（复利计息）
- 问题：本金10000元，年利率2%复利计息，5年后本利和？
- 解答：本利和为等比数列，a₁=10000，q=1.02，n=5，a₅=10000×1.02⁴≈10824.32元。

#### 2. 初等函数示例（利润最大化）
- 问题：商品进价30元，售价x元（30≤x≤60），销量y=-2x+120，求最大利润。
- 解答：利润L=(x-30)(-2x+120)=-2x²+180x-3600，a=-2<0，顶点x=45，最大利润450元。
