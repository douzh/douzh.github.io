# 代数研究范畴

代数是数学的核心分支，其研究范畴随数学发展从**具体的数与运算**逐步抽象为**集合与代数结构**，覆盖初等、高等、抽象三个层级。以下是代数的完整研究范畴划分：

# 一、 初等代数（基础范畴，小学至高中阶段）
核心是**用符号代替数，研究数与代数式的运算、方程与不等式的求解**，解决实际的数量关系问题。
1.  **数系与基本运算**
    - 数的分类：自然数、整数、有理数、无理数、实数、复数的定义与性质。
    - 数的运算：加减乘除、乘方开方的法则；运算律（交换律、结合律、分配律）；运算优先级。
    - 衍生概念：奇数、偶数、质数、合数、最大公因数、最小公倍数、科学记数法。

    - [[2dn-11-10-110-101fushu]]
    - [[2dn-11-10-110-101fushu2]]
    - [[2dn-11-10-110-110shuxi]]
2.  **代数式及其运算**
    - 代数式分类：整式（单项式、多项式）、分式、根式。
    - 整式运算：加减（去括号、合并同类项）、乘法（乘法公式）、除法（长除法）、因式分解。
    - 分式运算：化简、通分、约分、分式方程求解（检验增根）。
    - 根式运算：二次根式的性质、分母有理化、根式方程求解（检验增根）。
    - [[2dn-11-10-110-120yunsuan]]
3.  **方程与不等式**
    - 方程体系：一元一次方程、二元/多元一次方程组、一元二次方程（判别式、韦达定理）、分式方程、根式方程、高次方程（换元法降次）。
    - 不等式体系：一元一次不等式（组）、一元二次不等式、分式不等式、根式不等式；不等式的基本性质与证明。
4.  **数列与简单函数**
    - 数列：等差数列、等比数列的通项公式与前 $n$ 项和公式；数列求和方法（裂项相消、错位相减）。
    - 初等函数：一次函数、反比例函数、二次函数、幂函数、指数函数、对数函数的定义与性质（单调性、奇偶性）。

# 二、 高等代数（大学基础范畴，数学/理工专业核心）
核心是**将初等代数抽象化，研究多项式、矩阵、线性空间等结构化对象**，是代数与几何、分析的桥梁。
1.  **多项式理论**
    - 一元多项式：定义、次数、带余除法、整除性、最大公因式（辗转相除法）、不可约多项式、因式分解唯一性定理、代数基本定理。
    - 多元多项式：对称多项式、牛顿公式、多项式的根与系数关系。
2.  **行列式与矩阵**
    - 行列式：$n$ 阶行列式的定义、性质、计算方法（三角化、降阶、范德蒙德行列式）；克拉默法则。
    - 矩阵：矩阵的定义、运算（加减、数乘、乘法、转置）；逆矩阵（伴随矩阵法、初等变换法）；矩阵的秩；初等变换与初等矩阵；分块矩阵。
3.  **线性方程组**
    - 线性方程组的表示：系数矩阵、增广矩阵；解的判定定理（秩的应用）。
    - 齐次线性方程组：基础解系、通解结构。
    - 非齐次线性方程组：特解+对应齐次方程组通解的结构。
4.  **向量空间（线性空间）与线性变换**
    - 向量空间：定义（8条公理）、子空间、生成子空间、线性相关性（线性组合、线性无关）、基与维数、坐标变换、过渡矩阵。
    - 线性变换：定义、线性变换的矩阵表示、特征值与特征向量、线性变换的对角化。
5.  **欧几里得空间（欧氏空间）**
    - 内积的定义与性质；向量的长度、夹角、正交性；标准正交基（施密特正交化）。
    - 正交变换与正交矩阵；对称变换与实对称矩阵的正交对角化。
6.  **二次型**
    - 二次型的矩阵表示；化二次型为标准形（配方法、正交变换法）。
    - 惯性定理（正/负惯性指数）；正定二次型的判定（顺序主子式、特征值）。

# 三、 抽象代数（近世代数，大学进阶范畴，数学专业深化）
核心是**脱离具体的数与运算，研究任意集合上定义的代数结构及其性质**，是现代代数的核心。
1.  **群论**
    - 群的定义：非空集合+满足封闭性、结合律、单位元、逆元的二元运算；交换群（阿贝尔群）、有限群、无限群。
    - 群的子结构：子群、正规子群、商群；群的同态与同构；循环群、置换群、对称群、交错群。
    - 群论定理：拉格朗日定理、柯西定理、西罗定理。
2.  **环论**
    - 环的定义：非空集合+加法（交换群）+乘法（结合律、分配律）；交换环、整环、除环、无零因子环。
    - 环的子结构：子环、理想、商环；环的同态与同构；多项式环、整数环。
3.  **域论**
    - 域的定义：交换的除环（乘法存在逆元）；常见域（有理数域 $\mathbb{Q}$、实数域 $\mathbb{R}$、复数域 $\mathbb{C}$、有限域）。
    - 域的扩张：代数扩张、超越扩张、分裂域、伽罗瓦扩张。
4.  **其他抽象代数结构（拓展范畴）**
    - 模论：环上的线性空间，是向量空间的推广。
    - 格论：满足交换律、结合律、吸收律的偏序集；布尔代数。
    - 同调代数：研究模的同调序列，连接代数与拓扑。

# 四、 代数的交叉与应用范畴（现代数学延伸）
1.  **代数数论**：研究代数数（整系数多项式的根）与代数整数，结合数论与抽象代数。
2.  **代数几何**：用代数方法研究几何图形，核心是多项式方程组的解集（代数簇）。
3.  **线性代数应用**：矩阵论在计算机图形学、机器学习、密码学中的应用；线性方程组在工程计算中的求解。
