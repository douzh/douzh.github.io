# 方程与不等式

核心结论：方程与不等式的理论以实数运算公理为基石，方程聚焦“等量关系求解”，不等式聚焦“不等量关系判定”，二者是解决数学问题与实际数量关系分析的核心工具。

### 一、公理与定理（含证明）
#### 1. 方程相关公理与定理
方程的核心是“等式关系”，所有运算规则基于等式公理推导。

##### （1）等式基本公理（无需证明，方程运算的前提）
- 自反性：对任意实数a，a = a。
- 对称性：若a = b，则b = a。
- 传递性：若a = b且b = c，则a = c。
- 同加/减公理：若a = b，则对任意实数c，a + c = b + c（或a - c = b - c）。
- 同乘/除公理：若a = b，对任意实数c，ac = bc；若c ≠ 0，则a/c = b/c。
- 代入公理：若a = b，则任意含a的代数式f(a) = f(b)。

##### （2）一元一次方程解的存在定理
- 定理：形如ax + b = 0（a、b为常数，a ≠ 0）的一元一次方程，有且仅有唯一解x = -b/a。
- 证明：由等式同减公理，ax + b - b = 0 - b → ax = -b；再由同除公理（a ≠ 0），两边同除以a，得x = -b/a，解唯一。

##### （3）一元二次方程根的相关定理
设一元二次方程为ax² + bx + c = 0（a、b、c为常数，a ≠ 0）。
- 根的判别式定理：Δ = b² - 4ac
  - 若Δ > 0，方程有两个不相等的实数根；
  - 若Δ = 0，方程有两个相等的实数根；
  - 若Δ < 0，方程无实数根（有一对共轭复数根）。
- 证明：通过配方法推导求根公式，ax² + bx + c = 0 → x² + (b/a)x = -c/a → (x + b/(2a))² = (b² - 4ac)/(4a²)。右边非负时才有实数根，故Δ = b² - 4ac的符号决定根的情况。
- 韦达定理（根与系数关系）：若方程的两根为x₁、x₂，则x₁ + x₂ = -b/a，x₁x₂ = c/a。
- 证明：由求根公式x = [-b ± √Δ]/(2a)，相加得(x₁ + x₂) = [-b + √Δ - b - √Δ]/(2a) = -2b/(2a) = -b/a；相乘得x₁x₂ = [b² - (b² - 4ac)]/(4a²) = 4ac/(4a²) = c/a。

##### （4）方程增根定理（分式/根式方程）
- 定理：分式方程、根式方程求解时，因“去分母”“平方”等运算扩大未知数取值范围，导致满足变形后方程但不满足原方程的解为增根。
- 证明：原方程对未知数有定义域限制（分式分母≠0、根式被开方数≥0），变形运算未考虑该限制，故可能产生超出定义域或不满足原方程的解，需检验排除。

#### 2. 不等式相关公理与定理
不等式的核心是“不等关系的传递与变形”，基于实数的大小公理推导。

##### （1）实数大小公理（无需证明）
对任意两个实数a、b，以下三种关系必有且仅有一种成立：a > b，a = b，a < b。且a > b ⇔ a - b > 0；a < b ⇔ a - b < 0。

##### （2）不等式基本性质定理（含证明）
- 性质1（传递性）：若a > b且b > c，则a > c。
  证明：a > b ⇒ a - b > 0；b > c ⇒ b - c > 0。两正数相加仍为正，(a - b) + (b - c) = a - c > 0 ⇒ a > c。
- 性质2（可加性）：若a > b，则a + c > b + c（c为任意实数）。
  证明：a > b ⇒ a - b > 0；(a + c) - (b + c) = a - b > 0 ⇒ a + c > b + c。
- 性质3（乘正数保号性）：若a > b且c > 0，则ac > bc；若a > b且c < 0，则ac < bc。
  证明：a > b ⇒ a - b > 0；c > 0时，(a - b)c > 0 ⇒ ac - bc > 0 ⇒ ac > bc；c < 0时，(a - b)c < 0 ⇒ ac - bc < 0 ⇒ ac < bc。
- 性质4（同向可加性）：若a > b且c > d，则a + c > b + d。
  证明：由性质2，a + c > b + c且b + c > b + d，再由传递性得a + c > b + d。
- 性质5（同向同正可乘性）：若a > b > 0且c > d > 0，则ac > bd。
  证明：由性质3，ac > bc且bc > bd，再由传递性得ac > bd。

##### （3）重要不等式定理
- 均值不等式（基本不等式）：对任意正数a、b，(a + b)/2 ≥ √(ab)，当且仅当a = b时取等号。
  证明：(√a - √b)² ≥ 0 ⇒ a - 2√(ab) + b ≥ 0 ⇒ a + b ≥ 2√(ab) ⇒ (a + b)/2 ≥ √(ab)。
- 柯西不等式（二维）：对任意实数a、b、c、d，(a² + b²)(c² + d²) ≥ (ac + bd)²，当且仅当ad = bc时取等号。
  证明：展开左边得a²c² + a²d² + b²c² + b²d²；右边得a²c² + 2acbd + b²d²。左边 - 右边 = a²d² - 2acbd + b²c² = (ad - bc)² ≥ 0，故不等式成立。

### 二、应用场景
#### 1. 方程的应用场景
- 数学内部：求解函数零点（如二次函数与x轴交点）、数列通项公式（已知递推关系列方程）、几何图形边长/角度计算（如三角形周长、圆的半径）。
- 实际场景：
  - 工程领域：行程问题（路程=速度×时间，列方程求速度/时间）、工程量计算（工作总量=效率×时间）。
  - 经济领域：利润问题（利润=售价-成本，列方程求定价/销量）、增长率问题（终值=初值×(1+增长率)ⁿ）。
  - 物理领域：运动学公式（如s = v₀t + ½at²，列方程求加速度a）、力学平衡（受力平衡列方程）。
  - 生活场景：溶液浓度问题（溶质=浓度×溶液质量，列方程求稀释/浓缩比例）。

#### 2. 不等式的应用场景
- 数学内部：求函数定义域（如√(x - 3)中x - 3 ≥ 0）、函数值域（如y = x + 1/x（x > 0）用均值不等式求最小值）、数列单调性判断、方程根的分布（如一元二次方程有正根的条件）。
- 实际场景：
  - 优化问题：成本最小化（如生产两种产品，资源约束下求最低成本）、利润最大化（销量约束下求最大利润）。
  - 资源分配：如分配资金到两个项目，要求收益率不低于某值，列不等式确定分配范围。
  - 质量控制：产品尺寸误差范围（如零件直径5±0.1cm，即4.9cm ≤ 直径 ≤ 5.1cm）。
  - 生活场景：购物优惠对比（如满减与折扣，列不等式判断哪种更划算）。

### 三、应用示例
#### 1. 方程应用示例
##### （1）一元一次方程
- 问题：某车间有22名工人，每人每天可生产1200个螺钉或2000个螺母，1个螺钉需配2个螺母。为使每天生产的螺钉和螺母刚好配套，应安排多少工人生产螺钉？
- 解答：设安排x人生产螺钉，则(22 - x)人生产螺母。配套关系：螺母数量=2×螺钉数量，列方程2000(22 - x) = 2×1200x → 2000×22 - 2000x = 2400x → 44000 = 4400x → x = 10。
- 结论：安排10人生产螺钉，12人生产螺母。

##### （2）一元二次方程（韦达定理应用）
- 问题：已知一元二次方程x² - 5x + 6 = 0，求两根之和与两根之积，并验证。
- 解答：a=1，b=-5，c=6。由韦达定理，x₁ + x₂ = -b/a = 5，x₁x₂ = c/a = 6。因式分解方程得(x - 2)(x - 3) = 0，两根为2和3，和为5，积为6，验证成立。

##### （3）分式方程（检验增根）
- 问题：解方程(3)/(x - 1) = (4)/(x)
- 解答：两边同乘x(x - 1)（x≠0且x≠1）得3x = 4(x - 1) → 3x = 4x - 4 → x = 4。
- 检验：x=4时，分母x=4≠0，x-1=3≠0，代入原方程左边=3/3=1，右边=4/4=1，成立，故x=4是解。

##### （4）根式方程（检验增根）
- 问题：解方程√(2x - 3) = x - 1
- 解答：两边平方得2x - 3 = (x - 1)² → 2x - 3 = x² - 2x + 1 → x² - 4x + 4 = 0 → (x - 2)² = 0 → x=2。
- 检验：x=2时，被开方数2×2 - 3=1≥0，左边=√1=1，右边=2 - 1=1，成立，故x=2是解。

#### 2. 不等式应用示例
##### （1）一元一次不等式
- 问题：某超市推出满300减50的优惠，商品A单价80元，购买多少件A商品才能享受优惠？
- 解答：设购买x件，列不等式80x ≥ 300 → x ≥ 3.75。因x为整数，故x≥4。
- 结论：购买4件及以上可享受优惠。

##### （2）一元二次不等式
- 问题：解不等式x² - 3x - 4 < 0
- 解答：因式分解得(x - 4)(x + 1) < 0。方程(x - 4)(x + 1)=0的根为x₁=-1，x₂=4。二次函数开口向上，故不等式解集为-1 < x < 4。

##### （3）均值不等式应用（优化问题）
- 问题：用长20m的篱笆围一个矩形菜园，如何围能使菜园面积最大？最大面积是多少？
- 解答：设矩形长为x m，宽为y m，则2(x + y)=20 → x + y=10（x>0，y>0）。面积S=xy，由均值不等式，xy ≤ [(x + y)/2]² = 25，当且仅当x=y=5时取等号。
- 结论：围成长宽均为5m的正方形（特殊矩形），最大面积25m²。

##### （4）柯西不等式应用
- 问题：已知2x + 3y = 5，求x² + y²的最小值。
- 解答：由柯西不等式，(x² + y²)(2² + 3²) ≥ (2x + 3y)² → (x² + y²)(4 + 9) ≥ 25 → 13(x² + y²) ≥ 25 → x² + y² ≥ 25/13。当且仅当x/2 = y/3（即x=10/13，y=15/13）时取最小值。
- 结论：最小值为25/13。
