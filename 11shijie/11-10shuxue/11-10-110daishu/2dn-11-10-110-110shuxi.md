# 数系与基本运算

核心结论：数系按“自然数→整数→有理数→实数→复数”逐步扩展，核心是弥补前一数系的缺陷（如无逆元、不完备），基本运算基于交换律、结合律、分配律等公理，关键定理（如数学归纳法、确界原理）是数学推理的基础，应用覆盖计数、度量、工程等全场景。

## 一、数系与基本运算的核心公理
数系的扩展脉络是“满足更广泛运算需求”，每个数系的公理是后续运算和定理的基础，基本运算（加减乘除、乘方开方）的公理具有继承性和扩展性。

### 1.1 自然数系（ℕ）
- **核心公理：皮亚诺公理**（定义自然数的本质）
  1. 0∈ℕ（或1∈ℕ，主流两种定义，此处以0为起点）；
  2. 对任意n∈ℕ，存在唯一后继n'=n+1∈ℕ；
  3. 0不是任何自然数的后继；
  4. 若n'=m'，则n=m（后继唯一性）；
  5. 归纳公理：若S⊆ℕ，0∈S且“n∈S→n'∈S”，则S=ℕ。
- **基本运算公理**（加法、乘法定义）
  - 加法：a+0=a；a+b'=(a+b)'（递归定义），满足交换律a+b=b+a、结合律(a+b)+c=a+(b+c)；
  - 乘法：a×0=0；a×b'=a×b+a（递归定义），满足交换律a×b=b×a、结合律(a×b)×c=a×(b×c)、分配律a×(b+c)=a×b+a×c。

### 1.2 整数系（ℤ）
- **核心公理**（自然数扩展，弥补“无加法逆元”缺陷）
  1. 包含所有自然数，新增负元素：对任意a∈ℕ，存在-a∈ℤ，使得a+(-a)=0（加法逆元公理）；
  2. 0∈ℤ，满足a+0=a（加法单位元）；
- **基本运算**：减法定义为a-b=a+(-b)，运算公理继承自然数的交换律、结合律、分配律，且对加减乘封闭。

### 1.3 有理数系（ℚ）
- **核心公理**（整数扩展，弥补“无乘法逆元”缺陷）
  1. 有理数表示为a/b（a∈ℤ，b∈ℕ⁺，且a、b互质）；
  2. 对任意非零q∈ℚ，存在q⁻¹∈ℚ，使得q×q⁻¹=1（乘法逆元公理）；
- **基本运算**：除法定义为a÷b=a×b⁻¹（b≠0），运算公理延续，且对加减乘除（非零）封闭。

### 1.4 实数系（ℝ）
- **核心公理**（有理数扩展，弥补“不完备性”缺陷）
  1. 包含所有有理数，满足“完备性公理”（等价形式：确界原理）：非空有上界的实数集必有唯一上确界；
  2. 运算公理继承有理数，新增非负实数的开方运算（如√2∈ℝ）。

### 1.5 复数系（ℂ）
- **核心公理**（实数扩展，弥补“负数不能开偶次方”缺陷）
  1. 引入虚数单位i，满足i²=-1；
  2. 任意复数z=a+bi（a,b∈ℝ），加法：(a+bi)+(c+di)=(a+c)+(b+d)i；乘法：(a+bi)(c+di)=(ac-bd)+(ad+bc)i；
  3. 运算满足交换律、结合律、分配律，对加减乘除（非零）封闭。

## 二、关键定理及证明
选取各数系中最基础、应用最广的定理，证明兼顾严谨性与易懂性。

### 2.1 数学归纳法（自然数系核心定理）
- **定理内容**：设P(n)是关于自然数n的命题，若：
  1. 基例：P(0)成立；
  2. 归纳步：若P(k)成立，则P(k+1)成立；
  则对所有n∈ℕ，P(n)成立。
- **证明**：
  令S={n∈ℕ | P(n)成立}。由基例知0∈S；由归纳步，若k∈S则k+1∈S。根据皮亚诺公理5（归纳公理），S=ℕ，故所有自然数n满足P(n)。

### 2.2 有理数的稠密性（有理数系关键定理）
- **定理内容**：任意两个有理数a<b，必存在有理数c使得a<c<b。
- **证明**：
  取c=(a+b)/2。因a、b是有理数，故a+b∈ℚ（有理数加法封闭），除以2等价于乘以1/2（1/2∈ℚ），故c∈ℚ。
  又a=(a+a)/2 < (a+b)/2 < (b+b)/2 = b，故a<c<b，即c满足条件。

### 2.3 确界原理推论：√2是实数（实数系核心定理）
- **定理内容**：存在唯一实数α，使得α²=2（即√2∈ℝ）。
- **证明**：
  1. 构造集合S={x∈ℝ | x²<2}。S非空（1∈S，1²=1<2），且有上界（2∈ℝ，x²<2⇒x<2）；
  2. 由实数完备性公理（确界原理），S存在唯一上确界α；
  3. 证明α²=2：
     - 若α²<2，取ε=(2-α²)/(2α+1)（ε>0），则(α+ε)²=α²+2αε+ε² < α²+2αε+ε=α²+ε(2α+1)=2，故α+ε∈S，与α是上界矛盾；
     - 若α²>2，取ε=(α²-2)/(2α)（ε>0），则(α-ε)²=α²-2αε+ε²>α²-2αε=2，故α-ε是S的上界，与α是最小上界矛盾；
  4. 故α²=2，即√2=α∈ℝ。

### 2.4 复数模长乘法公式（复数系常用定理）
- **定理内容**：设z₁=a+bi，z₂=c+di（a,b,c,d∈ℝ），则|z₁z₂|=|z₁|·|z₂|（|z|=√(实部²+虚部²)为复数模长）。
- **证明**：
  |z₁|=√(a²+b²)，|z₂|=√(c²+d²)，故|z₁|·|z₂|=√[(a²+b²)(c²+d²)]；
  z₁z₂=(ac-bd)+(ad+bc)i，故|z₁z₂|=√[(ac-bd)²+(ad+bc)²]；
  展开验证：(ac-bd)²+(ad+bc)²=a²c²-2acbd+b²d²+a²d²+2adbc+b²c²=a²(c²+d²)+b²(c²+d²)=(a²+b²)(c²+d²)，故|z₁z₂|=√[(a²+b²)(c²+d²)]=|z₁|·|z₂|。

## 三、应用场景与应用示例
每个数系的应用都对应其核心特性，示例兼顾数学推理与实际场景。

### 3.1 自然数系
- **应用场景**：计数、递推问题、数学归纳法证明、离散量计算。
- **应用示例**：证明1+2+3+...+n=n(n+1)/2（求和公式）
  - 基例：n=1时，左边=1，右边=1×2/2=1，成立；
  - 归纳步：假设n=k时成立，即1+2+...+k=k(k+1)/2；
  - 当n=k+1时，左边=1+2+...+k+(k+1)=k(k+1)/2 + (k+1)=(k+1)(k+2)/2，与右边相等，故公式成立；
  - 实际应用：统计班级50名学生的总分，可直接用公式计算1+2+...+50=50×51/2=1275。

### 3.2 整数系
- **应用场景**：有正负的量计算（债务、温差、海拔）、离散量的增减变化。
- **应用示例**：温差计算
  - 场景：某城市清晨气温为-5℃，中午气温上升12℃，求中午气温；
  - 计算：(-5)+12=7（℃），利用整数加法公理（-5的加法逆元是5，12-5=7）；
  - 实际意义：温度从负数值上升，用整数加法直接刻画“增减”关系。

### 3.3 有理数系
- **应用场景**：比例分配、分数运算、精度要求不高的度量（如日常购物、工程配料）。
- **应用示例**：混凝土配料比例
  - 场景：混凝土中水泥、沙子、石子的比例为1:2:3，现有水泥5吨，需配多少吨沙子和石子？
  - 计算：水泥占1份=5吨，沙子占2份=5×(2/1)=10吨，石子占3份=5×(3/1)=15吨；
  - 核心：利用有理数的比例运算（乘法逆元与分配律），实现按比例分配资源。

### 3.4 实数系
- **应用场景**：连续量度量（长度、面积、速度、温度）、极限运算、微积分、几何计算。
- **应用示例**：圆的面积计算
  - 场景：计算半径为2cm的圆的面积；
  - 原理：圆的面积公式S=πr²，其中π是无理数（属于实数），依赖实数的完备性（π的定义是圆周长与直径的比，需实数系保证其存在）；
  - 计算：S=π×2²=4π≈12.57（cm²）；
  - 实际应用：建筑设计中计算圆形花坛的占地面积、机械加工中计算圆形零件的截面积。

### 3.5 复数系
- **应用场景**：交流电路分析、量子力学、几何变换（旋转、缩放）、信号处理。
- **应用示例**：交流电路阻抗计算
  - 场景：交流电路中，电感阻抗Z_L=jωL（j=i，ω为角频率，L为电感），电阻R=10Ω，电感L=0.1H，ω=100rad/s，求总阻抗Z；
  - 计算：Z=R+Z_L=10+j(100×0.1)=10+j10（Ω），模长|Z|=√(10²+10²)=10√2≈14.14Ω，辐角θ=45°；
  - 意义：复数可同时表示阻抗的“电阻分量”和“电抗分量”，辐角表示电压与电流的相位差，是电路分析的核心工具。
