# 复数

复数是对实数的扩充，它可以解决实数范围内无法解决的方程问题（比如 $x^2 = -1$），是数学、物理、工程等领域的重要工具。

### 复数的定义

形如 $\boldsymbol{z = a + bi}$ 的数称为复数，其中：

- $a$ 和 $b$ 都是实数；

- $i$ 是虚数单位，规定 $i^2 = -1$；

- $a$ 称为复数 $z$ 的实部，记作 $\text{Re}(z) = a$；

- $b$ 称为复数 $z$ 的虚部，记作 $\text{Im}(z) = b$（注意虚部是实数 $b$，不是 $bi$）。

### 复数的分类

根据实部和虚部的取值，复数可分为三类：

1. 实数：当 $b = 0$ 时，$z = a$，就是普通的实数；

2. 纯虚数：当 $a = 0$ 且 $b \neq 0$ 时，$z = bi$，比如 $3i$、$-5i$；

3. 非纯虚数的虚数：当 $a \neq 0$ 且 $b \neq 0$ 时，比如 $2 + 3i$、$-1 - 4i$。

### 复数的相等条件

两个复数 $z_1 = a_1 + b_1i$ 和 $z_2 = a_2 + b_2i$ 相等的充要条件是：

$a_1 = a_2 \quad \text{且} \quad b_1 = b_2$

注意：两个不全是实数的复数，不能比较大小。比如我们无法判断 $2 + 3i$ 和 $1 + 4i$ 谁大谁小。

### 复数的几何意义

复数可以和平面直角坐标系中的点、向量一一对应，这个平面称为复平面（也叫高斯平面）：

- 复平面的横轴为实轴，表示复数的实部 $a$；

- 纵轴为虚轴（原点除外），表示复数的虚部 $b$；

- 复数 $z = a + bi$ 对应复平面内的点 $(a, b)$，也对应从原点出发到点 $(a, b)$ 的向量 $\overrightarrow{OZ}$。

**复数的模**

向量 $\overrightarrow{OZ}$ 的长度称为复数 $z$ 的模，记作 $|z|$，计算公式为：

$|z| = \sqrt{a^2 + b^2}$

复数的模是一个非负实数，比如 $|2 + 3i| = \sqrt{2^2 + 3^2} = \sqrt{13}$。

### 复数的四则运算

设 $z_1 = a_1 + b_1i$，$z_2 = a_2 + b_2i$（$a_1,a_2,b_1,b_2\in\mathbb{R}$）

加法

$z_1 + z_2 = (a_1 + a_2) + (b_1 + b_2)i$

实部与实部相加，虚部与虚部相加。

减法

$z_1 - z_2 = (a_1 - a_2) + (b_1 - b_2)i$

实部与实部相减，虚部与虚部相减。

乘法

$z_1 \cdot z_2 = (a_1a_2 - b_1b_2) + (a_1b_2 + a_2b_1)i$

按照多项式乘法展开，再代入 $i^2 = -1$ 化简。

除法

$\frac{z_1}{z_2} = \frac{(a_1 + b_1i)(a_2 - b_2i)}{(a_2 + b_2i)(a_2 - b_2i)} = \frac{a_1a_2 + b_1b_2}{a_2^2 + b_2^2} + \frac{a_2b_1 - a_1b_2}{a_2^2 + b_2^2}i \quad (z_2 \neq 0)$

核心是分母实数化，给分子分母同乘分母的共轭复数（$z_2 = a_2 + b_2i$ 的共轭复数为 $\overline{z_2} = a_2 - b_2i$）。

### 共轭复数

对于复数 $z = a + bi$，称 $\boldsymbol{\overline{z} = a - bi}$ 为 $z$ 的共轭复数。

共轭复数的性质：

- $z + \overline{z} = 2a$（实数），$z - \overline{z} = 2bi$；

- $z \cdot \overline{z} = a^2 + b^2 = |z|^2$；

- $\overline{z_1 \pm z_2} = \overline{z_1} \pm \overline{z_2}$，$\overline{z_1 \cdot z_2} = \overline{z_1} \cdot \overline{z_2}$。

### 复数的三角形式与欧拉公式

除了代数形式 $z = a + bi$，复数还有三角形式：

$z = r(\cos\theta + i\sin\theta)$

其中 $r = |z|$ 是模，$\theta$ 是复数对应的向量与实轴正方向的夹角，称为辐角。

结合欧拉公式 $e^{i\theta} = \cos\theta + i\sin\theta$，复数还可以写成指数形式：

$z = re^{i\theta}$

这种形式在乘方、开方运算中非常方便（棣莫弗公式：$[r(\cos\theta + i\sin\theta)]^n = r^n(\cos n\theta + i\sin n\theta)$）。

### 欧拉公式

欧拉公式（e^(iθ) = cosθ + i sinθ）的核心几何意义是**复平面上的旋转变换**。

**核心几何解释**

- 公式左侧的e^(iθ)，可理解为“复平面上模长为1、辐角为θ的复数”。
- 右侧的cosθ + i sinθ，对应复平面内坐标为(cosθ, sinθ)的点，恰好落在单位圆上。
- 本质是：以自然常数e为底的虚指数运算，等价于在单位圆上绕原点旋转θ角（θ以弧度为单位）。

**关键延伸意义**

1. 连接代数与几何：将指数运算（代数）和旋转（几何）直接关联，搭建了两大数学领域的桥梁。
2. 描述圆周运动：θ随时间变化时，e^(iωt)（ω为角速度）可表示单位圆上的匀速圆周运动，是描述波动、振动的基础。
3. 单位圆的参数化：用单一指数形式简洁表示单位圆上的所有点，比三角函数形式更统一。

**特殊情况的几何直观**

当θ=π时，欧拉公式变为e^(iπ) + 1 = 0，几何上是“单位圆上绕原点旋转π角（180度），从点(1,0)转到(-1,0)”，直观体现了实数、虚数、指数和三角函数的内在统一。

### 欧拉公式证明

欧拉公式是连接复数、三角函数和指数函数的核心桥梁，常见且易懂的证明方法是**泰勒级数展开法**（无需高深知识，逻辑闭环）。

欧拉公式 `e^(iθ) = cosθ + i sinθ` 可通过对 `e^x`、`cosθ`、`sinθ` 分别做泰勒级数展开，再将 `x = iθ` 代入指数函数展开式，整理后与三角函数级数相加结果完全一致，从而证明成立。

**证明前提（泰勒级数展开式）**

泰勒级数的核心是：足够光滑的函数可表示为幂级数之和。以下是三个关键函数在 `x=0` 处的泰勒展开式（麦克劳林级数），收敛域均为全体实数（`θ` 为实数时适用）：
1. 指数函数：`e^x = 1 + x + x²/2! + x³/3! + x⁴/4! + x⁵/5! + … + xⁿ/n! + …`
2. 余弦函数：`cosθ = 1 - θ²/2! + θ⁴/4! - θ⁶/6! + … + (-1)ⁿθ^(2n)/(2n)! + …`
3. 正弦函数：`sinθ = θ - θ³/3! + θ⁵/5! - θ⁷/7! + … + (-1)ⁿθ^(2n+1)/(2n+1)! + …`

---

**步骤1：将 `x = iθ` 代入指数函数展开式**

根据虚数单位 `i` 的性质（`i² = -1`，`i³ = -i`，`i⁴ = 1`，`i⁵ = i`，周期为4），展开 `e^(iθ)`：
```
e^(iθ) = 1 + (iθ) + (iθ)²/2! + (iθ)³/3! + (iθ)⁴/4! + (iθ)⁵/5! + (iθ)⁶/6! + (iθ)⁷/7! + …
```

**步骤2：化简每一项的虚数单位幂次**

按 `i` 的周期性整理，分离实数项和含 `i` 的虚数项：
```
e^(iθ) = 1 + iθ + (i²θ²)/2! + (i³θ³)/3! + (i⁴θ⁴)/4! + (i⁵θ⁵)/5! + (i⁶θ⁶)/6! + (i⁷θ⁷)/7! + …
       = 1 + iθ - θ²/2! - iθ³/3! + θ⁴/4! + iθ⁵/5! - θ⁶/6! - iθ⁷/7! + …
```
（注：`i²=-1` 使第二项变负，`i³=-i` 使第四项带 `-i`，`i⁴=1` 使第六项为正，以此类推）

**步骤3：分组分离实数项和虚数项**

将不含 `i` 的项归为一组，含 `i` 的项提取 `i` 后归为另一组：
```
e^(iθ) = [1 - θ²/2! + θ⁴/4! - θ⁶/6! + …] + i[θ - θ³/3! + θ⁵/5! - θ⁷/7! + …]
```

**步骤4：对比三角函数的泰勒展开式**

观察两组级数，恰好分别对应 `cosθ` 和 `sinθ` 的泰勒展开式：
- 第一组（实数项）= `cosθ`
- 第二组（虚数项）= `sinθ`

因此：`e^(iθ) = cosθ + i sinθ`，欧拉公式得证。

### 复向量和向量的区别

**核心结论**

高斯平面的向量（复向量）本质是“复数的几何表示”，直角坐标系的向量是“多维空间的有向线段”，前者是后者在二维实空间的特例，但附加了复数特有的运算和意义。

1. **定义与本质**
- 高斯平面向量：以原点为起点，终点坐标对应复数的实部和虚部（a,b），本质是“复数的几何载体”，仅存在于二维平面。
- 直角坐标系向量：可在n维空间（n≥1）中定义，由坐标分量（x₁,x₂,…,xₙ）描述，本质是“空间中具有大小和方向的量”，不局限于二维。

1. **运算规则**
- 高斯平面向量：除了向量的加减、数乘，还自带复数的**乘法（或除法）** ，结果仍为复数（对应向量旋转+伸缩）。
- 直角坐标系向量：核心运算为加减、数乘、点积（结果为标量）、叉积（仅三维，结果为向量），无“向量×向量=向量”的天然乘法（需额外定义矩阵乘法等）。

1. **应用场景**
- 高斯平面向量：主要用于处理复数相关问题，比如复变函数、信号处理、交流电分析等，侧重“旋转、相位”相关计算。
- 直角坐标系向量：适用范围更广，涵盖物理力学（力、速度合成）、几何分析、线性代数等，侧重“多维空间的量化描述”。

二维直角坐标系中的向量，若仅考虑加减和数乘运算，与高斯平面向量的代数结构一致（同构），但一旦涉及乘法运算，两者的差异就会显现。

### 复向量计算优势

复向量的优势本质是**把“旋转+伸缩”的几何变换，转化为简单的复数乘法**，比直角坐标系向量的运算更简洁、直观，还能自然适配相位相关需求。

**核心优势**

复向量能将“旋转、相位”相关的复杂操作（如角度叠加、相位偏移）转化为代数运算，避免直角坐标系向量的繁琐推导，且天然贴合相位的周期性和叠加性。

1. **旋转操作：乘法替代矩阵/三角函数**
- 复向量：旋转θ角只需乘以复数e^(iθ)（或cosθ + i sinθ），一步完成“旋转+可能的伸缩”。比如向量(1,0)（对应复数1）旋转90°，直接乘i就得到(0,1)，无需额外计算。
- 直角坐标系向量：旋转θ角需用旋转矩阵（[cosθ, -sinθ; sinθ, cosθ]）与向量做矩阵乘法，还要展开三角函数运算，步骤更繁琐。

1. **相位叠加：代数加法替代几何合成**
- 复向量：相位是复数的辐角，多个相位叠加直接对应复数乘法（辐角相加、模长相乘）。比如信号相位偏移α后再偏移β，只需将对应复数相乘，辐角自动叠加为α+β。
- 直角坐标系向量：相位需通过反正切函数（arctan(y/x)）计算，多次相位叠加要先合成向量再反求相位，过程中容易丢失精度，且计算量更大。

1. **伸缩+旋转同步：单一运算兼顾双重需求**
- 复向量：复数的模对应向量长度（伸缩倍数），辐角对应旋转角度，一次乘法就能同时实现“伸缩”和“旋转”。比如乘以3e^(i60°)，就是将向量拉长3倍再旋转60°。
- 直角坐标系向量：伸缩需做数乘，旋转需做矩阵乘法，两个操作要分步进行，且需分别处理长度和角度的计算，逻辑更零散。

1. **周期性适配：天然契合相位的循环特性**
- 复向量：复数辐角的周期性（2π为周期）与相位的周期性完全匹配，计算时无需额外处理周期边界，比如相位370°可直接等价于10°（复数辐角自动取模2π）。
- 直角坐标系向量：相位需手动通过三角函数的周期性调整，容易出现计算冗余或边界错误。

### 计算示例

**欧拉公式（e^(iθ) = cosθ + i sinθ）** 

初始向量：幅度=2，相位=30°；需求：放大1.5倍 + 逆时针旋转60°，求最终坐标、幅度、相位。

**步骤1：初始向量的指数形式**

根据欧拉公式，复数可表示为 `z = r×e^(iθ)`（r=幅度，θ=相位/辐角）
- 初始幅度r₁=2，初始相位θ₁=30°=π/6（弧度制，欧拉公式常用弧度）
- 初始复数：`z₁ = 2×e^(iπ/6)`

**步骤2：“放大+旋转”的算子复数**

- 幅度放大1.5倍：算子幅度r₂=1.5
- 旋转60°=π/3：算子相位θ₂=π/3
- 算子复数：`z₂ = 1.5×e^(iπ/3)`

**步骤3：复数乘法（指数形式核心优势：指数相加）**

复数指数形式乘法规则：`r₁e^(iθ₁) × r₂e^(iθ₂) = (r₁×r₂)×e^(i(θ₁+θ₂))`
- 直接计算结果：`z_result = 2×1.5 × e^(i(π/6 + π/3)) = 3×e^(iπ/2)`

**步骤4：还原为坐标（可选，按需转换）**

用欧拉公式将结果转回代数形式（x+yi），x=rcosθ，y=rsinθ

- θ=π/2（90°），cos(π/2)=0，sin(π/2)=1
- 坐标：`z_result = 3×(cosπ/2 + i sinπ/2) = 3×(0 + i×1) = 0 + 3i`，对应坐标(0,3)

**最终结果**

幅度=3，相位=π/2（90°），坐标(0,3)。

**欧拉公式的额外优势**

1. 运算更简洁：无需展开三角函数，直接通过“指数相加”实现相位叠加，完全规避繁琐的多项式乘法。
2. 直观性更强：相位的叠加直接体现为指数部分的代数加法，物理意义（相位累积）与数学运算完全统一。
3. 多次操作更高效：若需多次旋转+放大，比如再旋转30°、放大2倍，只需继续乘 `2×e^(iπ/6)`，结果直接为 `3×2 × e^(i(π/2 + π/6)) = 6×e^(i2π/3)`，一步到位。
