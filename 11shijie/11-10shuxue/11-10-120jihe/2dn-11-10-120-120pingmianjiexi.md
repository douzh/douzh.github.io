# 平面解析几何

平面解析几何的核心思想是**用代数方法研究平面几何问题**，通过建立平面直角坐标系，将点映射为坐标、曲线映射为方程，实现几何与代数的相互转化。其知识框架按**研究领域、核心公理、常用公式、经典证明**四个维度结构化呈现。

## 一、 核心研究领域
1.  **坐标系与点的坐标**
    - 平面直角坐标系的建立：横轴（$x$轴）、纵轴（$y$轴）、原点、象限的定义
    - 点的坐标表示：平面内任意一点$P$对应唯一有序实数对$(x,y)$，反之亦然
    - 对称点的坐标特征：关于$x$轴、$y$轴、原点、直线$y=x$对称的点的坐标变换规律
2.  **直线与线性方程**
    - 直线的倾斜角与斜率：倾斜角$\alpha$的范围$[0,\pi)$，斜率$k=\tan\alpha$（$\alpha\neq\frac{\pi}{2}$）
    - 直线方程的多种形式：点斜式、斜截式、两点式、截距式、一般式
    - 两条直线的位置关系：平行、垂直、相交（交点坐标求解）
    - 点到直线的距离、两条平行线间的距离
3.  **圆锥曲线**
    - 圆的方程：标准式、一般式，点与圆、直线与圆、圆与圆的位置关系
    - 椭圆：定义（到两定点距离之和为定值）、标准方程、几何性质（范围、对称性、顶点、离心率）
    - 双曲线：定义（到两定点距离之差的绝对值为定值）、标准方程、几何性质（范围、对称性、顶点、渐近线、离心率）
    - 抛物线：定义（到定点与定直线距离相等）、标准方程、几何性质（范围、对称性、顶点、准线、离心率）
4.  **曲线与方程**
    - 曲线的方程与方程的曲线的定义：满足纯粹性与完备性
    - 求曲线方程的方法：直接法、定义法、相关点法、参数法
    - 参数方程与普通方程的互化：直线、圆、椭圆的参数方程

## 二、 核心公理与基本原理
平面解析几何的公理体系基于**平面几何公理**和**坐标系的基本约定**，核心原理如下：
1.  **坐标对应公理**：平面内的点与有序实数对$(x,y)$之间存在一一对应关系。
2.  **两点确定直线公理**：平面内任意两点$A(x_1,y_1)$、$B(x_2,y_2)$，有且只有一条直线经过这两点。
3.  **距离公式公理基础**：两点间的距离满足平面几何中“两点之间线段最短”的公理，其代数表达式由勾股定理推导而来。
4.  **斜率存在的约定**：对于与$x$轴不垂直的直线，其斜率$k$存在；与$x$轴垂直的直线，斜率不存在。
5.  **圆锥曲线的定义公理**：椭圆、双曲线、抛物线的定义本身可作为推导其方程的公理依据，无需额外证明。

## 三、 常用公式
### 1.  点与坐标相关公式
- **两点间距离公式**：设两点$A(x_1,y_1)$、$B(x_2,y_2)$，则$|AB|=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}$
- **线段中点坐标公式**：设线段$AB$的中点为$M$，则$M\left(\frac{x_1+x_2}{2},\frac{y_1+y_2}{2}\right)$
- **线段定比分点公式**：设点$P$分线段$AB$的比为$\lambda=\frac{AP}{PB}$，则$P\left(\frac{x_1+\lambda x_2}{1+\lambda},\frac{y_1+\lambda y_2}{1+\lambda}\right)$（$\lambda\neq-1$）
- **点的对称变换公式**
  - 点$P(x,y)$关于$x$轴对称的点：$P_1(x,-y)$
  - 点$P(x,y)$关于$y$轴对称的点：$P_2(-x,y)$
  - 点$P(x,y)$关于原点对称的点：$P_3(-x,-y)$
  - 点$P(x,y)$关于直线$y=x$对称的点：$P_4(y,x)$

### 2.  直线相关公式
- **斜率公式**
  - 两点式：过$A(x_1,y_1)$、$B(x_2,y_2)$（$x_1\neq x_2$）的直线斜率$k=\frac{y_2-y_1}{x_2-x_1}$
  - 倾斜角式：$k=\tan\alpha$（$\alpha\in[0,\pi)$，$\alpha\neq\frac{\pi}{2}$）
- **直线方程的五种形式**
  - 点斜式：过点$(x_0,y_0)$，斜率为$k$的直线方程：$y-y_0=k(x-x_0)$
  - 斜截式：斜率为$k$，在$y$轴上截距为$b$的直线方程：$y=kx+b$
  - 两点式：过两点$(x_1,y_1)$、$(x_2,y_2)$（$x_1\neq x_2,y_1\neq y_2$）的直线方程：$\frac{y-y_1}{y_2-y_1}=\frac{x-x_1}{x_2-x_1}$
  - 截距式：在$x$轴、$y$轴上截距分别为$a$、$b$（$a\neq0,b\neq0$）的直线方程：$\frac{x}{a}+\frac{y}{b}=1$
  - 一般式：$Ax+By+C=0$（$A,B$不同时为0）
- **两条直线的位置关系判定公式**
  设直线$l_1:A_1x+B_1y+C_1=0$，$l_2:A_2x+B_2y+C_2=0$
  - 平行：$A_1B_2-A_2B_1=0$且$A_1C_2-A_2C_1\neq0$（或$B_1C_2-B_2C_1\neq0$）
  - 垂直：$A_1A_2+B_1B_2=0$
  - 相交：$A_1B_2-A_2B_1\neq0$
- **距离公式**
  - 点到直线的距离：点$P(x_0,y_0)$到直线$Ax+By+C=0$的距离$d=\frac{|Ax_0+By_0+C|}{\sqrt{A^2+B^2}}$
  - 两条平行线间的距离：直线$l_1:Ax+By+C_1=0$与$l_2:Ax+By+C_2=0$的距离$d=\frac{|C_1-C_2|}{\sqrt{A^2+B^2}}$

### 3.  圆的相关公式
- **圆的方程**
  - 标准式：圆心为$(a,b)$，半径为$r$的圆的方程：$(x-a)^2+(y-b)^2=r^2$
  - 一般式：$x^2+y^2+Dx+Ey+F=0$（$D^2+E^2-4F>0$），圆心为$\left(-\frac{D}{2},-\frac{E}{2}\right)$，半径$r=\frac{1}{2}\sqrt{D^2+E^2-4F}$
- **直线与圆的位置关系判定**
  设圆的圆心到直线的距离为$d$，圆的半径为$r$
  - 相离：$d>r$
  - 相切：$d=r$
  - 相交：$d<r$

### 4.  圆锥曲线的标准方程与性质公式
- **椭圆**
  - 定义式：平面内与两定点$F_1,F_2$的距离之和等于常数$2a$（$2a>|F_1F_2|=2c$）的点的轨迹
  - 标准方程（焦点在$x$轴）：$\frac{x^2}{a^2}+\frac{y^2}{b^2}=1$（$a>b>0$），其中$b^2=a^2-c^2$
  - 离心率：$e=\frac{c}{a}$（$0<e<1$）
- **双曲线**
  - 定义式：平面内与两定点$F_1,F_2$的距离之差的绝对值等于常数$2a$（$0<2a<|F_1F_2|=2c$）的点的轨迹
  - 标准方程（焦点在$x$轴）：$\frac{x^2}{a^2}-\frac{y^2}{b^2}=1$（$a>0,b>0$），其中$b^2=c^2-a^2$
  - 渐近线方程：$y=\pm\frac{b}{a}x$
  - 离心率：$e=\frac{c}{a}$（$e>1$）
- **抛物线**
  - 定义式：平面内与一个定点$F$和一条定直线$l$（$F$不在$l$上）的距离相等的点的轨迹
  - 标准方程（焦点在$x$轴正半轴）：$y^2=2px$（$p>0$），焦点$F\left(\frac{p}{2},0\right)$，准线方程$x=-\frac{p}{2}$
  - 离心率：$e=1$

## 四、 经典定理证明
### 1.  两点间距离公式的证明
**求证**：平面内两点$A(x_1,y_1)$、$B(x_2,y_2)$的距离为$|AB|=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}$。
**证明**：
1.  过点$A$作$x$轴的平行线，过点$B$作$y$轴的平行线，两线交于点$C$。
2.  则点$C$的坐标为$(x_2,y_1)$，且$\triangle ABC$为直角三角形，$\angle C=90^\circ$。
3.  由平面几何的勾股定理，$|AB|^2=|AC|^2+|BC|^2$。
4.  计算直角边长度：$|AC|=|x_2-x_1|$，$|BC|=|y_2-y_1|$。
5.  因此$|AB|^2=(x_2-x_1)^2+(y_2-y_1)^2$，两边开平方得$|AB|=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}$。

### 2.  点到直线的距离公式的证明
**求证**：点$P(x_0,y_0)$到直线$l:Ax+By+C=0$的距离为$d=\frac{|Ax_0+By_0+C|}{\sqrt{A^2+B^2}}$。
**证明**：
1.  当$B\neq0$时，直线$l$的斜率为$-\frac{A}{B}$，则过点$P$且与$l$垂直的直线斜率为$\frac{B}{A}$，其方程为$y-y_0=\frac{B}{A}(x-x_0)$，即$Bx-Ay+(Ay_0-Bx_0)=0$。
2.  联立直线$l$与垂线的方程，求解交点$Q$（垂足）的坐标：
    $$\begin{cases}Ax+By+C=0\\Bx-Ay+(Ay_0-Bx_0)=0\end{cases}$$
    解得$Q$的坐标为$\left(\frac{B(Bx_0-Ay_0)-AC}{A^2+B^2},\frac{A(-Bx_0+Ay_0)-BC}{A^2+B^2}\right)$。
3.  利用两点间距离公式计算$|PQ|$：
    $$|PQ|=\sqrt{\left(x_0-\frac{B(Bx_0-Ay_0)-AC}{A^2+B^2}\right)^2+\left(y_0-\frac{A(-Bx_0+Ay_0)-BC}{A^2+B^2}\right)^2}$$
4.  化简上式，分子提取公因式后可得：
    $$|PQ|=\frac{|Ax_0+By_0+C|}{\sqrt{A^2+B^2}}$$
5.  当$B=0$时，直线$l$的方程为$Ax+C=0$，即$x=-\frac{C}{A}$，此时点$P$到直线$l$的距离为$|x_0+\frac{C}{A}|=\frac{|Ax_0+C|}{\sqrt{A^2}}$，与公式一致。
    综上，点到直线的距离公式成立。

### 3.  椭圆标准方程的推导
**已知**：椭圆的定义为平面内与两定点$F_1(-c,0)$、$F_2(c,0)$的距离之和等于常数$2a$（$2a>2c>0$）。
**求证**：椭圆的标准方程为$\frac{x^2}{a^2}+\frac{y^2}{b^2}=1$（$a>b>0$，$b^2=a^2-c^2$）。
**证明**：
1.  设椭圆上任意一点$P(x,y)$，根据定义有$|PF_1|+|PF_2|=2a$。
2.  由两点间距离公式，$\sqrt{(x+c)^2+y^2}+\sqrt{(x-c)^2+y^2}=2a$。
3.  移项得$\sqrt{(x+c)^2+y^2}=2a-\sqrt{(x-c)^2+y^2}$，两边平方：
    $$(x+c)^2+y^2=4a^2-4a\sqrt{(x-c)^2+y^2}+(x-c)^2+y^2$$
4.  展开并化简得：$cx-a^2=-a\sqrt{(x-c)^2+y^2}$。
5.  再次两边平方：$c^2x^2-2a^2cx+a^4=a^2[(x-c)^2+y^2]$。
6.  展开整理：$(a^2-c^2)x^2+a^2y^2=a^2(a^2-c^2)$。
7.  令$b^2=a^2-c^2$（$b>0$），代入上式得：$b^2x^2+a^2y^2=a^2b^2$。
8.  两边同时除以$a^2b^2$，得到椭圆的标准方程：$\frac{x^2}{a^2}+\frac{y^2}{b^2}=1$。

## 五、 延伸与拓展
1.  **极坐标系**：用极径和极角表示点的位置，适合研究圆、椭圆、双曲线等曲线的极坐标方程，简化焦点相关问题的求解。
2.  **参数方程**：引入参数（如角度、时间）表示曲线，将二元方程转化为一元函数，便于分析曲线的几何性质和运动轨迹。
3.  **平面向量与解析几何的结合**：用向量的坐标运算研究直线的方向、点的位置关系，简化垂直、平行等判定条件。
