The default note type in Trilium, text notes allow for rich formatting, tables, images, admonitions and a handful of other features.

## Formatting bars

Most of the interaction with text notes is done via the built-in toolbars. Depending on preference, there are two different layouts:

*   The _Floating toolbar_ is hidden by default and only appears when needed. In this mode there are actually two different toolbars:

## Read-Only vs. Editing Mode

Text notes are usually opened in edit mode. However, they may open in read-only mode if the note is too big or the note is explicitly marked as read-only. For more information, see <a class="reference-link" href="#root/_help_CoFPLs3dRlXc">[missing note]</a>.

## Keyboard shortcuts

There are numerous keyboard shortcuts to format the text without having to use the mouse. For a reference of all the key combinations, see  <a class="reference-link" href="#root/_help_A9Oc6YKKc65v">Keyboard Shortcuts</a>. In addition, see <a class="reference-link" href="#root/_help_QrtTYPmdd1qq">Markdown-like formatting</a> as an alternative to the keyboard shortcuts.

## Content width

For readability purposes on wider screens, the width of text notes is limited via a configurable option. See <a class="reference-link" href="#root/_help_t596jLvPrqkS">[missing note]</a> for more information.

## Converting to a Markdown note

Text notes can be converted to <a class="reference-link" href="#root/_help_6RM1Q7ppFVoj">Markdown</a> notes. See <a class="reference-link" href="#root/_help_jludwdW7N4hg">Converting between note types</a>.

## Technical details

For the text editing functionality, Trilium uses a commercial product (with an open-source base) called <a class="reference-link" href="#root/_help_MI26XDLSAlCD">[missing note]</a>. This brings the benefit of having a powerful WYSIWYG (What You See Is What You Get) editor.
