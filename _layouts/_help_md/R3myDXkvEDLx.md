The right sidebar displays specific content for the current note. The sidebar is grouped into multiple tabs:

*   <a class="reference-link" href="#root/_help_2dcGDhp9WFKb">Outline tab</a>, which displays the table of contents, highlights and other navigation-related sections depending on the note type.
*   <a class="reference-link" href="#root/_help_uNtgN0cUKEBc">Attributes tab</a>, which provides a visual editor for the current note's <a class="reference-link" href="#root/_help_zEY4DaJG4YT5">Attributes</a>.
*   <a class="reference-link" href="#root/_help_LrKznOtw9cQD">AI chat tab</a>, which uses the <a class="reference-link" href="#root/_help_GBBMSlVSOIGP">AI</a> integration to chat, with optional access to the current note.
*   <a class="reference-link" href="#root/_help_KRlZFoIH0j6p">Connections tab</a>, which groups together the note map, note paths, backlinks and similar notes.

> [!WARNING]
> There are currently two types of sidebars; the documentation here refers only to the one defined in the <a class="reference-link" href="#root/_help_IjZS7iK5EXtb">New Layout</a>. The old layout has a different sidebar mechanism which only shows the table of contents and highlights.

## Toggling the right sidebar

There are two ways to toggle the right sidebar:

*   Via the <img src="Right Sidebar_image.png" width="25" height="21">icon near the title bar, which toggles whether the sidebar is docked.
*   Via the _Toggle right pane_ [keyboard shortcut](#root/_help_A9Oc6YKKc65v), which is not assigned by default.

## Peeking the sidebar

There is a small strip near the right edge of the app which shows an arrow icon.

*   When the sidebar is hidden, pressing the edge will _peek_ the sidebar.
    *   In this mode the sidebar is shown temporarily above the content, without shifting the content of your notes.
    *   Clicking outside the sidebar while in peek mode will simply hide the sidebar. Same goes for the X button and clicking on the right edge.
    *   Pressing the pin icon will dock the sidebar.
*   When the sidebar is docked, pressing the edge will hide the sidebar (similar to the toggle icon at the top).
