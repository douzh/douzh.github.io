{"noteId":"_help_W8vYD3Q1zjCR","content":"The _File_ note type can be used to attach various external files such as images, videos or PDF documents.\n\n## Uploading a file\n\nSince these files come from an external source, it is not possible to create a _File_ note type directly:\n\n*   Drag a file into the <a class=\"reference-link\" href=\"#root/_help_oPVyFC7WL2Lp\">Note Tree</a>.\n*   Right click a note and select _Import into note_ and point it to one of the supported files.\n\n## Supported file types\n\n### PDFs\n\nPDFs can be uploaded to Trilium and they will display a live preview with full support for various features such as table of contents, annotations, as well as remembering the last page read. For more information, see the dedicated <a class=\"reference-link\" href=\"#root/_help_XJGJrpu7F9sh\">PDFs</a> page.\n\n## Office documents\n\nTrilium offers previews for Office documents such as Word (`.docx`), Excel (`.xlsx`) and PowerPoint (`.pptx`). For more information, see the dedicated <a class=\"reference-link\" href=\"#root/_help_KG48zgNY31NW\">Office documents</a>.\n\n### Images\n\n<figure class=\"image image-style-align-center image_resized\" style=\"width:50%;\"><img style=\"aspect-ratio:879/766;\" src=\"2_File_image.png\" width=\"879\" height=\"766\"></figure>\n\nInteraction:\n\n*   _Copy reference to clipboard_, for embedding the image within  <a class=\"reference-link\" href=\"#root/_help_iPIMuisry3hd\">Text</a> notes.\n    *   See <a class=\"reference-link\" href=\"#root/_help_0Ofbk1aSuVRu\">Image references</a> for more information.\n    *   Alternatively, press the corresponding button from the <a class=\"reference-link\" href=\"#root/_help_XpOYSgsLkTJy\">Floating buttons</a>.\n\n### Videos\n\nSee <a class=\"reference-link\" href=\"#root/_help_AjqEeiDUOzj4\">Audio &amp; Video</a>.\n\n### Audio\n\n<figure class=\"image image-style-align-center image_resized\" style=\"width:50%;\"><img style=\"aspect-ratio:850/243;\" src=\"1_File_image.png\" width=\"850\" height=\"243\"></figure>\n\nAdding a supported audio file will reveal a basic audio player that can be used to play it.\n\nInteractions:\n\n*   The audio can be played/paused using the dedicated button.\n*   Dragging the mouse across, or clicking the progress bar will seek through the song.\n*   The volume can be set.\n*   The playback speed can be adjusted via the contextual menu next to the volume.\n\n### Text files\n\n<figure class=\"image image-style-align-center image_resized\" style=\"width:50%;\"><img style=\"aspect-ratio:926/347;\" src=\"File_image.png\" width=\"926\" height=\"347\"></figure>\n\nFiles that are identified as containing text will show a preview of their content. One common use case for this type of file is to embed text files whose content is not necessarily of interest to the user, such as third-party libraries or generated content, that can then be downloaded if needed.\n\nNote that generally text files will be [imported](#root/_help_mHbBMPDPkVV5) as either <a class=\"reference-link\" href=\"#root/_help_iPIMuisry3hd\">Text</a> or  <a class=\"reference-link\" href=\"#root/_help_6f9hih2hXXZk\">Code</a> notes. To bypass this behavior and create a _File_ note type, use the _Import into note_ feature and uncheck _Import HTML, Markdown and TXT as text notes_, as well as _Import recognized code files as code notes_. \n\nSince one of the use cases for having files instead of notes is to display large files, the content preview is limited to a relatively small amount of characters. To view the full file, consider opening it in an external application.\n\n### GPS tracks\n\nTrilium displays information about GPS tracks in `.gpx` format, such as the distance, duration, elevation profile, tracks, markers.\n\nWhen a `.gpx` note is dropped in a  <a class=\"reference-link\" href=\"#root/_help_81SGnPGMk7Xc\">Geo Map</a>, the track itself will also be displayed on the map.\n\n<figure class=\"image\"><img style=\"aspect-ratio:1500/807;\" src=\"4_File_image.png\" width=\"1500\" height=\"807\"></figure>\n\n### Unknown file types\n\n<figure class=\"image image-style-align-center image_resized\" style=\"width:50%;\"><img style=\"aspect-ratio:532/240;\" src=\"3_File_image.png\" width=\"532\" height=\"240\"></figure>\n\nIf the file could not be identified as any of the supported file types from above, it will be treated as an unknown file. In this case, all the default interactions will be available such as downloading or opening the file externally, but there will be no preview of the content.\n\n## Interaction\n\n*   Regardless of the file type, a series of buttons will be displayed in the _Image_ or _File_ tab in the <a class=\"reference-link\" href=\"#root/_help_BlN9DFI679QC\">Ribbon</a>.\n    *   _Download_, which will download the file for local use.\n    *   _Open_, will will open the file with the system-default application.\n    *   Upload new revision to replace the file with a new one.\n*   It is **not** possible to change the note type of a _File_ note.\n*   Convert into an [attachment](#root/_help_0vhv7lsOLy82) from the [note menu](#root/_help_8YBEPzcpUgxw).\n\n## Relation with other notes\n\n*   Files are also displayed in the <a class=\"reference-link\" href=\"#root/_help_0ESUbbAxVnoK\">Note List</a> based on their type:\n    \n    <img class=\"image_resized\" style=\"aspect-ratio:853/315;width:50%;\" src=\"5_File_image.png\" width=\"853\" height=\"315\">\n*   Non-image files can be embedded into text notes as read-only widgets via the <a class=\"reference-link\" href=\"#root/_help_nBAXQFj20hS1\">Include Note</a> functionality.\n*   Image files can be embedded into text notes like normal images via  <a class=\"reference-link\" href=\"#root/_help_0Ofbk1aSuVRu\">Image references</a>.\n\n## File size limit\n\nAn individual file cannot be bigger than 374 MiB.
