There are two types of links:

*   <a class="reference-link" href="#root/_help_3IDVtesTQ8ds">External links</a>, for standard hyperlinks to websites or other resources.
*   <a class="reference-link" href="#root/_help_hrZ1D00cLbal">Internal (reference) links</a> for links to other notes within Trilium.
    *   The list of notes that refer to a particular note is called <a class="reference-link" href="#root/_help_wfGXLmm7x27z">Backlinks</a>.

## Note map

Trilium provides a visualization of incoming and outgoing links for a particular note. See [note map](#root/_help_BCkXAVs63Ttv) for details.
