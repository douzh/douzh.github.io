## Formatting bars

Most of the interaction with text notes is done via the built-in toolbars. Depending on preference, there are two different layouts:

  * The _Floating toolbar_ is hidden by default and only appears when needed. In this mode there are actually two different toolbars:   
![](1_Text_image.png) ![](2_Text_image.png)
  * A toolbar that appears when text is selected. This provides text-level formatting such as bold, italic, text colors, inline code, etc.

Fore more information see [Formatting toolbar](#root/_help_nRhnJkTT8cPs).

## Read-Only vs. Editing Mode

Text notes are usually opened in edit mode. However, they may open in read-only mode if the note is too big or the note is explicitly marked as read-only. For more information, see [[missing note]](#root/_help_CoFPLs3dRlXc).

## Keyboard shortcuts

There are numerous keyboard shortcuts to format the text without having to use the mouse. For a reference of all the key combinations, see  [Keyboard Shortcuts](#root/_help_A9Oc6YKKc65v). In addition, see [Markdown-like formatting](#root/_help_QrtTYPmdd1qq) as an alternative to the keyboard shortcuts.

## Content width

For readability purposes on wider screens, the width of text notes is limited via a configurable option. See [[missing note]](#root/_help_t596jLvPrqkS) for more information.

## Converting to a Markdown note

Text notes can be converted to [Markdown](#root/_help_6RM1Q7ppFVoj) notes. See [Converting between note types](#root/_help_jludwdW7N4hg).

## Technical details

For the text editing functionality, Trilium uses a commercial product (with an open-source base) called [[missing note]](#root/_help_MI26XDLSAlCD). This brings the benefit of having a powerful WYSIWYG (What You See Is What You Get) editor.
