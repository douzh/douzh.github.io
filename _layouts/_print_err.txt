0: Trilium supports Markdown for both import and export, while trying to keep compatibility as high as possible.

1: 

2: ## Import

3: 

4: ### Clipboard import

5: 

6: If you want to import just a chunk of markdown from clipboard, you can do it from editor block menu:

7: 

8: ![](Markdown_markdown-inline-import.gif)

9: 

10: ### File import

11: 

12: You can also import Markdown files from files:

13: 

14: *   single markdown file (with .md extension)

15: *   whole tree of markdown files (packaged into [.zip](https://en.wikipedia.org/wiki/Tar_\(computing\)) archive)

16:     *   Markdown files need to be packaged into ZIP archive because browser can't read directories, only single files.

17:     *   You can use e.g. [7-zip](https://www.7-zip.org) to package directory of markdown files into the ZIP file

18: 

19: ![](Markdown_markdown-file-import.gif)

21: ## Export

22: 

23: ### Subtree export

24: 

25: You can export whole subtree to ZIP archive which will have directory structured modelled after subtree structure:

26: 

27: ![](Markdown_markdown-export-subtree.gif)

28: 

29: ### Single note export

30: 

31: If you want to export just single note without its subtree, you can do it from Note actions menu:

32: 

33: ![](Markdown_markdown-export-note.gif)

34: 

35: ### Exporting protected notes

36: 

37: If you want to export protected notes, enter a protected session first! This will export the notes in an unencrypted form, so if you reimport into Trilium, make sure to re-protect these notes.
