<p>有时，部署<a href="#root/z5TN5NCWzga3">专用服务器安装</a>并不可行。桌面应用默认自带一个功能完整的服务器实例。</p><p>出于安全原因，该功能<strong>默认未启用</strong>。要启用它，请在<a class="reference-link" href="#root/TNBOr62S7Osb">Security</a>中启用 <em>网络访问（Network access）</em>。</p><p>启用网络访问并重启应用后，你可以在本机通过访问 <a href="http://localhost:37840/login">http://localhost:37840/login</a> 打开该 Web 界面。</p><aside class="admonition note"><p>注意：桌面应用内嵌的服务器只在桌面应用运行时才运行。关闭应用也会关闭服务器。要解决此问题，可以尝试将应用隐藏到系统托盘。</p></aside><h2>移动界面</h2><p>默认情况下，即使在移动设备上也会显示桌面用户界面。要切换到移动版，只需进入<a class="reference-link" href="#root/a1NgEcaebRLj">Global menu</a>并选择“切换到移动版”。</p><h2>在 Windows 上通过 Windows Defender 防火墙开放外部端口</h2><p>首先，在本地终端运行 <code spellcheck="false">ipconfig</code> 查出桌面服务器的 IP。然后在另一台设备上尝试访问 <code spellcheck="false">http://&lt;ip&gt;:37840/login</code>。如果访问不了，很可能是操作系统防火墙拦截了该端口。</p><p>如果你使用的是 Windows Defender 防火墙：</p><ol><li>进入 Windows 开始菜单，搜索“高级安全 Windows Defender 防火墙”。</li><li>在左侧树中进入“入站规则”，然后在右侧“操作”侧栏中选择“新建规则”。</li><li>选择“端口”并点击“下一步”。</li><li>在“特定本地端口”中输入 <code spellcheck="false">37840</code>，然后点击“下一步”。</li><li>保持勾选“允许连接”并点击“下一步”。</li><li>配置要应用的网络（不确定则全部勾选），然后点击“下一步”。</li><li>为规则添加合适的名称（如“Trilium Notes”）并点击“完成”。</li></ol><aside class="admonition warning"><p>警告：自 v0.104.0 起，Trilium 使用的端口仅在 <code spellcheck="false">localhost</code> 上可访问。如需在本地网络中启用，请参见<a class="reference-link" href="#root/KENrlyFaUbZN">Network Access</a>。</p></aside>
