## 关键结论：Trilium backend 脚本的取数通道

- **`require('fs')` 被显式封锁**，报错原文：`Module 'fs' is blocked for security. Scripts cannot access OS-level modules like child_process, fs, net, os.`
  → 同理 `child_process` / `net` / `os` 全不能用，别再试
- **可行通道：`fetch()` + 本地 HTTP 服务**。做法：`cd kb-km && python3 -m http.server 8765 --bind 127.0.0.1`，
  脚本内 `await fetch('http://127.0.0.1:8765/xxx.md')`。注意取源是异步的，脚本主体要包进 `async IIFE`，
  建树日志会进 Trilium 日志（Help → Show logs），Execute 面板可能只显示同步部分
- 兜底通道：把 md 导入为库内笔记挂 `#src=src-level2/3`，脚本读 `getContent()`
- 注意 `r.text()` 拿到的是字符数不是字节数（中文 3 字节→1 字符），145221 字节 ≈ 95812 字符，属正常
