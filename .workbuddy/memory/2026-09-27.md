# 2026-09-27

## 本机安装 ffmpeg 9.0.2

- 需求：本地安装 ffmpeg（用于视频压缩/倍速/竖屏 1080x1920 剪辑合成）
- `brew install ffmpeg` 失败：系统 Command Line Tools 过旧（要求 Xcode 16.2 CLT），且 `softwareupdate --list` 里**没有** CLT 更新项（只有 macOS Sonoma 14.8.9 / Tahoe 26.7 大版本升级），故未走系统升级路线
- 最终方案：evermeet.cx 的 macOS 预编译静态二进制（ffmpeg 9.0.2 + ffprobe 9.0.2），装到 `/usr/local/bin`（该目录当前用户可写，无需 sudo）
- 坑：
  - evermeet 直连仅 ~24KB/s，单次 curl 必然超时 → 用 `curl -C -` 断点续传循环；**开两个连接并行下载反而更快**（ffmpeg 8.5 分钟 / ffprobe 14 分钟）
  - 下载后必须 `xattr -d com.apple.quarantine`，否则 Gatekeeper 拦截
  - npm 包 `@ffmpeg-installer/darwin-x64` 里是 2018 年的 N-92718，太旧，不要用
- 验证：竖屏 1080x1920 生成、2 倍速 + CRF 28 压缩、drawtext/overlay/fade 滤镜均正常
