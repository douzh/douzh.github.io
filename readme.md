## 命记

一、命由天生但可改变
- 世界运行自有其规律，但因有规律才可改变，过去不可改变，未来不可限量，一切都在当下。
- 如果我们什么也不做，命运将代替我们选择，未来将不再存在，活着的我们将在沉默中死去。

二、三观定命
- 世界观：人们对整个世界（包括自然界、人类社会和思想）的总体看法和根本观点。
- 人生观：人对人生的目的、意义、价值的根本看法，人生观是世界观在人生问题上的体现。
- 价值观：人对事物（包括人、事、物）高低贵贱的判断标准，价值观则是人生观的具体延伸。cd
